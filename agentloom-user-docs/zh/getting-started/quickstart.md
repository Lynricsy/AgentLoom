# 快速开始

本指南将带你从零开始，完成注册、创建工作流、添加节点、连线配置，到运行并查看结果的完整流程。整个过程大约需要十分钟。

---

## 第一步：注册账号

1. 打开浏览器，访问 [https://agentloom.ling.plus/](https://agentloom.ling.plus/)。

2. 你会看到登录页面。如果你还没有账号，点击页面下方的"注册"链接，进入注册页面。

3. 填写你的邮箱地址和密码，点击"注册"按钮完成账号创建。你也可以使用 Google 或 GitHub 账号直接登录。

> 界面提示：注册页面位于 `/register` 路径，登录页面位于 `/login` 路径。如果你选择第三方账号登录，系统会跳转到对应的授权页面，授权后自动返回 AgentLoom。

4. 注册成功后，系统会引导你完成初始设置（比如创建你的组织）。按照提示操作即可。

5. 设置完成后，你会进入 AgentLoom 的主界面 -- Studio 工作台。

---

## 第二步：创建你的第一个工作流

登录后，你将看到工作流列表页面。这是 AgentLoom 的起始页面，展示你创建的所有工作流。

1. 点击页面右上角的"新建工作流"按钮（带有加号图标）。

> 界面提示：页面顶部标题为"工作流"，右上角有一个蓝色或主题色的按钮，上面写着"新建工作流"。

2. 在弹出的对话框中，填写以下信息：
   - **名称**（必填）：为你的工作流起一个名字，例如"我的第一个工作流"
   - **描述**（可选）：简要描述工作流的用途，例如"快速入门测试"
   - 你还可以点击名称左侧的图标选择器，为工作流选择一个有辨识度的图标

3. 点击"创建"按钮。

4. 系统会自动跳转到画布编辑器页面，这就是你构建工作流的主要工作区域。

> 界面提示：画布编辑器的地址格式为 `/workflows/工作流ID`。你会看到一个空白的画布区域，左侧有节点面板，顶部有版本工具栏。

---

## 第三步：添加节点

现在你面前是一个空白的画布。让我们来添加一些节点，搭建一个最简单的工作流 -- 一个 AI Agent 处理文本并输出结果。

### 添加 Chat Agent 节点

1. 在画布左侧，你会看到一个节点面板，里面按分类排列了所有可用的节点类型。

> 界面提示：节点面板按分类分组显示，分类包括"Agent 智能体"、"工具"、"触发器"、"知识与记忆"、"输出"、"流程控制"等。

2. 在"Agent 智能体"分类中，找到"Chat Agent"节点。

3. 用鼠标将"Chat Agent"节点拖拽到画布中央区域，松开鼠标即可放置节点。

4. 放置成功后，画布上会出现一个带有名称的节点卡片。

### 添加 LLM 模型节点

Chat Agent 需要一个 LLM 模型来提供推理能力。

1. 在节点面板的"Agent 智能体"分类中，找到"LLM 模型"节点。

2. 将它拖拽到画布上，放在 Chat Agent 节点的左边或上方。

### 添加文本输出节点

为了看到工作流的运行结果，我们需要添加一个输出节点。

1. 在节点面板的"输出"分类中，找到"Text Output"节点。

2. 将它拖拽到画布上，放在 Chat Agent 节点的右边或下方。

此时你的画布上应该有三个节点：LLM 模型、Chat Agent、Text Output。

---

## 第四步：连接节点

节点添加好后，需要通过连线将它们串联起来，让数据可以在节点之间流转。

### 了解端口

仔细观察每个节点，你会发现节点的边缘有一些小圆点或小图形，这些就是"端口"。端口分为两种：

- **输入端口**：通常在节点的左侧，用来接收来自上游节点的数据
- **输出端口**：通常在节点的右侧，用来向下游节点发送数据

不同颜色和形状的端口代表不同的数据类型。只有数据类型兼容的端口之间才能连线。

### 连接 LLM 模型到 Chat Agent

1. 将鼠标移到 LLM 模型节点右侧的"模型"输出端口上（鼠标悬停时端口会高亮）。

2. 按住鼠标左键，从该端口开始向 Chat Agent 节点左侧的"模型"输入端口拖拽。

3. 当连线到达目标端口时，端口会显示可连接的提示。松开鼠标，连线即建立成功。

> 界面提示：成功连线后，两个端口之间会显示一条平滑的曲线。如果尝试连接不兼容的端口类型，系统会阻止连接并给出提示。

### 连接 Chat Agent 到 Text Output

1. 从 Chat Agent 节点右侧的"回复"输出端口开始拖拽。

2. 连接到 Text Output 节点左侧的"文本"输入端口。

### 连接执行流

除了数据连线，你还需要连接"执行流"来告诉系统节点的运行顺序。

1. 在 LLM 模型节点上，你会看到一个箭头形状的执行流输出端口。从这个端口拖线到 Chat Agent 的执行流输入端口。

2. 同样，将 Chat Agent 的执行流输出端口连接到 Text Output 的执行流输入端口。

> 界���提示：执行流端口通常显示为箭头形状，颜色与数据端口不同。执行流定义了节点的执行顺序。

现在你的三个节点已经正确连接起来，形成了一个完整的流程链路。

---

## 第五步：配置节点

节点连好后，需要对关键节点进行配置。

### 配置 LLM 模型

1. 点击画布上的"LLM 模型"节点，右侧会弹出属性配置面板。

> 界面提示：属性面板位于画布右侧，宽度约 320 像素。面板顶部显示节点名称和类型，下方是配置表单。

2. 在配置面板中，选择你想使用的 AI 模型提供商和具体模型。如果你还没有配置过模型，可以先在"资源 > LLM 模型"页面添加你的模型配置。

### 配置 Chat Agent

1. 点击画布上的"Chat Agent"节点，打开它的属性配置面板。

2. 在"System Prompt"字段中，输入 Agent 的系统提示词。例如：

   ```
   你是一位友好的助手。请用简洁明了的语言回答用户的问题。
   ```

   系统提示词决定了 Agent 的行为模式和回答风格。

### 配置 Text Output

Text Output 节点通常无需额外配置，它会自动接收并展示上游 Agent 的文本输出。

---

## 第六步：运行工作流

一切就绪，现在来运行你的工作流。

1. 在画布上方的版本工具栏中，找到"运行"按钮（蓝色按钮，带有播放图标）。

> 界面提示：版本工具栏位于画布顶部，从左到右依次是状态徽章（"草稿"/"已发布"/"已归档"）、保存快照、历史记录、介入策略、输入参数、触发器、发布、导出、导入、分享、运行等按钮。

2. 点击"运行"按钮。如果工作流配置了输入参数，系统会先弹出参数填写页面；如果没有（就像我们这个简单示例），工作流会直接开始运行。

3. 运行开始后，你会看到：
   - "运行"按钮变为"执行中"状态，并显示加载动画
   - 画布底部的状态栏显示当前执行状态和进度，例如"执行中 (1/3)"
   - 画布上的节点会依次高亮，显示它们各自的执行状态

> 界面提示：底部状态栏显示"节点数 | 连接数 | 缩放比例 | 保存状态 | 执行状态"。执行状态会实时更新。

4. 等待工作流执行完成。对于这个简单示例，通常几秒到几十秒即可完成。

---

## 第七步：查看结果

工作流执行完成后，你可以查看每个节点的运行结果。

### 查看节点执行详情

1. 点击画布上的任意节点（比如 Chat Agent），打开右侧属性面板。

2. 在属性面板的下方区域，你会看到"实时执行"区段，其中包含：
   - **执行状态**：显示节点的当前状态（已完成、失败等）
   - **步骤 ID**：此次执行的唯一标识
   - **流式状态**：是否还在接收输出
   - **开始时间**和**完成时间**：节点的执行时间区间
   - **输出流**：节点产生的文本输出内容

> 界面提示：如果节点执行成功，状态徽章会显示绿色的"已完成"；如果失败，会显示红色的"失败"并附带错误信息。

### 查看完整执行记录

如果你想查看更详细的执行信息，可以进入执行调试页面：

1. 在工作流列表页或执行历史中，找到这次执行记录，点击进入。

2. 执行调试页面分为三栏：
   - **左栏**：只读画布视图，展示工作流全貌
   - **中栏**：执行时间线，按时间顺序展示每个节点的执行过程
   - **右栏**：选中某个节点后，展示该节点的详细执行信息

---

## 小结与下一步

恭喜你成功运行了第一个 AgentLoom 工作流。让我们回顾一下整个流程：

1. **注册账号** -- 访问 AgentLoom 并完成注册
2. **创建工作流** -- 在工作流列表页新建空白工作流
3. **添加节点** -- 从节点面板拖拽节点到画布
4. **连接节点** -- 通过端口连线建立数据流和执行流
5. **配置节点** -- 在属性面板中设置各节点参数
6. **运行** -- 点击运行按钮启动执行
7. **查看结果** -- 在属性面板或执行调试页面查看输出

如果你不想从零开始搭建，AgentLoom 提供了多个预置模板，涵盖竞品分析、内容创作、代码审查等常见场景。在工作流列表页创建新工作流时，你可以选择从模板开始，系统会自动为你搭建好完整的节点和连线结构，你只需要根据自己的需求调整配置即可。

详细操作请参考 [使用模板](../workflows/templates.md)。
