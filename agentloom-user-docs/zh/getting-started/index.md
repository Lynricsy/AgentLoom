# 什么是 AgentLoom

AgentLoom 是一个多智能体工作流编排平台。它提供了一个可视化的画布编辑器，让你可以像搭积木一样把多个 AI 智能体（Agent）和工具组合成完整的自动化流程，无需编写任何代码就能构建出强大的 AI 工作管线。

你可以通过浏览器访问 [https://agentloom.ling.plus/](https://agentloom.ling.plus/) 开始使用 AgentLoom。

---

## 核心价值

### 可视化编排，所见即所得

在 AgentLoom 中，你的整个 AI 工作流程以直观的流程图形式呈现在画布上。每一个功能单元是一个"节点"，节点之间通过连线传递数据。你只需要拖拽节点、拉线连接，就能构建出从简单到复杂的各种流程。

这意味着你不需要理解编程语言，不需要编写代码，也不需要处理 API 调用的技术细节。你关注的是"我希望 AI 做什么"和"数据怎么流转"。

### 多 Agent 协作

传统的 AI 工具通常是"一个大模型做所有事"。AgentLoom 的思路不同 -- 你可以为不同的任务配置不同的专精 Agent，让它们各自发挥所长，然后通过工作流串联起来协同工作。

比如一个内容创作流程可以由四个 Agent 分工：

- **选题 Agent** 负责确定写作方向
- **研究 Agent** 负责收集素材
- **写作 Agent** 负责生成初稿
- **审校 Agent** 负责润色终稿

每个 Agent 只专注于自己擅长的环节，整体效果远超让单一 Agent 处理所有事情。

### 灵活的自动化触发

工作流不仅可以手动运行，还能通过定时任务、Webhook 或外部 API 事件自动触发。这意味着你可以搭建完全无人值守的自动化流水线，比如每天早上自动生成竞品分析报告、收到客户反馈时自动分类和生成回复建议等。

### 企业级安全与协作

AgentLoom 采用多租户架构，支持组织级别的管理和基于角色的权限控制。你的团队可以在同一个平台上协作，不同成员拥有不同的操作权限。同时，端到端加密保护你的敏感数据和 AI 交互记录。

## 谁适合使用 AgentLoom

AgentLoom 面向所有希望利用 AI 提升工作效率的用户，尤其适合以下角色：

### 业务分析师

如果你经常需要处理大量数据、整理报表或进行市场分析，AgentLoom 可以帮助你搭建自动化的分析流水线。例如：

- 每周自动汇总销售数据并生成分析报告
- 从多个数据源收集信息并进行交叉分析
- 监控市场动态并提炼关键洞察

你只需要在画布上拖拽几个节点、配置好数据来源和分析要求，就能让 AI 自动完成这些重复性工作。

### 产品经理

产品经理可以利用 AgentLoom 构建用户反馈分析、竞品监控、需求文档生成等自动化流程：

- 自动对用户反馈进行情感分析和主题分类
- 定期收集竞品信息并生成对比报告
- 根据需求描述自动生成 PRD 草稿或用户故事

### 运营人员

日常运营中有大量重复性的内容创作和数据处理工作，AgentLoom 可以大幅减轻这些负担：

- 批量生成社交媒体文案
- 自动化客服回复建议生成
- 数据报表的定期自动生成和分发

### 开发者

开发者可以利用 AgentLoom 在不编写胶水代码的情况下快速组合 AI 能力，也可以通过 HTTP 请求节点、代码执行节点和 MCP 工具节点接入自己的服务：

- 用代码审查工作流自动审查提交的代码
- 搭建文档自动生成流水线
- 创建多 Agent 协作的复杂 AI 应用原型

## 主要能力概述

以下是 AgentLoom 提供的核心能力，每一项在后续文档中都有详细介绍。

### 可视化画布编辑器

基于 DAG（有向无环图）的可视化画布，提供拖拽式的节点编排体验。支持缩放、平移、搜索、撤销/重做等画布操作。左侧节点面板展示所有可用节点类型，右侧属性面板在选中节点后显示配置选项。

### 丰富的节点类型

AgentLoom 提供多种类型的节点来满足不同的编排需求：

| 节点分类 | 包含的节点 | 用途 |
|---------|-----------|------|
| Agent 智能体 | LLM 模型、智能路由、Agent、Skill | AI 推理与智能决策 |
| 工具 | HTTP 请求、代码执行、MCP 工具、沙箱、输入预处理器、工作区 | 与外部系统交互 |
| 触发器 | 手动触发、定时触发、Webhook、API 事件 | 控制工作流的启动方式 |
| 知识与记忆 | 知识库、Memory | 接入私有知识和长期记忆 |
| 输出 | 文本输出、JSON 输出 | 定义工作流的最终结果 |
| 流程控制 | 条件分支、循环、迭代、合并、可复用块 | 控制执行逻辑 |

### 端口与数据类型

每个节点通过"端口"与其他节点连接。端口有明确的数据类型，系统会自动检查连接两端的类型是否兼容，避免不合理的连接。支持的数据类型包括：model（模型）、text（文本）、json（结构化数据）、image（图片）、audio（音频）、tool（工具）、sandbox（沙箱）、knowledge（知识库）、skill（技能）、agent（智能体）。

### 工作流执行引擎

点击运行按钮即可启动工作流。执行引擎会按照 DAG 的拓扑顺序依次运行各个节点，并在界面上实时显示每个节点的运行状态和输出结果。如果某个节点需要人工干预（例如审批 Agent 的工具调用），执行会暂停等待你处理后再继续。

### 版本管理

AgentLoom 提供完整的版本管理能力。你可以在编辑过程中随时保存快照（版本），也可以将当前工作流发布为正式版本。如果发布后发现问题，可以随时回滚到之前的版本。不再需要的工作流可以归档。

### 输入参数

工作流可以定义输入参数，让每次运行时接收不同的数据。支持三种输入收集方式：表单模式（用户填写表单字段）、对话模式（通过对话收集参数）和混合模式（两者结合）。

### 分享与市场

你可以生成只读分享链接，将工作流分享给团队成员或外部用户。也可以将工作流导出为文件或发布到工作流市场，让其他人可以从中学习或直接使用你的方案。

### Agent 独立对话

除了在工作流中使用 Agent，你也可以创建独立的 Agent 进行一对一对话。独立 Agent 拥有自己的记忆系统、沙箱环境和技能配置，适合处理开放式的对话任务。

### 知识库

基于向量检索（RAG）的知识库功能。你可以上传文档到知识库，然后在工作流或 Agent 对话中引用，让 AI 基于你的私有数据进行回答。

### 技能系统

AgentLoom 内置了五个常用技能：代码审查（code-review）、文档生成（documentation）、测试生成（test-generation）、代码重构（refactoring）和调试（debugging）。你也可以创建自定义技能来增强 Agent 的能力。

## AgentLoom 与其他工具的区别

你可能已经使用过其他 AI 工具或平台。以下是 AgentLoom 在一些关键维度上的差异点：

### 与单一 AI 对话工具的区别

像 ChatGPT 或 Claude 这样的对话工具，本质上是"一个 Agent 回答所有问题"。而 AgentLoom 允许你将任务拆解给多个专精 Agent，让它们按照预定义的流程协作，并且可以反复运行。

### 与低代码/无代码平台的区别

传统低代码平台处理的是表单、审批、数据库操作等业务逻辑。AgentLoom 专注于 AI 智能体的编排，核心能力是 LLM 推理、知识检索和 Agent 协作，而非通用的业务流程自动化。

### 与 AI 编排框架的区别

LangChain、LangGraph 等编排框架需要编写代码来构建 AI 管线。AgentLoom 提供了完全可视化的方式来完成相同的工作，同时保留了通过代码节点和 MCP 工具接入自定义逻辑的能力。
