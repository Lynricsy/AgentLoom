# 常见问题（FAQ）

本页汇集了用户在使用 AgentLoom 过程中最常遇到的问题和解答。

## 账户与登录

### 注册时提示"邮箱已被使用"怎么办？

你可能之前已经用这个邮箱注册过。请尝试使用"忘记密码"功能重置密码。如果确认没有注册过，请检查是否有同事使用你的邮箱创建了账号。

### 登录后页面一直显示加载中

这通常是网络连接或会话过期导致的。请尝试以下步骤：
1. 刷新浏览器页面
2. 清除浏览器缓存和 Cookie
3. 尝试使用无痕/隐私模式登录
4. 检查浏览器控制台是否有网络错误

### 如何启用两步验证（MFA）？

进入 **设置** > **安全设置** 页面，在"两步验证"区域点击"启用"。系统支持 TOTP 认证，你需要使用认证器应用（如 Google Authenticator、Authy 等）扫描二维码完成绑定。启用后每次登录都需要输入动态验证码。

### 我的账户角色权限不够，无法执行某些操作

AgentLoom 使用基于角色的权限控制（RBAC），角色从高到低为：owner > admin > creator > operator > viewer。不同角色的操作权限不同，例如：
- **viewer**：只能查看资源，不能创建或修改
- **operator**：可以运行工作流，但不能创建新的
- **creator**：可以创建和编辑工作流、Agent 等资源
- **admin/owner**：拥有组织管理权限

如果需要更高权限，请联系组织的 owner 或 admin 调整你的角色。

### 如何退出当前组织？

目前需要联系组织的 owner 或 admin 将你从组织中移除。

## 工作流编辑

### 两个节点之间无法连线是怎么回事？

AgentLoom 有端口数据类型兼容性检查。每个节点的输入和输出端口都有特定的数据类型（如 text、json、model、sandbox 等）。如果两个端口的类型不兼容，系统会阻止连线。

解决方法：
- 确认源节点的输出端口类型与目标节点的输入端口类型匹配
- 将鼠标悬停在端口上，可以看到端口的数据类型标签
- 如果需要进行类型转换（例如将文本转为 JSON），可以在中间添加相应的处理节点

### 保存工作流时提示"版本冲突"

这是乐观并发控制（OCC）机制在起作用。当你编辑工作流的同时，其他人（或另一个浏览器标签页）也修改并保存了同一个工作流时，就会出现版本冲突。

解决方法：
1. 刷新页面获取最新版本
2. 重新进行你的修改
3. 再次保存

建议在团队协作时，避免同时编辑同一个工作流。

### 画布上的节点太多，操作卡顿怎么办？

对于大型工作流，可以：
- 使用可复用块将常用的节点组合封装起来，减少画布上的节点数量
- 尝试缩小画布缩放比例，减少渲染压力
- 关闭不需要的浏览器标签页，释放内存

### 如何撤销画布上的操作？

使用键盘快捷键 Ctrl+Z（Mac 上是 Cmd+Z）可以撤销最近的操作。Ctrl+Shift+Z（Cmd+Shift+Z）可以重做。

## 工作流执行

### 工作流执行失败，显示"failed"状态

执行失败的原因有很多，请按以下步骤排查：
1. 点击执行记录，查看具体是哪个节点失败
2. 点击失败的节点，查看错误信息
3. 常见原因包括：
   - LLM 模型 API 调用失败（密钥无效、余额不足、服务不可用）
   - 沙箱执行超时
   - 输入数据格式不符合预期
   - 资源配额已用尽

### 工作流执行很慢，一直停在某个节点

可能的原因：
- **Agent 节点**：如果提示词要求 Agent 执行复杂推理或多次工具调用，可能需要较长时间
- **沙箱节点**：代码执行可能比较耗时
- **知识库节点**：首次检索时可能需要加载索引

如果等待时间超出预期，可以点击执行状态栏中的"取消"按钮终止执行。

### 执行结果中的文本输出是空的

请检查：
- 工作流的连线是否完整，确保数据从输入节点一直流到输出节点
- Agent 节点是否已选择已发布的 Agent，以及该 Agent 自身的模型是否正确配置
- 提示词是否清晰地指示了 Agent 需要产出什么内容
- 输入节点是否提供了有效的输入数据

### 如何查看历史执行记录？

在工作流详情页面中，可以查看该工作流的所有执行记录。点击具体的执行记录可以查看详细的执行过程、各节点状态和输出结果。

组织管理员还可以在 **设置** > **运行监控** 中查看组织级别的执行概况。

## Agent 对话

### Agent 对话时没有回复

可能的原因：
- 网络连接中断，Socket.IO 实时通道断开
- LLM 模型服务暂时不可用
- Agent 配置的模型密钥已失效

解决方法：
1. 刷新页面重新连接
2. 检查 Agent 的模型配置是否正确
3. 尝试创建一个新的对话

### Agent 的回答质量不理想

提升 Agent 回答质量的建议：
- **优化提示词**：更明确地描述 Agent 的角色、任务和约束
- **启用相关技能**：在设置中启用适合场景的技能
- **选择更强的模型**：对于复杂任务，选择推理能力更强的模型
- **接入知识库**：在 Agent 配置画布中把知识库绑定到 Agent Main，保存并发布 Agent；工作流引用该 Agent 后会自动使用这项能力

### Agent 记忆是什么？如何使用？

Agent 记忆是一个图拓扑结构的长期记忆系统。Agent 可以在对话过程中将重要信息保存到记忆图谱中，并在后续对话中检索和引用这些记忆。

你可以在 Agent 详情页面的"记忆"标签中查看和管理 Agent 的记忆图谱。记忆管理也支持在移动端操作。

## 知识库

### 文档上传后一直显示"处理中"

文档处理时间取决于文件大小和格式。通常几分钟内会完成。如果超过 10 分钟仍在处理中：
- 确认文档格式是系统支持的类型（TXT、Markdown、PDF 等）
- 确认文档大小没有超过限制
- 尝试重新上传文档

### 知识库检索没有返回相关结果

可能的原因和解决方法：
- **文档内容问题**：确认你的问题确实能在文档中找到答案
- **检索参数过严**：降低相似度阈值，增加 Top K 数量
- **文档未处理完成**：确认文档状态为"已完成"
- **分块效果不佳**：如果文档结构不清晰，可能影响分块质量，建议整理文档格式后重新上传

### 知识库支持哪些文档格式？

目前支持以下格式：
- 纯文本文件（.txt）
- Markdown 文件（.md）
- PDF 文件（.pdf）

## API 与集成

### API 调用返回 401 未授权错误

请确认：
- 你使用的是有效的 API Key（以 `al_` 为前缀）或有效的 JWT Token
- API Key 通过 `X-Api-Key` 请求头传递
- JWT Token 通过 `Authorization: Bearer <token>` 请求头传递
- API Key 没有被撤销

### API 调用返回 429 限流错误

AgentLoom API 默认限流为每分钟 100 次请求。如果你收到 429 错误：
- 检查响应头中的 `Retry-After` 字段，等待指定时间后重试
- 检查响应头中的 `X-RateLimit-*` 字段了解限流详情
- 优化调用频率，避免短时间内发送大量请求
- 联系组织管理员确认是否可以调整 API 限流配置

### Webhook 触发器没有被触发

排查步骤：
1. 确认工作流已发布（只有已发布的工作流才能被 Webhook 触发）
2. 确认 Webhook URL 配置正确
3. 如果启用了签名验证，确认签名计算方式正确（HMAC-SHA256）
4. 检查外部系统的 Webhook 发送记录，确认请求是否成功发出
5. 确认工作流的触发器节点配置正确

### 如何生成和管理 API Key？

进入 **设置** > **API 密钥管理** 页面。点击"创建 API Key"按钮，为新密钥设置名称。创建成功后，系统会显示完整的 API Key（以 `al_` 为前缀），请立即复制并安全保存，因为之后无法再次查看完整密钥。

## 沙箱环境

### 沙箱执行超时

Agent 在沙箱中的操作有时间限制。如果任务复杂需要更长时间：
- 检查沙箱节点的超时配置，适当增加超时时长
- 优化 Agent 的提示词，让它更高效地完成任务
- 将复杂任务拆分为多个步骤

### 沙箱中的文件在执行结束后还能查看吗？

如果工作流或对话创建了 workspace 快照，你可以在 **资源** > **工作区** 中找到对应的快照，并浏览其中的文件目录和内容。如果没有创建快照，沙箱中的文件会在沙箱会话结束后销毁。

## 移动端

### 移动端支持哪些功能？

AgentLoom 移动端（Flutter 应用）目前支持：
- Agent 对话：与 Studio 对称的聊天界面
- 记忆管理：查看和管理 Agent 的记忆图谱
- 技能管理：查看和编辑技能的基本信息（名称和描述）
- 账户设置：OAuth 登录、MFA 管理、密码修改

工作流编辑和执行监控等功能目前仅在 Studio（Web 端）提供。

### 移动端无法连接到服务

请确认：
- 你的设备网络连接正常
- 应用中配置的服务器地址正确
- 如果使用了 VPN 或代理，确保它们没有阻断连接
- 尝试退出登录后重新登录

## 其他问题

### 如何切换界面语言？

AgentLoom 目前支持中文界面。英文文档正在翻译中。

### 支持哪些浏览器？

推荐使用最新版本的 Chrome、Firefox、Safari 或 Edge 浏览器。不建议使用 Internet Explorer。

### 数据安全性如何保障？

AgentLoom 采用多层安全措施：
- 多租户架构确保组织间的数据隔离
- 端到端加密（E2EE）保护敏感数据
- 基于角色的权限控制（RBAC）
- API 请求签名验证
- 审计日志记录所有关键操作

如果你的问题在本页面中没有找到答案，请查看 [错误参考](./errors) 页面，或联系技术支持获取帮助。
