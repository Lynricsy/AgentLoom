# 移动端功能

本页详细介绍 AgentLoom 移动端应用的各项功能和使用方法。

## Agent 对话

Agent 对话是移动端的核心功能。你可以随时随地与 Agent 进行多轮对话，就像在 Studio 中一样。

### 发起新对话

1. 在底部导航栏点击 **Agent** 标签
2. 在 Agent 列表中找到你想对话的 Agent
3. 点击 Agent 卡片进入对话界面
4. 在底部输入框中输入你的消息
5. 点击发送按钮，等待 Agent 回复

### 继续已有对话

1. 进入 Agent 对话界面
2. 系统会自动加载该 Agent 的对话历史
3. 你可以在历史消息列表中查看之前的对话内容
4. 直接在输入框中继续对话

### 对话特性

- **实时推送**：Agent 的回复通过 Socket.IO 实时推送，无需手动刷新
- **消息历史**：完整保留对话历史，随时可以回溯查看
- **多 Agent 支持**：可以同时与多个不同的 Agent 维持独立的对话
- **跨端同步**：在移动端发起的对话，也可以在 Studio 中继续（反之亦然）

### 对话中的交互

在对话过程中，你可以：

- 查看 Agent 的思考过程和工具调用详情
- 如果 Agent 请求权限确认，会弹出权限确认对话框
- 长按消息可以复制文本内容
- 向上滑动加载更早的消息记录

::: tip 对话质量
移动端的 Agent 对话与 Studio 使用完全相同的后端服务和模型配置。如果你发现对话质量不符合预期，请在 Studio 中检查 Agent 的模型和提示词配置。
:::

## 记忆管理

Agent 记忆系统让 Agent 能够跨对话保留重要信息。移动端提供了完整的记忆管理功能。

### 查看记忆图谱

1. 进入某个 Agent 的详情页
2. 切换到"记忆"标签
3. 你将看到 Agent 的记忆图谱可视化视图

记忆图谱以节点和连线的形式展示 Agent 存储的信息：
- **节点**：每个节点代表一条记忆片段
- **连线**：连线表示记忆之间的关联关系
- **节点大小**：反映记忆的重要程度

### 记忆详情

点击图谱中的某个记忆节点，可以查看详细信息：

- 记忆内容：Agent 记住的具体信息
- 创建时间：这条记忆是何时产生的
- 关联上下文：这条记忆在哪次对话中产生
- 关联记忆：与这条记忆相关的其他记忆

### 管理记忆

在记忆管理界面，你可以：

- **浏览记忆列表**：以列表形式查看所有记忆条目
- **搜索记忆**：通过关键词搜索特定的记忆内容
- **查看记忆详情**：点击查看某条记忆的完整信息
- **删除记忆**：移除不再需要的记忆条目

::: warning 注意
删除记忆是不可逆的操作。删除后，Agent 在后续对话中将不再能够检索到该条记忆。
:::

### 记忆的工作原理

Agent 在对话过程中会自动识别重要信息并存储为记忆。例如：

- 用户提供的个人偏好
- 项目的关键技术决策
- 对话中达成的共识
- 重要的上下文信息

在后续对话中，Agent 会自动检索相关记忆，将其作为上下文参考来生成更有针对性的回答。

## 技能管理

技能是 Agent 的行为指导文件。移动端支持查看和编辑技能的基本信息。

### 浏览技能列表

1. 在设置或资源入口中找到"技能"管理页面
2. 技能列表展示了所有可用的技能，包括内置技能和自定义技能
3. 内置技能会标记特殊标签，表明是系统预置的

### 查看技能详情

点击某个技能可以查看：
- **名称**：技能的显示名称
- **描述**：技能的功能说明
- **状态**：当前是启用还是禁用
- **类型**：内置技能或自定义技能

### 编辑技能信息

在移动端，你可以编辑技能的以下基本信息：
- **名称**：修改技能的显示名称
- **描述**：更新技能的功能描述

::: tip 完整编辑
如果需要编辑技能的 SKILL.md 内容（即技能的详细行为指导），请在 Studio（Web 端）中使用 Monaco 编辑器进行操作。移动端仅支持名称和描述的编辑。
:::

### 内置技能列表

AgentLoom 预置了以下内置技能：

| 技能 | 用途 |
|------|------|
| code-review | 代码审查，关注代码质量、安全漏洞和最佳实践 |
| documentation | 文档生成，包括 API 文档、README 和技术规范 |
| test-generation | 测试生成，创建单元测试、集成测试和端到端测试 |
| refactoring | 代码重构，分析结构问题并提出改进方案 |
| debugging | 调试分析，系统化地分析错误和定位根因 |
| self-evolution | 自我演化，Agent 能力的持续优化和学习 |

## 账户与安全设置

### 修改密码

1. 进入 **设置** 页面
2. 点击"安全设置"
3. 选择"修改密码"
4. 输入当前密码和新密码
5. 确认修改

### 管理 MFA

在安全设置中，你可以：

- **启用 MFA**：绑定一个 TOTP 认证器（如 Google Authenticator）
- **验证 MFA**：测试当前绑定的认证器是否正常工作
- **查看 MFA 状态**：确认 MFA 是否已启用

### 会话管理

在安全设置中查看所有活跃的登录会话：

- 查看各会话的设备类型和登录时间
- 终止不再需要的会话
- 确认没有未授权的登录

## 通知

移动端可以接收以下类型的平台通知：

| 通知类型 | 说明 |
|----------|------|
| 执行完成 | 工作流执行成功完成 |
| 执行失败 | 工作流执行失败，需要关注 |
| 需要介入 | 工作流执行中有节点需要人工审批 |

通知通过应用内推送和 Socket.IO 实时通道送达。你可以在设置中配置通知偏好：

- 选择接收哪些类型的通知
- 设置是否启用推送通知
- 配置邮件通知偏好

## 离线与网络

### 网络状态指示

应用界面会显示当前的网络连接状态。当网络断开时，部分功能将不可用。

### 自动重连

当网络连接中断后恢复时，应用会自动：
- 重新建立 Socket.IO 连接
- 同步对话消息
- 恢复通知推送

### 离线限制

以下功能需要网络连接才能使用：
- Agent 对话（需要实时连接后端服务和 LLM 模型）
- 记忆管理（需要与服务端同步）
- 技能编辑（需要保存到服务端）

## 常见操作速查

| 管理技能 | 设置 > 技能管理 |
| 修改密码 | 设置 > 安全设置 > 修改密码 |
| 管理 MFA | 设置 > 安全设置 > 两步验证 |
| 查看通知 | 通知入口 |
| 切换组织 | 设置 > 账户 > 组织 |
