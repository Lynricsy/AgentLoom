# 移动端入门

AgentLoom 提供了跨平台移动端应用，让你随时随地与 Agent 对话、管理记忆和技能。本页介绍如何下载安装、登录以及移动端界面的基本布局。

## 下载安装

AgentLoom 移动端基于 Flutter 构建，支持 iOS 和 Android 两大平台。

### iOS

1. 打开 App Store
2. 搜索"AgentLoom"
3. 点击"获取"下载安装

### Android

1. 打开 Google Play 商店
2. 搜索"AgentLoom"
3. 点击"安装"

::: tip 版本要求
- iOS：需要 iOS 15.0 或更高版本
- Android：需要 Android 8.0（API 26）或更高版本
:::

## 登录认证

移动端支持多种登录方式，与 Studio（Web 端）使用同一套账户体系。

### 邮箱密码登录

1. 打开应用，进入登录页面
2. 输入你在 AgentLoom 平台注册时使用的邮箱和密码
3. 点击"登录"

### OAuth 社交账号登录

移动端支持以下社交账号快捷登录：

- **Google 账号登录**：点击"使用 Google 登录"按钮，系统会跳转到 Google 认证页面完成授权
- **GitHub 账号登录**：点击"使用 GitHub 登录"按钮，系统会跳转到 GitHub 认证页面完成授权

OAuth 登录使用系统浏览器进行授权跳转，授权完成后会自动返回应用。

### 两步验证（MFA）

如果你的账户启用了两步验证（MFA），登录时还需要完成额外的验证步骤：

1. 输入邮箱和密码后，系统会提示输入验证码
2. 打开你的认证器应用（如 Google Authenticator）
3. 输入当前显示的 6 位动态验证码
4. 点击"验证"完成登录

移动端也支持在设置中启用或管理 MFA：
- 注册新的 TOTP 认证器
- 验证认证器绑定状态

## 界面概览

登录成功后，你将看到移动端的主界面。底部导航栏提供了主要功能入口。

### 底部导航

移动端的底部导航栏包含以下主要入口：

| 标签 | 功能 | 说明 |
|------|------|------|
| Agent | Agent 列表与对话 | 查看所有 Agent，发起或继续对话 |
| 工作流 | 工作流管理 | 查看工作流列表和执行记录 |
| 仪表板 | 数据概览 | 查看使用统计和概况 |
| 资源 | 资源管理 | 管理知识库等资源 |
| 设置 | 个人设置 | 账户、安全和偏好设置 |

### Agent 列表

Agent 标签是移动端的核心入口。在这里你可以：

- 浏览你组织中的所有 Agent
- 快速搜索特定的 Agent
- 点击 Agent 卡片进入对话界面
- 查看 Agent 的基本信息和状态

### 对话界面

点击某个 Agent 后进入对话界面，这是一个与 Studio 对称的聊天界面：

- 顶部显示 Agent 名称和状态
- 中间区域是消息列表，展示对话历史
- 底部是输入框，可以输入消息发送给 Agent
- Agent 的回复会实时推送并显示在消息列表中

对话通过 Socket.IO 实时通道传输，与 Studio 中的 Agent 对话体验保持一致。

### 设置页面

设置页面包含以下选项：

- **账户信息**：查看和编辑个人资料
- **安全设置**：修改密码、管理 MFA
- **会话管理**：查看和管理活跃的登录会话
- **通知偏好**：设置通知接收方式
- **关于**：查看应用版本信息

## 与 Studio 的功能对比

移动端专注于随时随地的 Agent 交互和轻量管理场景，部分高级功能仅在 Studio（Web 端）提供：

| 功能 | 移动端 | Studio（Web 端） |
|------|--------|------------------|
| Agent 对话 | 支持 | 支持 |
| Agent 记忆管理 | 支持 | 支持 |
| 技能管理 | 支持（基本信息编辑） | 支持（含 SKILL.md 编辑） |
| 工作流编辑 | 不支持 | 支持 |
| 工作流执行监控 | 查看记录 | 完整监控 |
| 画布编辑器 | 不支持 | 支持 |
| 知识库管理 | 查看 | 完整管理 |
| 组织管理 | 基本查看 | 完整管理 |
| API Key 管理 | 不支持 | 支持 |
| 审计日志 | 不支持 | 支持 |
| 资源配额管理 | 不支持 | 支持 |

## 网络要求

移动端需要稳定的网络连接才能正常使用：

- Agent 对话需要 Socket.IO 实时连接
- 应用默认连接到 `https://agentloom.ling.plus/` 后端服务
- 如果网络中断，应用会自动尝试重连
- OAuth 登录需要能够访问 Google 或 GitHub 的认证服务
