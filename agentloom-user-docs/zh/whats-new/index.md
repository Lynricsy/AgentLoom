# 更新日志

了解 AgentLoom 的最新功能、改进和修复。

---

## v1.2.0

*2026 年 3 月*

### 新功能

**Agent 记忆系统**

Agent 现在拥有长期记忆能力。通过图拓扑结构的记忆存储，Agent 能够在多轮对话中记住重要信息，并在后续对话中自动检索和引用这些记忆。

- 记忆图谱可视化：在 Agent 详情页查看记忆的网络结构
- 实时记忆操作：通过 Socket.IO 实时更新记忆图谱
- 移动端支持：在移动端也可以查看和管理 Agent 记忆

**多 Agent 共享沙箱**

工作流中的多个 Agent 节点现在可以共享同一个沙箱环境。前一个 Agent 写入的文件，后一个 Agent 可以直接读取，实现真正的协作式工作流。

- 一个沙箱节点可同时服务多个下游 Agent
- 支持 persistent 模式的沙箱生命周期管理
- 沙箱会话在工作流执行和 Agent 对话间复用

**资源治理仪表板**

组织管理员现在可以通过运行监控仪表板实时了解平台的运行状况。

- 支持 15 分钟、1 小时、24 小时三个时间窗口
- 展示执行趋势、队列快照和告警热点
- 直接从仪表板跳转到相关的配额管理和审计日志页面

### 改进

- **智能路由**：FALLBACK_CHAIN 策略现在支持非认证失败时自动切换模型重试，提升了工作流的稳定性
- **执行性能**：Socket.IO 事件推送增加了背压控制（500 容量队列，100ms 排空周期），减少了大量并发执行时的内存压力
- **断线续传**：客户端断线后重连时，可通过 lastEventId 从断点恢复事件流，不再丢失执行过程中的事件
- **工作流输入**：输入参数现在支持表单（form）、对话（conversation）和混合（hybrid）三种收集模式

### 修复

- 修复了工作流保存时偶发的版本冲突误报问题
- 修复了知识库文档处理在特殊 PDF 格式下卡住的问题
- 修复了移动端 Agent 对话在网络切换后无法自动重连的问题
- 修复了触发器配置中 Cron 表达式验证过于严格的问题

## v1.1.0

*2026 年 2 月*

### 新功能

**技能系统**

引入了技能系统，让 Agent 可以获得专业能力指导。技能采用 SKILL.md 格式（YAML frontmatter + Markdown 正文），通过系统提示注入的方式影响 Agent 的行为。

- 6 个内置技能：code-review、documentation、test-generation、refactoring、debugging、self-evolution
- 技能管理页面：在设置中管理技能的启停状态
- 画布技能节点：在工作流中为 Agent 注入指定技能

**审计日志**

组织管理员现在可以查看完整的操作审计日志，追踪组织内所有关键操作。

- append-only 双表架构（热表 + 归档表）确保日志不可篡改
- 按资源类型和资源 ID 查看事件序列
- 支持时间范围筛选和分页查询
- 自动归档策略，定期将历史日志转移到归档表

**插件市场**

支持工作流和插件的市场交易。开发者可以将工作流上架到市场，其他用户可以浏览、搜索和安装。

- 支持工作流和 WASM 插件两种类型
- 支持免费和按次计费两种定价模式
- 插件使用 RSA-PSS 签名验证，确保安全性

### 改进

- **Agent 对话**：新增 Socket.IO 实时通道，对话响应延迟降低 40%
- **知识库检索**：优化了向量检索算法，相关性评分更准确
- **工作流导出**：导出文件增加了敏感信息脱敏处理
- **API Key**：新增 API Key 管理界面，支持创建、查看和撤销

### 修复

- 修复了条件分支节点在多条件分支时评估顺序不确定的问题
- 修复了大型工作流导入时内存溢出的问题
- 修复了 Webhook 触发器在高并发下偶发的重复触发问题
- 修复了 Studio 画布在 Firefox 浏览器中的拖拽偏移问题

## v1.0.0

*2026 年 1 月*

### 新功能

AgentLoom v1.0.0 是平台的首个正式版本，包含以下核心功能：

**可视化工作流编排**

- 拖拽式画布编辑器
- 14 种内置节点类型（AI 推理、输入输出、逻辑控制、工具集成、知识技能）
- DAG 拓扑调度器，支持并行执行和依赖管理
- 工作流版本管理和发布机制
- 工作流分享和导出/导入

**独立 Agent 体系**

- Agent 定义和版本管理
- 多轮对话界面
- 代码沙箱集成
- Agent 节点桥接（可在工作流中使用独立 Agent）

**知识库 RAG**

- 文档上传和智能分块
- Qdrant 向量检索引擎
- 可配置的检索参数（Top K、相似度阈值）

**触发器自动化**

- Cron 定时触发
- Webhook 触发（支持 HMAC-SHA256 签名验证）
- API 事件触发（支持 GitHub Webhook 适配器）

**多租户与安全**

- 基于角色的权限控制（owner / admin / creator / operator / viewer）
- 端到端加密（E2EE）
- API Key 认证（`al_` 前缀 + SHA-256 hash）
- 100 req/min 默认限流

**平台 API**

- RESTful API（/api/v1/ 前缀）
- 双重认证（JWT + API Key）
- OpenAPI 3.0 规范
- TypeScript 和 Python SDK 生成支持

**移动端应用**

- Flutter 跨平台应用
- Agent 对话功能
- OAuth 登录（Google / GitHub）
- MFA TOTP 支持

### 已知限制

- 工作流编辑暂不支持多人实时协同编辑
- 移动端暂不支持工作流编辑和执行监控
- 单个 workspace 归档文件限制为 50MB
- 文本文件预览限制为 10MB
