# 用例教程

欢迎来到 AgentLoom 用例教程。在这里，我们精心准备了多个真实场景的完整教程，帮助你快速掌握平台的核心功能，并将它们应用到实际工作中。

## 为什么要看用例教程

每个用例教程都提供了从零开始的端到端操作步骤。你不需要提前掌握所有功能，只需要跟着教程一步一步做，就能在实践中理解工作流编排、Agent 配置、知识库接入等核心能力。

## 教程分类

### 客户服务

| 教程 | 难度 | 核心功能 | 预计时间 |
|------|------|----------|----------|
| [构建智能客服机器人](./customer-support) | 入门 | 知识库 + Agent + 工作流 + Webhook | 30 分钟 |

这个教程适合刚接触 AgentLoom 的用户。你将学会如何上传 FAQ 文档到知识库，创建具有客服角色的 Agent，并通过工作流将各个环节串联起来。最终配置 Webhook 触发器，让外部系统可以自动调用你的客服机器人。

### 文档处理

| 教程 | 难度 | 核心功能 | 预计时间 |
|------|------|----------|----------|
| [RAG 文档智能分析](./document-analysis) | 入门 | 知识库 RAG + JSON 输出 + 检索配置 | 25 分钟 |

这个教程展示如何利用知识库的 RAG（检索增强生成）能力，对大量文档进行智能分析和结构化输出。你将学会配置检索参数、处理分析结果，并以 JSON 格式输出结构化数据。

### 开发流程

| 教程 | 难度 | 核心功能 | 预计时间 |
|------|------|----------|----------|
| [自动化代码审查](./code-review) | 中级 | Agent + 沙箱 + 技能 + GitHub Webhook | 40 分钟 |

面向有开发背景的用户。你将创建一个具有代码审查技能的 Agent，为它配置沙箱环境，并连接 GitHub Webhook，实现 PR 提交后自动进行代码审查。

### 高级场景

| 教程 | 难度 | 核心功能 | 预计时间 |
|------|------|----------|----------|
| [多 Agent 协作管线](./multi-agent) | 高级 | 多 Agent 节点 + 共享沙箱 + 智能路由 | 50 分钟 |

这个教程展示 AgentLoom 最强大的能力之一：多个 Agent 协同工作。你将构建一个产品需求分析管线，让需求分析、技术方案、代码生成三个 Agent 依次协作，共享同一个沙箱环境。

## 如何使用教程

1. **按顺序学习**：如果你是新手，建议从"构建智能客服机器人"开始，它覆盖了最基础的功能。

2. **准备工作**：每个教程开头会列出前置条件。请确保你已经完成注册、登录，并拥有至少一个可用的组织工作区。

3. **跟着操作**：教程中的每一步都配有详细说明。打开 AgentLoom Studio，一边阅读教程一边操作。

4. **尝试变化**：完成教程后，试着修改配置参数或替换不同的模型，观察结果的变化。这是加深理解的好方法。

## 常见前置条件

在开始任何教程之前，请确保：

- 你已经注册并登录 AgentLoom 平台
- 你的账户属于至少一个组织
- 你拥有 creator 或以上的角色权限（owner、admin、creator）
- 你的组织已经配置了至少一个 LLM 模型提供商

如果在教程过程中遇到问题，可以参考[故障排查](../troubleshooting/)或[常见问题](../troubleshooting/faq)页面。
