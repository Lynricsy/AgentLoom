# RAG 文档智能分析

本教程将带你使用 AgentLoom 的知识库 RAG（检索增强生成）能力，构建一个能够智能分析文档并输出结构化结果的工作流。

## 你将学到什么

- 上传多份文档到知识库并配置检索参数
- 创建使用 JSON 输出的分析工作流
- 配置知识库检索的高级参数
- 运行分析并获取结构化 JSON 结果
- 理解 RAG 检索的工作原理

## 前置条件

- 已注册并登录 AgentLoom 平台
- 拥有 creator 或以上角色权限
- 组织已配置至少一个 LLM 模型提供商
- 准备好一组待分析的文档（合同、报告、技术文档等均可）

## 场景说明

假设你是一家公司的运营人员，需要定期分析大量产品反馈报告，提取关键信息并生成结构化的分析摘要。手动阅读每份报告耗时耗力，我们将用 AgentLoom 自动化这个过程。

## 第一步：创建知识库并上传文档

1. 进入 **资源** > **知识库**，点击 **创建知识库**。

2. 填写信息：
   - **名称**：产品反馈文档库
   - **描述**：存储各渠道收集的产品反馈报告

3. 创建完成后，进入知识库详情页。

4. 点击 **上传文档**，选择你的反馈报告文件并上传。你可以一次性上传多个文件。

5. 等待所有文档处理完成。系统会自动对每份文档进行：
   - **文档解析**：提取文本内容
   - **智能分块**：将长文档拆分为合适大小的段落
   - **向量索引**：将每个段落转换为向量，建立检索索引

::: tip 文档处理时间
处理时间取决于文档的数量和大小。通常每份文档需要几秒到几十秒不等。你可以在文档列表中查看每份文档的处理状态。
:::

## 第二步：创建文档分析 Agent

1. 进入 **Agent** 页面，点击 **创建 Agent**。

2. 填写基本信息：
   - **名称**：文档分析助手
   - **描述**：基于知识库内容生成结构化的产品反馈分析

3. 选择适合文档分析的模型，并设置系统提示词：

   ```
   你是一个专业的数据分析师。你的任务是基于提供的文档内容进行深入分析。

   分析要求：
   1. 仔细阅读所有检索到的文档片段
   2. 识别其中的关键信息、模式和趋势
   3. 将分析结果组织为结构化的 JSON 格式

   输出格式要求（JSON）：
   {
     "summary": "简要的一句话总结",
     "keyFindings": ["发现1", "发现2", ...],
     "categories": {
       "分类名": {
         "count": 提及次数,
         "details": "详细描述"
       }
     },
     "sentiment": "positive/neutral/negative",
     "recommendations": ["建议1", "建议2", ...]
   }

   请严格按照上述 JSON 格式输出，不要包含其他文字。
   ```

4. 保存并发布 Agent。只有已发布的 Agent 才能在工作流中选择。

## 第三步：创建分析工作流

1. 进入 **工作流** 页面，点击 **创建工作流**。

2. 输入名称"产品反馈智能分析"，进入画布编辑器。

3. **添加文本输入节点**：
   - 拖拽一个 **文本输入** 节点到画布
   - 配置变量名为 `analysisQuery`
   - 这个节点用来输入你的分析指令，比如"请分析近期用户反馈中提到的主要问题"

4. **添加知识库节点**：
   - 拖拽一个 **知识库** 节点到画布
   - 在配置面板中选择"产品反馈文档库"
   - 配置检索参数（详见下一步）
   - 连接：文本输入节点的「文本」输出 --> 知识库节点的输入

5. **添加 Agent 节点**：
   - 拖拽一个 **Agent** 节点到画布
   - 在配置面板中选择第二步发布的"文档分析助手"
   - 连接：知识库节点的输出 --> Agent 节点的「上下文」输入，文本输入节点的「文本」输出 --> Agent 节点的「文本」输入

6. **添加 JSON 输出节点**：
   - 拖拽一个 **JSON 输出** 节点到画布
   - 连接：Agent 节点的「结构化」输出 --> JSON 输出节点的输入

7. 最终工作流结构：

   ```
   文本输入 --+--> 知识库 --(上下文)--> Agent --> JSON 输出
              |
              +--------------(文本)---->
   ```

8. 保存工作流。

## 第四步：配置检索参数

知识库的检索参数直接影响分析质量。点击知识库节点，在配置面板中调整以下参数：

### 检索数量（Top K）

这个参数决定每次检索返回多少个相关文档片段。

- **推荐值**：5-10 条
- **场景建议**：
  - 如果文档数量少（10 份以下），设为 3-5
  - 如果文档数量多（数十份），设为 8-10
  - 过多会引入不相关内容，过少可能遗漏重要信息

### 相似度阈值

控制返回结果的最低相关度。

- **推荐值**：0.7（范围 0-1）
- **场景建议**：
  - 希望结果更精准：提高到 0.8
  - 希望覆盖更全面：降低到 0.6
  - 不设阈值：设为 0，返回所有 Top K 结果

::: tip 调优建议
检索参数没有万能的最佳值，需要根据实际数据和分析目标反复调试。建议先用默认值测试，然后根据结果逐步调整。
:::

## 第五步：运行分析

1. 点击画布工具栏中的 **运行** 按钮。

2. 在输入面板中，输入分析指令，例如：

   ```
   请分析文档中用户反馈的主要问题，按问题类型分类，评估整体情绪倾向，并给出改进建议。
   ```

3. 点击 **开始执行**。

4. 观察执行过程：
   - 文本输入节点：接收分析指令
   - 知识库节点：从文档库中检索相关段落
   - Agent 节点：基于检索结果进行分析推理
   - JSON 输出节点：输出结构化分析结果

5. 执行完成后，点击 JSON 输出节点查看结果。

## 第六步：查看与使用分析结果

JSON 输出节点会展示结构化的分析结果。一个典型的输出示例：

```json
{
  "summary": "用户反馈整体偏正面，但在性能和文档方面存在改进空间",
  "keyFindings": [
    "80% 的用户对核心功能表示满意",
    "性能问题是最常被提及的改进需求",
    "新用户普遍反映入门文档不够清晰"
  ],
  "categories": {
    "功能体验": {
      "count": 45,
      "details": "用户对可视化编辑器和节点连接体验评价较高"
    },
    "性能问题": {
      "count": 23,
      "details": "主要集中在大型工作流的加载速度和执行延迟"
    },
    "文档质量": {
      "count": 18,
      "details": "新用户反映教程不够完整，缺少视频指导"
    }
  },
  "sentiment": "positive",
  "recommendations": [
    "优先优化大型工作流的加载和执行性能",
    "完善新用户入门教程，增加视频内容",
    "建立用户反馈的定期跟踪机制"
  ]
}
```

### 使用分析结果

你可以将这个工作流的结果用于：

- **定期报告**：配合定时触发器，自动生成周报/月报
- **下游处理**：将 JSON 输出连接到其他工作流节点进行进一步处理
- **API 集成**：通过 API 触发工作流，将结果集成到你的内部系统中

## 进阶：配合定时触发自动分析

如果你需要定期自动执行分析，可以添加一个定时触发器：

1. 在画布中添加一个 **触发器** 节点。

2. 选择触发类型为 **定时触发（Cron）**。

3. 设置 Cron 表达式，例如每周一早上 9 点执行：`0 9 * * 1`

4. 将触发器节点连接到文本输入节点。

5. 在文本输入节点中设置默认的分析指令。

6. 保存并发布工作流。

## 完成

你已经成功构建了一个 RAG 文档智能分析工作流。关键要点回顾：

- 知识库通过向量检索为 Agent 提供相关文档内容
- 检索参数（Top K 和相似度阈值）需要根据实际数据调优
- JSON 输出节点可以让 Agent 生成结构化数据，便于下游处理
- 配合触发器可以实现定期自动分析
