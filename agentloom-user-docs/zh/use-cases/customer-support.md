# 构建智能客服机器人

本教程将带你从零开始构建一个智能客服机器人。它能够基于你的 FAQ 文档自动回答用户问题，并通过 Webhook 接入外部客服系统。

## 你将学到什么

- 创建知识库并上传 FAQ 文档
- 创建具有客服角色的 Agent
- 搭建包含知识库检索的工作流
- 配置 Webhook 触发器实现外部系统接入
- 测试完整的客服问答流程

## 前置条件

- 已注册并登录 AgentLoom 平台
- 拥有 creator 或以上角色权限
- 组织已配置至少一个 LLM 模型提供商
- 准备好一份 FAQ 文档（TXT、Markdown 或 PDF 格式均可）

## 第一步：创建知识库

知识库是客服机器人的"大脑"。我们先把 FAQ 文档上传到知识库中，让 Agent 能够从中检索信息。

1. 在左侧导航栏中，点击 **资源** 进入资源管理页面。

2. 选择 **知识库** 分类，点击右上角的 **创建知识库** 按钮。

3. 在弹出的创建对话框中，填写以下信息：
   - **名称**：输入一个容易识别的名称，比如"产品 FAQ 知识库"
   - **描述**：简要说明这个知识库的用途，比如"存储产品常见问题与解答"

4. 点击 **创建** 完成知识库的创建。

5. 进入刚创建的知识库详情页，点击 **上传文档** 按钮。

6. 选择你准备好的 FAQ 文档并上传。系统会自动对文档进行分块处理和向量化索引。

7. 等待文档处理完成。处理状态会从"处理中"变为"已完成"。

::: tip 文档格式建议
建议 FAQ 文档使用清晰的问答格式，每个问题和回答之间有明确的分隔。Markdown 格式效果最好，因为标题层级可以帮助系统更好地分块。
:::

## 第二步：创建客服 Agent

接下来创建一个专门用于客服场景的 Agent。

1. 在左侧导航栏中，点击 **Agent**，进入 Agent 管理页面。

2. 点击右上角的 **创建 Agent** 按钮。

3. 填写基本信息：
   - **名称**：客服助手
   - **描述**：基于知识库回答用户产品相关问题的智能客服

4. 在 Agent 配置区域，设置系统提示词。以下是一个推荐的客服提示词模板：

   ```
   你是一个专业的客服助手。你的职责是：
   1. 根据知识库中的信息，准确回答用户的问题
   2. 如果知识库中没有相关信息，诚实地告知用户你无法回答，并建议联系人工客服
   3. 回答时保持礼貌、简洁、专业的语气
   4. 不要编造不存在的信息
   5. 如果用户的问题不清楚，主动询问以明确需求
   ```

5. 在 Agent 配置画布中添加知识库节点，选择第一步创建的「产品 FAQ 知识库」，并将其「知识库」输出连接到 Agent Main 的「知识库」输入端口。

6. 点击 **保存并发布** 完成 Agent 创建。只有已发布的 Agent 才能在工作流中选择，知识库绑定会随 Agent 定义一起生效。

## 第三步：创建客服工作流

现在使用已绑定知识库的 Agent 构建工作流。工作流画布中不需要添加知识库节点。

1. 在左侧导航栏中，点击 **工作流**，然后点击 **创建工作流**。

2. 输入工作流名称，比如"智能客服问答流程"，然后进入画布编辑器。

3. **添加文本输入节点**：
   - 从左侧节点面板拖拽一个 **文本输入** 节点到画布上
   - 这个节点用来接收用户的问题
   - 点击节点，在右侧配置面板中设置变量名为 `userQuestion`

4. **添加 Agent 节点**：
   - 拖拽一个 **Agent** 节点到画布上
   - 在配置面板中选择第二步发布的「客服助手」
   - 将文本输入节点的「文本」输出连接到 Agent 节点的「文本」输入端口

5. **添加文本输出节点**：
   - 拖拽一个 **文本输出** 节点到画布上
   - 将 Agent 节点的「回复」输出连接到文本输出节点的「文本」输入端口

6. 完成后，你的工作流应该呈现如下结构：

   ```text
   文本输入「文本」 --> Agent「文本」；Agent「回复」 --> 文本输出「文本」
   ```

   两条数据连线均为 `text` 类型。知识库由「客服助手」的 Agent 配置提供，不在工作流画布中重复连接。

7. 点击工具栏中的 **保存** 按钮保存工作流。

## 第四步：测试工作流

在添加触发器之前，先手动测试一下工作流是否正常工作。

1. 点击画布工具栏中的 **运行** 按钮。

2. 在弹出的输入面板中，输入一个测试问题，比如："你们的退货政策是什么？"

3. 点击 **开始执行**，观察执行过程。

4. 工作流状态栏会依次显示文本输入、Agent 和文本输出节点的执行状态。当所有节点执行完成后，状态变为「已完成」。

5. 点击文本输出节点，查看 Agent 的回答。验证回答是否基于知识库内容生成。

6. 多测试几个不同的问题，确保回答质量符合预期。如果回答不理想，可以回到第二步调整提示词，或者回到第一步补充知识库文档。

::: warning 注意
如果测试时 Agent 的回答没有使用知识库内容，请检查：目标知识库的文档是否已处理完成、知识库是否已连接到「客服助手」配置画布中 Agent Main 的「知识库」端口，以及工作流是否选择了包含该绑定的已发布 Agent 版本。
:::

## 第五步：配置 Webhook 触发器

工作流测试通过后，我们添加 Webhook 触发器，让外部系统可以自动调用这个客服工作流。

1. 在画布中，拖拽一个 **触发器** 节点到画布上。

2. 在配置面板中，选择触发类型为 **Webhook**。

3. 系统会自动生成一个 Webhook URL 和安全密钥（Secret）。请妥善保存这两个值。

4. 配置 Webhook 参数：
   - **认证模式**：推荐选择"签名验证"（signed），这样外部系统调用时需要提供签名
   - **Secret**：系统自动生成的密钥，用于签名验证

5. 将触发器的 `exec` 输出连接到文本输入节点的 `exec` 输入；Webhook 请求体中的 `userQuestion` 参数会由同名工作流输入参数提供给文本节点。

6. 保存工作流，然后点击 **发布** 使工作流生效。

## 第六步：接入外部系统

拿到 Webhook URL 后，你可以将它接入到任何支持 HTTP 请求的外部系统中。

以一个简单的调用为例，外部系统需要向 Webhook URL 发送 POST 请求，请求体中包含用户的问题：

```json
{
  "userQuestion": "你们支持哪些付款方式？"
}
```

如果启用了签名验证，还需要在请求头中包含签名信息。签名使用 HMAC-SHA256 算法，以 Webhook Secret 为密钥对请求体计算签名值。

系统收到请求后，会自动触发工作流执行，经过知识库检索和 Agent 推理后，返回客服回答。

## 完成

恭喜你完成了智能客服机器人的搭建。现在你拥有了一个能够：

- 从知识库中检索相关信息
- 基于检索结果智能生成回答
- 通过 Webhook 接收外部系统的请求
- 自动完成问答流程

### 进阶建议

- **丰富知识库**：持续上传更多文档到知识库，提升回答覆盖率
- **调优检索参数**：在知识库节点中调整检索数量和相似度阈值，平衡召回率和精确度
- **多轮对话**：如果需要支持多轮对话，考虑使用独立 Agent 的对话模式替代单次工作流执行
- **添加条件分支**：使用条件分支节点，根据问题类型路由到不同的处理分支
- **监控执行**：在设置页面查看工作流执行记录和监控仪表板，了解客服机器人的运行状况
