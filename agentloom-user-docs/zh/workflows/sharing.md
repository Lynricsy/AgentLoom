# 分享与导出

AgentLoom 提供了多种方式来分享你的工作流 -- 从生成只读链接到导出文件，再到发布到社区市场。本页详细介绍这些功能的使用方法。

---

## 生成分享链接

分享链接是最快捷的分享方式。你可以生成一个短链接，将工作流以只读形式分享给任何人。接收者不需要登录 AgentLoom 也可以查看工作流的结构。

### 前提条件

- 工作流必须处于"已发布"状态（草稿和归档状态的工作流不能分享）
- 你需要是工作流的创建者或拥有操作权限

### 操作步骤

1. 打开已发布的工作流画布编辑器。

2. 在版本工具栏中，点击"分享"按钮。

> 界面提示："分享"按钮带有分享图标，仅在工作流已发布时显示。

3. 系统会弹出分享管理对话框。在这里你可以：

   - **创建新分享**：选择分享权限后生成链接
   - **管理已有分享**：查看、撤销之前创建的分享链接

4. 创建分享时需要选择分享权限：

| 权限类型 | 说明 |
|---------|------|
| 只读 (read_only) | 接收者只能查看工作流的节点和连线结构，不能复制 |
| 可复制 (copyable) | 接收者可以查看工作流，并且可以一键复制到自己的账号中 |

5. 你还可以设置分享链接的过期时间。不设置则永久有效。

6. 点击确认，系统会生成一个短链接（格式如 `https://agentloom.ling.plus/s/abc123`）。

7. 复制链接，通过任何渠道（邮件、即时通讯、文档等）发送给接收者。

### 分享链接的内容

接收者打开分享链接后会看到：
- 工作流名称和描述
- 分享者信息
- 节点和连线数量统计
- 只读画布视图 -- 展示完整的工作流结构
- 如果权限为"可复制"，还会看到"复制到我的账号"按钮

### 管理分享链接

在分享管理对话框中，你可以查看所有已创建的分享链接，并且：

- 查看每个链接的访问量和复制量
- 撤销某个分享链接（撤销后链接立即失效）
- 查看链接的过期时间

## 导出工作流

将工作流导出为文件，方便在不同环境之间迁移或作为备份。

### 导出步骤

1. 打开工作流的画布编辑器。

2. 在版本工具栏中，点击"导出"按钮。

> 界面提示："导出"按钮带有下载图标。当画布上有节点时才会显示此按钮。导出过程中按钮会显示加载动画。

3. 系统会自动下载一个 JSON 文件到你的电脑。文件名格式为 `工作流名称-export-日期.agentloom-workflow.json`。

### 导出文件的内容

导出的文件采用 `agentloom-workflow-v1` 格式封装，包含：

```json
{
  "schemaVersion": "agentloom-workflow-v1",
  "exportedAt": "2026-04-05T12:00:00Z",
  "workflow": {
    "name": "工作流名称",
    "description": "工作流描述",
    "definition": {
      "nodes": [...],
      "edges": [...],
      "viewport": { "x": 0, "y": 0, "zoom": 1 }
    },
    "inputSchema": { ... }
  }
}
```

### 安全性说明

导出功能内置了安全保护机制：

- **自动剥离敏感信息**：导出时系统会自动使用 `sanitizeDefinition()` 递归剥离节点配置中的敏感数据（如 API Key、密码、Token 等）
- **不含执行数据**：导出的文件只包含工作流定义，不包含执行历史和运行时数据
- **不含组织信息**：导出的文件不包含与特定组织绑定的信息

这意味着你可以放心地分享导出文件，不用担心泄露敏感配置。

### 文件大小限制

导入时文件大小限制为 10MB。这对于绝大多数工作流来说绑绑有余。

## 导入工作流

从文件导入工作流，用于迁移、复原或使用他人分享的工作流。

### 导入步骤

1. 在画布编辑器中，点击版本工具栏上的"导入"按钮。

> 界面提示："导入"按钮带有文件夹输入图标。

2. 系统会弹出导入对话框。

3. 在对话框中：
   - 点击选择文件按钮，选择一个 `.agentloom-workflow.json` 文件
   - 或者直接将文件拖拽到对话框区域

4. 系统会自动验证文件格式和内容，并显示验证结果：
   - **文件有效**：显示节点数量、连线数量等信息
   - **文件无效**：显示具体的错误原因（如格式错误、缺少必要字段等）

5. 如果验证通过，可以修改导入后的工作流名称和描述。

6. 点击"导入"按钮确认。系统会创建一个新的工作流，包含导入文件中的所有节点、连线和配置。

### 导入的处理规则

- **创建新工作流**：导入不会覆盖任何现有工作流，而是创建一个全新的工作流
- **重新生成 ID**：所有节点和连线的 ID 都会重新生成，避免与现有工作流冲突
- **格式校验**：系统会使用 Zod 验证文件内容的完整性和正确性
- **兼容性处理**：支持 camelCase 和 snake_case 两种字段命名格式

## 从分享链接复制

如果你收到了一个标记为"可复制"的分享链接，可以将工作流复制到自己的账号。

### 操作步骤

1. 在浏览器中打开分享链接。

2. 查看工作流的结构和描述，确认是你需要的。

3. 点击"复制到我的账号"按钮。

4. 系统会在你的账号中创建一份工作流的副本。你可以自由编辑这份副本，不会影响原始工作流。

### 复制时的处理

- 工作流定义（节点、连线、配置）会完整复制
- 所有 ID 重新生成
- 工作流状态为"草稿"
- 来源标记为"从分享链接"

## 发布到工作流市场

如果你希望将工作流分享给更广泛的社区用户，可以将其发布到 AgentLoom 的工作流市场。

### 前提条件

- 工作流必须已发布
- 你需要是工作流的创建者或拥有管理权限

### 操作步骤

1. 在已发布的工作流画布编辑器中，找到版本工具栏上的"发布到市场"按钮（黄色按钮）。

> 界面提示："发布到市场"按钮带有商店图标，仅在工作流已发布时显示。

2. 点击后弹出市场发布对话框。

3. 填写市场展示信息：
   - 标题和描述
   - 分类（分析/内容/开发/自动化/报表）
   - 标签
   - 定价模式（免费或按次计费）

4. 确认发布。

### 发布后

- 工作流会出现在"市场"页面，所有用户都可以浏览
- 用户可以查看工作流的详情、评分和评价
- 用户可以将其安装到自己的账号中
- 你可以在"市场 > 我的上架"页面管理已发布的工作流

---

## 从市场安装工作流

你也可以从市场安装他人分享的工作流。

### 操作步骤

1. 进入"市场"页面（侧边栏导航）。

2. 浏览或搜索感兴趣的工作流。

3. 点击工作流卡片查看详情，包括节点结构、描述、评分和评价。

4. 点击"安装"按钮。

5. 系统会在你的账号中创建一份工作流副本，你可以自由编辑和使用。

### 安装权限

安装市场工作流需要以下角色之一：owner（拥有者）、admin（管理员）、creator（创建者）或 operator（操作者）。

---

## 多种创建来源的关系

以下是创建工作流时可用的三种来源（它们是互斥的，每次创建只能选择一种）：

| 来源方式 | 说明 |
|---------|------|
| 模板 (template_slug) | 从预置或自定义模板创建 |
| 分享链接 (share_token) | 从他人的分享链接复制创建 |
| 市场安装 (marketplace_listing_id) | 从工作流市场安装创建 |

无论从哪种来源创建，结果都是一个完整独立的工作流副本，你可以自由修改而不影响源工作流。

## 安全注意事项

### 导出安全

- 导出会自动剥离敏感配置，但请仍然在分享文件前检查一遍
- 导出文件不包含 API Key、密码等敏感数据
- 导出文件不包含执行历史数据

### 分享安全

- 分享链接可以设置过期时间
- 分享链接可以随时撤销
- 只读分享不允许复制工作流
- 分享的是已发布版本的快照，不会暴露你后续的编辑内容

### 市场安全

- 发布到市场的内容会经过基本审核
- 安装的工作流在你的账号中是独立副本，不会与原作者有数据交互
