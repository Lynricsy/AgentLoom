# 使用模板

AgentLoom 提供了多个预置工作流模板，覆盖竞品分析、内容创作、代码审查、数据报表等常见场景。使用模板可以让你跳过从零搭建的过程，直接在一个功能完备的工作流基础上进行调整。

---

## 什么是工作流模板

工作流模板是由 AgentLoom 团队或社区创建的预配置工作流方案。每个模板包含：

- **完整的节点和连线结构** -- 节点已经按照合理的逻辑连接好
- **预设的提示词文本** -- 模板用文本节点承载针对该场景优化的系统提示词，连接到 Agent 节点的「系统提示词」端口
- **输入参数定义** -- 已经定义好了运行时需要填写的输入字段
- **元信息** -- 包括作者、复杂度级别、预估运行时间、所需能力等

从模板创建的工作流是一个完全独立的副本。你可以自由修改任何内容，不会影响原始模板。

## 浏览模板

### 模板页面

你可以在 AgentLoom 的模板浏览页面查看所有可用的模板。

> 界面提示：模板浏览页面位于 `/templates` 路径，可以从侧边栏的"模板"导航入口进入。

### 模板卡片

模板以卡片形式展示，每张卡片包含：

- **模板名称**
- **简短描述** -- 说明模板的用途
- **分类标签** -- 模板所属的分类（分析、内容、开发、自动化、报表）
- **标签** -- 更具体的功能标签
- **复杂度** -- 初级 (beginner)、中级 (intermediate) 或高级 (advanced)
- **节点数量** -- 模板中包含的节点数
- **预估运行时间** -- 大致的执行耗时

### 模板分类

AgentLoom 的模板按以下类别组织：

| 分类 | 英文标识 | 包含的模板类型 |
|------|---------|--------------|
| 分析 | analysis | 竞品分析、市场洞察、数据分析 |
| 内容 | content | 文章创作、文案生成、内容审核 |
| 开发 | development | 代码审查、文档生成、测试生成 |
| 自动化 | automation | 流程自动化、任务调度 |
| 报表 | reporting | 数据报表、指标汇总 |

## 预置模板介绍

AgentLoom 预置了 5 个覆盖不同场景的模板，以下是每个模板的详细介绍。

### 每日竞品分析

| 属性 | 值 |
|------|-----|
| 标识 | daily-competitor-analysis |
| 分类 | 分析 |
| 复杂度 | 中级 |
| 节点数 | 3 |
| 预估耗时 | 约 2 分钟 |

**用途**：自动抓取竞品动态，通过 LLM 分析市场趋势并汇总为结构化报告，帮助团队快速掌握竞争格局。

**工作流结构**：
1. **竞品信息采集 Agent** -- 根据给定的竞品列表，收集并整理最新的产品动态、定价变化和市场活动
2. **趋势分析 LLM** -- 根据采集到的竞品信息，分析市场趋势、竞争态势和潜在机会
3. **分析报告汇总** -- 输出结构化分析报告

**输入参数**：
- 分析主题（文本，必填）
- 分析深度（单选：浅度/中度/深度，必填）
- 输出格式（多选：文本/表格/图表）
- 最大迭代次数（数字，1-10，默认 3）

**适合的用户**：产品经理、市场分析师、商业策略团队。

---

### 客户反馈智能分类

| 属性 | 值 |
|------|-----|
| 标识 | customer-feedback-classifier |
| 分类 | 分析 |
| 复杂度 | 初级 |
| 节点数 | 2 |
| 预估耗时 | 约 30 秒 |

**用途**：将客户反馈自动分类为正面、负面或中性，同时提取关键主题和情感倾向，助力产品决策。

**工作流结构**：
1. **反馈分类 Agent** -- 对输入的客户反馈进行情感分类，提取关键主题，输出结构化分类结果
2. **分类结果** -- 以 JSON 格式输出分类结果

**输入参数**：
- 客户反馈内容（文本，必填，5-2000 字符）
- 反馈渠道（单选：工单/邮件/应用内反馈/社交媒体）
- 重点关注主题（多选：功能需求/易用性/性能/稳定性/定价）

**适合的用户**：产品运营、客服团队、产品经理。

这是最简单的模板，只有两个节点，非常适合初次接触 AgentLoom 的用户上手练习。

---

### 技术博客创作工作流

| 属性 | 值 |
|------|-----|
| 标识 | tech-blog-writer |
| 分类 | 内容 |
| 复杂度 | 中级 |
| 节点数 | 4 |
| 预估耗时 | 约 5 分钟 |

**用途**：从选题到发布的完整内容创作流水线，由四个专精 Agent 分工协作完成。

**工作流结构**：
1. **选题 Agent** -- 根据给定的技术领域，生成有吸引力的博客选题，包含标题、目标读者和预期要点
2. **研究 Agent** -- 根据选定的博客主题，整理相关的技术概念、最佳实践和代码示例
3. **写作 Agent** -- 基于研究素材撰写一篇结构清晰、深入浅出的技术博客文章
4. **审校 Agent** -- 审查文章的技术准确性、文字质量和结构完整性，输出最终润色版本

**输入参数**：
- 博客主题（文本，必填，最大 150 字符）
- 目标读者层级（单选：入门/进阶/专家，必填）
- 目标字数（数字，800-5000，默认 1800）
- 需要包含的章节（多选：背景介绍/原理分析/代码示例/最佳实践/常见误区）

**适合的用户**：技术写作者、技术博客运营、开发者关系团队。

这个模板很好地展示了"多 Agent 串行协作"的模式 -- 四个 Agent 像一条流水线，依次完成选题、研究、写作和审校。

### 代码审查助手

| 属性 | 值 |
|------|-----|
| 标识 | code-review-assistant |
| 分类 | 开发 |
| 复杂度 | 高级 |
| 节点数 | 5 |
| 预估耗时 | 约 3 分钟 |

**用途**：多 Agent 并行审查代码，从安全、性能、规范三个维度同步进行，最后由汇总 Agent 生成综合审查报告。

**工作流结构**：
1. **代码输入处理** -- 接收代码输入，提取关键信息（语言、框架、文件结构），分发给各审查 Agent
2. **安全审查 Agent** -- 检查安全漏洞、注入风险、敏感数据泄露和不安全的依赖
3. **性能审查 Agent** -- 分析性能瓶颈、内存泄漏风险和可优化的算法
4. **规范审查 Agent** -- 检查代码风格一致性、命名规范、注释完整性和设计模式合理性
5. **汇总 Agent** -- 汇总所有审查结果，按严重程度排序，生成包含具体修改建议的综合报告

**输入参数**：
- 待审查代码（文本，必填，20-8000 字符）
- 编程语言（单选：TypeScript/JavaScript/Python/Go/Java/Rust，必填）
- 审查重点（多选：安全/性能/可维护性/测试覆盖/代码规范）
- 问题输出阈值（数字，1-5，默认 3）

**适合的用户**：开发团队、技术 Lead、代码质量保证团队。

这是最复杂的预置模板，展示了"并行 Agent 协作"的模式。三个审查 Agent 同时工作，最后由汇总 Agent 合并结果。这种结构特别适合需要从多个维度同时分析的场景。

### 数据报表自动生成

| 属性 | 值 |
|------|-----|
| 标识 | auto-data-report |
| 分类 | 报表 |
| 复杂度 | 中级 |
| 节点数 | 4 |
| 预估耗时 | 约 4 分钟 |

**用途**：从数据源提取信息，通过分析 Agent 处理数据趋势，生成图表描述，最终输出完整的数据分析报告。

**工作流结构**：
1. **数据源 Agent** -- 从给定的数据源描述中提取关键数据指标，整理为结构化数据集
2. **分析 Agent** -- 对数据集进行趋势分析、异常检测和关键指标计算
3. **图表描述生成** -- 基于分析结论，生成适合的图表类型建议和图表数据描述
4. **报告输出** -- 输出完整的数据分析报告

**输入参数**：
- 数据源描述（文本，必填，最大 500 字符）
- 报表周期（单选：日报/周报/月报/季度报表，必填）
- 关键指标（多选：营收/活跃用户/转化率/留存率/异常波动，必填）
- 图表数量上限（数字，1-8，默认 3）

**适合的用户**：数据分析师、运营团队、产品经理。

## 从模板创建工作流

### 方法一：从模板页面创建

1. 进入模板浏览页面（侧边栏 > 模板）。

2. 浏览可用模板，找到你感兴趣的那个。

3. 点击模板卡片，查看模板详情。

4. 在详情页面中，点击"使用此模板"按钮。

5. 系统会弹出创建向导对话框，你可以：
   - 修改工作流名称（默认使用模板名称）
   - 修改描述
   - 查看模板的节点结构和预估运行时间

6. 确认后，系统会基于模板创建一个新的工作流，并自动跳转到画布编辑器。

### 方法二：在创建工作流时选择模板

在工作流列表页点击"新建工作流"时，创建对话框中可以选择从模板开始。选择模板后，新工作流会预填好模板的全部结构。

### 创建后的调整

从模板创建的工作流已经包含了完整的节点、连线和配置，但你可能需要做以下调整：

1. **确认 Agent 与模型** -- 为模板中的每个 Agent 节点选择已发布的 Agent，并确认模型已在对应的 Agent 配置中绑定。工作流 Agent 节点没有模型输入端口；LLM 模型节点的输出仅能连接到智能路由的模型输入。

2. **调整系统提示词** -- 模板用文本节点提供了通用的提示词，编辑该节点的文本即可按你的场景优化；Agent 自身的提示词则在对应的 Agent 配置中修改。

3. **修改输入参数** -- 检查输入参数定义是否符合你的需求，可以添加、删除或修改字段。

4. **测试运行** -- 在正式使用前，先手动运行几次测试，确认输出质量满足要求。

## 将你的工作流变为模板

目前，你可以通过以下方式分享自己的工作流供他人使用：

### 通过分享链接

将工作流发布后，生成一个"可复制"权限的分享链接。他人打开链接后可以将其复制到自己的账号。详见 [分享与导出](./sharing.md)。

### 通过导出文件

将工作流导出为 `.agentloom-workflow.json` 文件，通过任何文件传输方式分享给他人。接收者可以在自己的 AgentLoom 中导入。

### 通过工作流市场

将工作流发布到 AgentLoom 工作流市场，让所有社区用户都能发现和使用你的方案。详见 [分享与导出](./sharing.md) 中的"发布到工作流市场"部分。

## 模板使用建议

### 选择合适的复杂度

如果你刚接触 AgentLoom：
- 从初级 (beginner) 模板开始，如"客户反馈智能分类"（只有 3 个节点）
- 理解基本的节点、连线和运行流程后，再尝试中级模板
- 高级模板（如"代码审查助手"）涉及并行路径和合并逻辑，适合有一定经验后再使用

### 先运行再修改

拿到模板后，建议先为每个 Agent 节点选好已发布的 Agent，直接运行一次看看默认效果。在理解了模板的工作方式后，再针对性地修改提示词文本节点和其他配置。

### 理解模板的设计思路

每个模板都体现了一种 Agent 协作模式：
- **串行协作**（如博客创作）：Agent 依次处理，后一个 Agent 基于前一个的输出工作
- **并行协作**（如代码审查）：多个 Agent 同时处理不同维度，最后汇总
- **简单流水线**（如反馈分类）：单一 Agent 处理后直接输出

理解这些模式后，你可以举一反三，设计出适合自己场景的新工作流。
