# 管理技能

本文介绍如何在 AgentLoom Studio 中管理技能，包括浏览已有技能、启用和禁用技能、创建自定义技能等操作。

## 进入技能管理页面

> 界面提示：在 AgentLoom Studio 左侧导航栏中，点击「设置」菜单，然后选择「技能」选项，即可进入技能管理页面。页面路径为 `/settings/skills`。

技能管理页面是集中查看和管理所有技能的地方。

## 浏览技能

### 分类标签页

技能管理页面顶部提供了分类标签页，帮助你快速筛选和浏览不同类型的技能：

- 你可以通过点击不同的分类标签来查看特定类别的技能
- 每个标签页只会显示属于该分类的技能列表

### 搜索技能

> 界面提示：在技能管理页面顶部，有一个搜索框，可以通过名称或描述关键词搜索技能。

如果你的组织拥有较多技能，搜索功能可以帮助你快速找到需要的技能。输入关键词后，列表会实时过滤显示匹配的结果。

### 技能卡片

每个技能在列表中以卡片形式展示，卡片上显示以下信息：

- **技能名称**：技能的标识名称
- **技能描述**：对技能功能和用途的简要说明
- **状态标识**：显示技能当前是启用还是禁用状态
- **内置标记**：如果是平台内置技能，会有特殊标记以便区分

点击技能卡片可以查看技能的详细信息。

## 启用和禁用技能

### 启用技能

要启用一个技能，在技能卡片上找到状态开关，将其切换到启用状态即可。

启用后的技能会在 Agent 对话和工作流执行时自动生效。当 Agent 启动时，系统会查询当前组织下所有已启用的技能，并将它们注入到 Agent 的系统提示中。

### 禁用技能

如果某个技能暂时不需要，你可以将其禁用。禁用技能不会删除它，只是让它在 Agent 执行时不再被注入。

禁用操作即时生效。已禁用的技能不会影响后续的 Agent 对话和工作流执行，但不会影响正在进行中的对话或执行。

### 内置技能的状态管理

内置技能默认处于启用状态。你可以根据需要禁用不需要的内置技能。内置技能不可删除，但可以自由地启用和禁用。

## 查看技能详情

点击技能卡片可以查看技能的完整信息：

- **基本信息**：名称、描述、创建时间、更新时间
- **技能内容**：SKILL.md 格式的完整技能文档
- **关联文件**：技能附带的补充文件列表
- **前置元数据**：YAML 格式的技能属性，包括许可协议、兼容性要求等

> 界面提示：点击技能卡片后，会弹出一个详情对话框，展示技能的完整信息。

## 创建自定义技能

除了使用内置技能，你还可以创建属于自己组织的自定义技能。

### 创建权限

创建技能需要以下角色之一：所有者（Owner）、管理员（Admin）或创建者（Creator）。操作者（Operator）和查看者（Viewer）角色只能浏览和使用已有技能。

### 创建步骤

> 界面提示：在技能管理页面中，点击「创建技能」按钮，即可打开创建对话框。

1. **填写基本信息**
   - **名称**（必填）：为技能设置一个清晰的名称，最长 128 个字符
   - **描述**（选填）：对技能的功能和适用场景进行说明，最长 2048 个字符

2. **编写技能内容**
   - 创建对话框中提供了代码编辑器，你可以在其中编写技能的 SKILL.md 内容
   - 编辑器支持 Markdown 语法高亮，方便你组织和格式化内容

3. **上传附件**（可选）
   - 你可以为技能附加相关文件，例如模板、示例代码、参考资料等
   - 单个文件最大 5 MB
   - 每个技能最多附加 50 个文件
   - 所有文件的总大小不超过 50 MB

4. **确认创建**
   - 填写完成后，点击「确认」按钮提交

### 编写技能内容的建议

好的技能文档应该包含以下要素：

- **明确的任务定义**：清楚说明这个技能帮助 Agent 完成什么任务
- **具体的工作步骤**：按顺序列出 Agent 应该遵循的操作流程
- **质量标准**：明确什么样的输出是合格的，什么样的需要改进
- **注意事项**：列出常见的错误和需要避免的做法
- **示例**：提供输入和输出的具体示例，帮助 Agent 理解期望的行为

## 更新技能

对于自定义技能，你可以随时更新其内容。

> 界面提示：在技能详情中，找到「编辑」按钮可以进入编辑模式。

更新技能时可以修改的内容包括：

- 技能名称和描述
- 技能内容（SKILL.md 正文）
- 附件文件（添加或替换）

更新操作使用乐观并发控制（OCC），如果有其他人同时在编辑同一个技能，系统会提示冲突，避免覆盖他人的修改。

## 归档技能

如果某个自定义技能不再需要但你不想删除它，可以将其归档。

- 归档后的技能会从活跃列表中移除
- 归档的技能不会被注入到 Agent 中
- 归档操作需要所有者、管理员或创建者角色

## 删除技能

如果确定某个自定义技能不再需要，你可以将其删除。

- 删除操作需要所有者（Owner）或管理员（Admin）角色
- 内置技能不可删除
- 删除操作不可撤销

**注意**：删除技能前，请确认没有工作流节点正在引用该技能。

## 技能在画布中的使用

除了通过全局启用让技能自动注入到所有 Agent 中，你还可以在工作流画布中使用专门的「技能节点」，将特定技能连接到特定的 Agent 节点。

> 界面提示：在工作流画布的节点面板中，可以找到「技能」节点类型。将其拖拽到画布上后，在配置面板中选择要使用的技能。

这种方式适合以下场景：

- 只希望特定 Agent 使用某项技能，而不是全局生效
- 在同一个工作流中，不同 Agent 需要使用不同的技能组合
