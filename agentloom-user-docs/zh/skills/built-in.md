# 内置技能

AgentLoom 预置了 5 个经过验证的内置技能，覆盖了软件开发中最常见的任务场景。这些技能开箱即用，无需额外配置，每个组织默认都可以使用。

## 代码审查（Code Review）

### 功能说明

代码审查技能让 Agent 能够按照专业标准对代码进行系统性的审查。启用此技能后，Agent 在审查代码时会关注代码质量、安全性、性能、可维护性等多个维度，并给出具体的改进建议。

### 使用场景

- 对提交的代码变更进行自动审查
- 在合并代码之前进行质量检查
- 对遗留代码进行健康度评估
- 团队代码规范的自动化执行

### Agent 的审查行为

启用代码审查技能后，Agent 会：

- 分析代码的结构和逻辑
- 检查是否存在潜在的安全漏洞
- 评估代码的性能表现
- 检查代码风格和命名规范
- 验证错误处理是否完善
- 给出具有可操作性的改进建议

## 文档生成（Documentation）

### 功能说明

文档生成技能让 Agent 能够为代码、API、项目等生成高质量的技术文档。启用此技能后，Agent 在编写文档时会遵循一致的格式和结构，确保文档内容完整、清晰、易于理解。

### 使用场景

- 为代码库生成 API 参考文档
- 为项目编写 README 和使用指南
- 为模块和函数编写注释文档
- 将技术方案整理为文档

### Agent 的文档行为

启用文档生成技能后，Agent 会：

- 按照统一的文档结构和格式组织内容
- 提供完整的参数说明和返回值描述
- 包含使用示例和代码片段
- 标注注意事项和已知限制
- 使用清晰易懂的语言表达

## 测试生成（Test Generation）

### 功能说明

测试生成技能让 Agent 能够为代码自动生成高质量的测试用例。启用此技能后，Agent 在编写测试时会考虑正常路径、边界条件、异常场景等多种情况，确保测试覆盖全面。

### 使用场景

- 为新编写的功能生成单元测试
- 为现有代码补充缺失的测试用例
- 生成集成测试和端到端测试
- 验证代码重构后的行为一致性

### Agent 的测试行为

启用测试生成技能后，Agent 会：

- 分析被测代码的功能和接口
- 设计覆盖正常路径的测试用例
- 设计覆盖边界条件的测试用例
- 设计覆盖异常和错误场景的测试用例
- 使用合适的测试框架和断言方法
- 确保测试用例独立且可重复运行

## 重构建议（Refactoring）

### 功能说明

重构建议技能让 Agent 能够对代码提出系统性的重构方案。启用此技能后，Agent 在分析代码时会识别可以改进的模式，并提供具体的重构步骤和预期收益。

### 使用场景

- 对复杂或难以维护的代码进行改善
- 消除代码中的重复逻辑
- 改善代码的模块化程度
- 提升代码的可读性和可测试性

### Agent 的重构行为

启用重构建议技能后，Agent 会：

- 识别代码中的坏味道（Code Smells）
- 提出具体的重构手法和步骤
- 解释每项重构的预期收益
- 评估重构的风险和影响范围
- 建议重构的优先顺序
- 确保重构不会改变代码的外部行为

## 调试辅助（Debugging）

### 功能说明

调试辅助技能让 Agent 能够系统性地帮助你分析和解决代码中的问题。启用此技能后，Agent 在调试时会按照结构化的方法论进行排查，而不是简单地猜测原因。

### 使用场景

- 分析错误日志和异常堆栈
- 排查性能瓶颈和内存泄漏
- 定位逻辑错误和边界条件问题
- 复现和诊断难以重现的 bug

### Agent 的调试行为

启用调试辅助技能后，Agent 会：

- 收集和分析错误信息和上下文
- 系统性地缩小问题范围
- 提出假设并设计验证方案
- 分析错误的根本原因而非表面症状
- 建议修复方案和预防措施
- 提供相关的调试工具和技巧建议

## 内置技能的特点

### 开箱即用

内置技能无需手动创建或上传，每个组织在初始化时就自动拥有这 5 个技能。

### 不可删除

内置技能作为系统预置资源不可删除，但你可以随时启用或禁用它们。如果某个内置技能不适合你的使用场景，将其禁用即可。

### 持续更新

随着平台版本的升级，内置技能的内容可能会得到优化和改进，以反映最新的行业最佳实践。
