# 知识库

知识库是 AgentLoom 中用于存储和管理私有文档数据的核心模块。通过知识库，你可以将企业内部的文档、技术手册、产品说明等资料上传到平台，让 AI Agent 在执行任务时能够基于这些真实数据进行智能检索和问答。

## 什么是知识库

在 AgentLoom 中，知识库是一个结构化的文档集合。你可以将各种格式的文档上传到知识库中，系统会自动对文档内容进行解析、分块和向量化处理，最终存储为可供 AI 快速检索的知识节点。

每个知识库都属于你所在的组织，支持设置为私有或组织内共享。你可以根据不同的业务场景创建多个知识库，例如为产品文档、技术规范、客户案例分别建立独立的知识库。

## RAG 是什么

RAG（Retrieval-Augmented Generation，检索增强生成）是一种让 AI 在回答问题时先从你的私有数据中检索相关信息，再结合检索结果生成回答的技术方案。

通俗来说，它的工作方式类似于：

1. 你向 Agent 提出一个问题
2. Agent 先从你的知识库中找到与问题最相关的几段内容
3. Agent 把这些相关内容和你的问题一起交给 AI 模型
4. AI 模型基于这些真实的参考资料生成准确的回答

这样做的好处是，AI 的回答不再只依赖于它的训练数据，而是能够引用你提供的最新、最准确的私有资料，大幅提高回答的可靠性和针对性。

## 知识库的适用场景

知识库适合以下常见场景：

### 企业知识问答

将公司的产品手册、操作指南、FAQ 等文档上传到知识库。当员工或客户提问时，Agent 可以从这些文档中快速找到准确答案，减少重复咨询和人工查找的工作量。

### 技术文档检索

上传 API 文档、架构设计文档、技术规范等资料。开发团队在遇到技术问题时，Agent 可以帮助快速定位到相关的技术说明和示例代码。

### 客户服务辅助

将客户常见问题、解决方案、服务流程等资料整理为知识库。客服团队可以借助 Agent 快速获取标准化的应答方案，提升服务效率和一致性。

### 合规与法规查询

上传行业法规、合规要求、内部制度等文件。当需要确认某项操作是否合规时，Agent 可以从这些权威文档中检索出相关条款。

### 研究与分析

将研究报告、行业分析、竞品资料等文档构建为知识库。在进行分析和决策时，Agent 可以帮助从大量资料中提取关键信息。

## 知识库的工作流程

使用知识库的完整流程如下：

1. **创建知识库** -- 在平台中创建一个新的知识库，设置名称和描述
2. **上传文档** -- 将文档文件上传到知识库中，支持 PDF、Word、Markdown 和纯文本格式
3. **等待处理** -- 系统自动对文档进行解析、分块和向量化处理
4. **配置检索** -- 根据需要调整检索策略和参数
5. **绑定 Agent** -- 在 Agent 配置画布中将知识库连接到 Agent Main 的「知识库」端口，保存并发布 Agent

> 界面提示：在 AgentLoom Studio 左侧导航栏中，点击「资源」菜单可以找到知识库管理入口。

## 支持的文档格式

AgentLoom 知识库当前支持以下文档格式：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PDF | `.pdf` | 支持文本型 PDF |
| Word 文档 | `.docx` | Microsoft Word 2007 及以上版本 |
| Markdown | `.md` | 标准 Markdown 格式 |
| 纯文本 | `.txt` | UTF-8 编码的纯文本文件 |

单个文件最大支持 50 MB。系统会根据文件类型自动选择对应的解析器进行处理。

## 知识库的技术基础

AgentLoom 的知识库基于向量数据库技术构建。当你上传文档后，系统会将文档内容切分为适当大小的文本块，然后使用嵌入模型（Embedding Model）将每个文本块转换为高维向量。这些向量存储在专业的向量数据库中，支持高效的语义相似度搜索。

当 Agent 需要检索知识时，系统会将用户的问题同样转换为向量，然后在向量空间中找到与问题最相近的文本块，作为 Agent 生成回答的参考依据。

与传统的关键词搜索不同，向量检索能够理解语义关系。例如，当你搜索「如何退货」时，即使文档中使用的是「商品退换流程」这样的表述，向量检索也能正确地找到这段内容，因为它们在语义上是相关的。
