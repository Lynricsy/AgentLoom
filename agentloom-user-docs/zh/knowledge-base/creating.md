# 创建知识库

本文介绍如何在 AgentLoom 中创建知识库、上传文档，以及了解文档处理的完整流程。

## 创建新的知识库

### 第一步：进入知识库管理页面

> 界面提示：在 AgentLoom Studio 左侧导航栏中，点击「资源」菜单，然后选择「知识库」标签页，即可看到当前组织下的所有知识库列表。

### 第二步：点击创建按钮

> 界面提示：在知识库列表页面的右上角，点击「创建知识库」按钮，将弹出知识库创建对话框。

### 第三步：填写基本信息

在创建对话框中，需要填写以下信息：

- **名称**（必填）：为你的知识库起一个有意义的名称，最长支持 255 个字符。建议使用能够清晰描述知识库用途的名称，例如「产品使用手册」「API 技术文档」「客户服务 FAQ」等。
- **描述**（选填）：对知识库内容和用途进行简要说明，最长支持 2000 个字符。好的描述可以帮助团队成员快速了解这个知识库包含的内容。
- **可见性**：选择知识库的访问范围。
  - **私有**：仅创建者可以访问和使用。
  - **组织**：组织内所有成员均可访问和使用。

### 第四步：确认创建

填写完信息后，点击「确认」按钮即可完成知识库创建。创建成功后，你将进入知识库的详情页面，可以开始上传文档。

## 上传文档

知识库创建完成后，你需要向其中上传文档才能让它发挥作用。

### 支持的文件格式

AgentLoom 当前支持以下四种文档格式：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PDF | `.pdf` | 支持文本型 PDF，扫描件需先进行 OCR 处理 |
| Word 文档 | `.docx` | 支持 Microsoft Word 2007 及以上版本格式 |
| Markdown | `.md` | 支持标准 Markdown 格式 |
| 纯文本 | `.txt` | 支持 UTF-8 编码的纯文本文件 |

**文件大小限制**：单个文件最大支持 50 MB。

### 上传步骤

1. 在知识库详情页面中，找到文档列表区域
2. 点击「上传文档」按钮
3. 在弹出的文件选择器中，选择要上传的文件
4. 等待文件上传完成

> 界面提示：文档上传区域位于知识库详情页的中下部分。上传过程中会显示进度提示。

### 批量上传

你可以在文件选择器中同时选择多个文件进行批量上传。每个文件会独立处理，即使某个文件处理失败也不会影响其他文件。

## 文档处理状态

文档上传后，系统会自动对其进行解析和处理。每个文档会经历以下状态：

### 已上传（Uploaded）

文档刚刚上传成功，尚未开始处理。系统会在短时间内自动将其加入处理队列。

### 处理中（Processing）

文档正在被系统处理，包括以下步骤：

1. **文档解析** -- 系统读取文档内容，提取文本信息。不同格式的文档使用专门的解析器处理。
2. **文本分块** -- 将提取的文本按照分块策略切分为适当大小的文本块。默认使用「句子窗口」策略，窗口大小为 3。
3. **向量化** -- 使用嵌入模型将每个文本块转换为高维向量，用于后续的语义检索。
4. **索引构建** -- 将向量数据写入向量数据库，构建检索索引。

> 界面提示：处理中的文档在列表中会显示「处理中」状态标识。

### 就绪（Ready）

文档已处理完成，可以被 Agent 正常检索和使用。

### 失败（Failed）

文档处理过程中出现了错误。可能的原因包括：

- 文件格式不正确或已损坏
- PDF 是纯扫描件，不包含可提取的文本
- 文件编码格式不被支持
- 系统处理过程中遇到临时错误

对于处理失败的文档，你可以查看错误信息了解具体原因，然后决定是重新上传文件还是调整文件格式。

## 知识库状态

知识库本身也有一个整体状态，反映其下文档的综合处理情况：

| 状态 | 说明 |
|------|------|
| 空库 | 知识库中没有任何文档 |
| 处理中 | 有文档正在处理，知识库内容尚未完全就绪 |
| 可用 | 所有文档处理完成，知识库可以正常使用 |
| 异常 | 存在处理失败的文档，建议检查并处理 |

## 管理文档

### 查看文档列表

> 界面提示：进入知识库详情页后，可以看到该知识库中所有文档的列表。列表支持按状态筛选和分页浏览。

文档列表会显示每个文档的以下信息：

- 文件名
- 文件类型
- 文件大小
- 处理状态
- 上传时间

### 查看文档内容

对于已处理完成的文档，你可以点击文档名称来获取文档内容的访问链接，在浏览器中查看原始文档。

### 删除文档

如果某个文档不再需要，你可以在文档列表中找到它，点击删除按钮将其从知识库中移除。删除文档时，系统会同时清理该文档在向量数据库中的索引数据。

**注意**：文档删除操作不可撤销，请确认后再执行。

## 删除知识库

如果整个知识库不再需要，你可以删除它。删除知识库时，其中的所有文档及其索引数据都会被一并清除。

> 界面提示：在知识库列表页面，每个知识库卡片上都有删除操作入口。

**注意**：删除知识库操作不可撤销，且会影响所有引用该知识库的工作流节点。建议在删除前确认没有正在使用的工作流依赖此知识库。

## 重建知识库索引

当你修改了知识库的分块策略或检索策略后，可能需要重建知识库索引，以使新策略对已有文档生效。

> 界面提示：在知识库详情页的设置区域，可以找到「重建索引」按钮。

重建索引会对知识库中所有文档重新执行分块和向量化处理。在重建过程中，知识库仍然可以被检索和使用，但检索结果可能不完全反映新策略的效果，直到重建完成为止。
