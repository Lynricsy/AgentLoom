# 组织与工作区

组织（Organization）是 AgentLoom 中团队协作的基础。每个组织代表一个独立的工作空间，拥有自己的成员、资源和配额。本文介绍如何创建组织、管理成员以及配置工作区。

## 创建组织

### 注册后的首次设置

当你在 AgentLoom 上完成注册后，系统会引导你创建或加入一个组织。每个用户至少需要属于一个组织才能使用平台的核心功能。

### 创建新组织

如果你是团队负责人或希望建立新的工作空间，可以创建一个新的组织。

> 界面提示：在 AgentLoom Studio 的组织设置页面中，可以找到创建组织的入口。

创建组织时需要填写：

- **组织名称**：你的团队或公司的名称
- **组织描述**（可选）：对组织用途或业务方向的简要说明

创建者会自动成为该组织的所有者（Owner），拥有最高权限。

## 邀请成员

组织创建完成后，你可以邀请团队成员加入。

### 发送邀请

> 界面提示：在组织设置页面的「成员管理」区域中，点击「邀请成员」按钮。

邀请成员时需要填写：

- **邮箱地址**：被邀请人的注册邮箱
- **角色**：为被邀请人分配一个初始角色（详见[角色与权限](./roles.md)）

### 邀请状态

发送邀请后，被邀请人会收到一封邀请邮件。邀请可能处于以下状态：

| 状态 | 说明 |
|------|------|
| 待接受（Pending） | 邀请已发送，等待对方确认 |
| 已接受（Accepted） | 对方已接受邀请，成为组织成员 |
| 已拒绝（Rejected） | 对方拒绝了邀请 |
| 已过期（Expired） | 邀请超过有效期未被处理 |

### 接受邀请

被邀请人点击邮件中的链接后，可以选择接受或拒绝邀请。如果被邀请人尚未注册 AgentLoom 账号，需要先完成注册。

## 管理成员

### 查看成员列表

> 界面提示：在组织设置页面的「成员管理」区域，可以看到当前组织所有成员的列表。

成员列表显示以下信息：

- 成员名称和邮箱
- 当前角色
- 加入时间
- 最近活跃时间

### 修改成员角色

组织的所有者和管理员可以修改其他成员的角色。

> 界面提示：在成员列表中，点击目标成员旁边的角色下拉框，选择新的角色即可。

角色修改即时生效。被修改角色的成员在下次操作时会按照新角色的权限执行。

**注意**：
- 只有所有者可以将其他成员提升为管理员
- 所有者角色只能通过转让的方式变更
- 不能将自己的角色降低到没有管理权限的级别（避免组织失去管理者）

### 移除成员

如果某个成员不再需要访问组织资源，所有者或管理员可以将其从组织中移除。

> 界面提示：在成员列表中，点击目标成员旁边的移除按钮。

**注意**：
- 移除成员后，该成员将无法访问组织中的任何资源
- 该成员创建的工作流和资源仍会保留在组织中
- 不能移除组织的所有者

## 工作区设置

### 组织基本信息

> 界面提示：在组织设置页面中，可以查看和修改组织的基本信息。

可以修改的信息包括：

- 组织名称
- 组织描述
- 组织头像

### 资源配额

每个组织都有对应的资源配额，限制了组织可以使用的资源上限。

> 界面提示：在「设置 - 资源配额」页面（路径 `/settings/resource-quotas`）中，可以查看当前组织的配额使用情况。

常见的配额项目包括：

| 配额项 | 说明 |
|--------|------|
| 并发执行数 | 同时运行的工作流执行数量上限 |
| 日执行量 | 每天可以执行的工作流总次数 |
| 日 API 调用量 | 每天可以发送的 API 请求总数 |
| 存储预算 | 组织可使用的存储空间上限 |
| API 请求速率 | 每分钟可以发送的 API 请求数 |

当配额达到上限时，新的操作可能会被暂时阻止，直到配额重置或被调整。

### 运行监控

组织的所有者和管理员可以通过监控仪表板查看组织的整体运行状况。

> 界面提示：在「设置 - 监控」页面（路径 `/settings/monitoring`）中，可以查看执行统计、资源使用趋势等信息。

### 审计日志

为了满足安全合规需求，AgentLoom 记录了组织内的重要操作日志。

> 界面提示：在「设置 - 审计日志」页面（路径 `/settings/audit-logs`）中，可以查询和浏览操作记录。

审计日志记录的内容包括：

- 工作流的创建、修改、删除操作
- 成员的加入和离开
- 角色变更
- 资源的访问和操作

## 切换组织

如果你同时属于多个组织，可以在 AgentLoom Studio 中切换当前活跃的组织。

> 界面提示：在 Studio 顶部导航栏中，点击当前组织名称可以看到你所属的所有组织列表，点击即可切换。

切换组织后，页面中显示的所有资源（工作流、Agent、知识库等）都会变更为目标组织的资源。

## 常见问题

### 邀请邮件没有收到

- 请检查垃圾邮件文件夹
- 确认邀请时填写的邮箱地址是否正确
- 如果仍未收到，可以让组织管理员重新发送邀请

### 成员无法执行某些操作

- 检查该成员的角色是否具有对应的权限
- 参考[角色与权限](./roles.md)文档确认每种角色的权限范围

### 需要转让组织所有权

- 所有者角色需要通过专门的转让流程变更
- 转让后，原所有者会变为管理员角色
