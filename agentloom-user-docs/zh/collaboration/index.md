# 团队协作

AgentLoom 提供了完整的团队协作功能，让组织中的成员可以共同构建、管理和运行 AI 工作流。通过多租户架构和基于角色的权限控制，你可以安全高效地开展团队协作。

## 协作功能概览

AgentLoom 的团队协作体系包含以下核心能力：

### 组织管理

每个团队在 AgentLoom 中对应一个组织（Organization）。组织是资源隔离的基本单位 -- 一个组织下的工作流、Agent、知识库等资源只对组织内的成员可见。

- 创建和配置组织
- 邀请成员加入组织
- 管理成员的角色和权限

### 角色权限

AgentLoom 提供了 5 种预设角色，从组织所有者到只读查看者，覆盖了不同的职责需求。每种角色拥有不同的操作权限，确保团队成员只能执行与其职责匹配的操作。

### 资源共享

组织内的成员可以共享以下资源：

- **工作流**：所有成员可以查看组织中的工作流，有权限的成员可以编辑和执行
- **Agent**：共享 Agent 定义和配置
- **知识库**：设置为组织可见的知识库可以被所有成员使用
- **技能**：组织级别的技能对所有成员生效
- **执行记录**：团队成员可以查看工作流和 Agent 的执行历史

### 市场

AgentLoom 内置了工作流和插件市场，让团队可以：

- 将自己的工作流发布到市场与其他团队共享
- 从市场浏览和安装其他团队分享的工作流和插件
- 对市场中的工作流和插件进行评价

## 多租户架构

AgentLoom 采用多租户架构设计。简单来说：

- **一个组织等于一个租户**：每个组织拥有独立的数据空间
- **数据隔离**：不同组织之间的数据完全隔离，互不可见
- **独立配额**：每个组织有独立的资源配额（并发执行数、日执行量、API 调用量等）
- **安全保障**：所有 API 请求都经过租户身份验证，确保你只能访问自己组织的数据

这种架构确保了即使多个组织使用同一个 AgentLoom 平台，每个组织的数据安全和独立性都得到保障。

## 协作的最佳实践

### 合理分配角色

根据团队成员的实际职责分配对应的角色。避免所有人都使用最高权限 -- 遵循最小权限原则可以减少误操作风险。

### 建立工作流规范

在团队内建立工作流的命名、描述和标签规范，让成员能够快速找到和理解已有的工作流。

### 利用知识库共享知识

将团队积累的文档和知识上传到组织级知识库，让所有 Agent 都能受益于团队的集体智慧。

### 通过市场复用成果

将经过验证的工作流发布到市场，既能帮助其他团队，也能提升自己团队的影响力。

### 善用通知保持同步

配置合理的通知偏好，确保团队成员能及时了解工作流执行结果、审批请求和资源变动。建议对失败通知和需要介入的通知开启邮件或推送，保证关键信息不遗漏。

## 企业运维功能

对于有运维和合规需求的组织，AgentLoom 还提供了以下协作管理工具：

### 资源配额管理

> 界面提示：在「设置 - 资源配额」页面（路径 `/settings/resource-quotas`）中管理组织配额。

组织所有者和管理员可以查看和调整资源配额，包括并发执行数、日执行量、API 调用限制等，确保资源使用在可控范围内。

### 运行监控

> 界面提示：在「设置 - 监控」页面（路径 `/settings/monitoring`）中查看监控仪表板。

监控仪表板提供组织级别的运行概览，帮助管理者了解工作流执行统计、资源使用趋势和当前队列状态。

### 审计日志

> 界面提示：在「设置 - 审计日志」页面（路径 `/settings/audit-logs`）中查询操作记录。

审计日志记录了组织内所有重要操作的完整历史，满足安全合规要求。支持按资源类型和操作类型进行筛选查询。
