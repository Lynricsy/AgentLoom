# 市场

AgentLoom 市场（Marketplace）是一个让团队之间共享工作流和插件的平台。你可以在市场中浏览、搜索和安装其他团队分享的优质工作流和插件，也可以将自己的作品发布到市场中。

## 浏览市场

### 进入市场

> 界面提示：在 AgentLoom Studio 左侧导航栏中，可以找到「市场」入口。市场页面公开可访问，无需特定权限即可浏览。

### 浏览方式

市场提供了多种浏览方式帮助你发现需要的内容：

**按分类浏览**：市场中的内容按照功能类别进行分类组织，你可以通过分类标签快速定位到感兴趣的领域。

**按排序浏览**：市场支持以下排序方式：
- **热门排序（Popular）**：按照安装和使用量排序，查看最受欢迎的内容
- **评分排序（Rating）**：按照用户评价排序，查看质量最高的内容
- **最新排序（Newest）**：按照发布时间排序，查看最新上架的内容

**按类型筛选**：你可以选择只显示工作流或只显示插件。

## 搜索

市场提供了关键词搜索功能，帮助你快速找到特定的工作流或插件。

> 界面提示：在市场页面顶部有一个搜索框，输入关键词即可搜索。

搜索会匹配工作流和插件的标题、摘要和标签等信息。

## 查看详情

在市场列表中点击某个工作流或插件，可以查看其详情页面。详情页面包含以下信息：

- **标题和摘要**：对内容功能的简要描述
- **发布者信息**：发布该内容的团队
- **标签**：功能和领域标签，帮助你快速判断是否适用
- **评价和评分**：其他用户的使用反馈
- **定价模式**：免费或按执行次数付费
- **安装量**：已有多少团队安装

## 安装工作流和插件

找到需要的内容后，你可以一键安装到自己的组织中。

### 安装权限

以下角色可以安装市场内容：

| 角色 | 可否安装 |
|------|---------|
| 所有者（Owner） | 可以 |
| 管理员（Admin） | 可以 |
| 创建者（Creator） | 可以 |
| 操作者（Operator） | 可以 |
| 查看者（Viewer） | 不可以 |

### 安装步骤

1. 在市场中找到并进入目标内容的详情页
2. 点击「安装」按钮
3. 在弹出的对话框中，你可以：
   - 自定义安装后的名称
   - 填写描述信息
4. 点击确认完成安装

安装完成后，工作流会作为副本出现在你的组织中。你可以自由修改和使用它，不会影响市场中的原始版本。

### 安装说明

- 安装的是工作流或插件的副本，与原始版本互相独立
- 安装后你可以根据自己的需求进行修改
- 安装量会被记录并反映在市场的统计信息中

## 评价

使用过市场中的工作流或插件后，你可以为它们撰写评价。

### 提交评价

1. 进入已安装内容的市场详情页
2. 在评价区域点击「撰写评价」
3. 选择评分（1-5 分）
4. 填写评价内容（可选，最长 2000 字）
5. 提交评价

### 评价规则

- 每个用户对同一个内容只能提交一次评价
- 评价内容对所有市场访问者可见
- 评价会影响内容在评分排序中的排名

## 定价模式

市场中的内容支持两种定价模式：

### 免费（Free）

内容可以免费安装和使用，没有额外费用。大多数社区分享的工作流和插件采用这种模式。

### 按执行付费（Per Execution）

安装免费，但每次执行时会产生费用。这种模式通常用于功能复杂或包含高级能力的商业插件。

## 发布到市场

如果你构建了优秀的工作流，可以将它发布到市场中与其他团队共享。

### 发布前提

- 你需要拥有所有者、管理员或创建者角色
- 工作流需要先发布版本（有已发布的版本）
- 发布时需要经过自动审查

### 发布步骤

> 界面提示：在工作流的管理页面中，可以找到「发布到市场」的操作入口。

1. 确保工作流已有已发布的版本
2. 点击「发布到市场」
3. 填写市场展示信息：
   - **标题**：简洁清晰的标题
   - **摘要**：对工作流功能的简要描述
   - **标签**：添加相关的功能和领域标签
   - **分类**（可选）：选择最匹配的功能分类
   - **封面图片**（可选）：上传封面图片
4. 提交后系统会自动进行审查
5. 审查通过后，内容会上架到市场

### 管理已发布的内容

发布后，你可以在「我的发布」页面管理已上架的内容：

- **下架**：将已上架的内容从市场中临时移除
- **重新上架**：将已下架的内容重新发布到市场（需要重新审查）
- **查看统计**：查看安装量、浏览量和评价信息

### 审查标准

发布到市场的内容需要通过自动审查。审查主要检查以下方面：

- 工作流定义的完整性和有效性
- 标题和摘要是否符合内容规范
- 标签的数量和格式是否合规

审查未通过时，系统会给出具体原因，你可以根据反馈修改后重新提交。
