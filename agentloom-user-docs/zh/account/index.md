# 账户设置

账户设置页面是管理你的个人信息、安全配置和通知偏好的中心。本文介绍账户设置的整体功能和基本操作。

## 账户设置概览

AgentLoom 的账户设置涵盖以下几个方面：

### 个人信息

管理你的基本账户信息，包括显示名称、头像和邮箱等。

### 安全设置

保护你的账户安全，包括密码修改、多因素认证（MFA）和会话管理。详细说明请参考[安全设置](./security.md)。

### 通知偏好

自定义你接收通知的方式和频率，选择哪些类型的通知通过哪些渠道发送。详细说明请参考[通知偏好](./notifications.md)。

## 进入账户设置

> 界面提示：在 AgentLoom Studio 中，点击右上角的用户头像或名称，在弹出的菜单中选择「设置」即可进入账户设置页面。

## 个人信息管理

### 查看账户信息

在账户设置页面中，你可以看到以下个人信息：

- **邮箱地址**：注册时使用的邮箱，也是你的登录账号
- **显示名称**：在团队中显示的名称
- **头像**：在界面中显示的个人头像
- **账户创建时间**：你注册 AgentLoom 的时间

### 修改显示名称

> 界面提示：在个人信息区域，点击显示名称旁边的编辑按钮即可修改。

修改后的名称会在你参与的所有组织中更新显示。

### 更新头像

> 界面提示：点击头像区域可以上传新的头像图片。

支持常见的图片格式，建议使用正方形图片以获得最佳显示效果。

## 登录方式

AgentLoom 支持以下登录方式：

### 邮箱密码登录

最基本的登录方式，使用注册邮箱和密码进行登录。

### OAuth 登录

你可以使用以下第三方账号进行登录：

- **Google 账号**：使用 Google 账号快速登录
- **GitHub 账号**：使用 GitHub 账号快速登录

使用 OAuth 登录时，AgentLoom 只会获取你的基本个人信息（如邮箱和显示名称），不会获取其他数据。

### 绑定第三方账号

如果你最初使用邮箱密码注册，之后可以在安全设置中绑定 Google 或 GitHub 账号。绑定后，你可以选择任何一种方式登录。

## 账户的组织归属

一个 AgentLoom 账户可以同时属于多个组织。在账户设置中，你可以看到你所属的所有组织列表。

> 界面提示：在设置页面的「组织」区域，可以查看和管理你的组织归属。

每个组织中你可能拥有不同的角色和权限。切换组织后，你在平台中看到的资源和可执行的操作会相应变化。

## 账户安全

保护账户安全是使用任何在线平台的重要环节。AgentLoom 提供了多层安全保护：

- **密码策略**：要求密码至少 8 个字符，包含大小写字母和数字
- **多因素认证**：支持 TOTP 双因素认证，为登录增加额外保护
- **会话管理**：查看和管理所有已登录的设备和浏览器
- **端到端加密**：对敏感数据实施端到端加密保护

详细说明请参考[安全设置](./security.md)。

## 数据安全

AgentLoom 高度重视你的数据安全：

- **传输加密**：所有数据传输使用 HTTPS 加密
- **存储加密**：敏感数据在存储时经过加密处理
- **端到端加密（E2EE）**：对 AI 输出和关键决策数据实施端到端加密，确保即使平台运维人员也无法查看你的数据明文
- **租户隔离**：不同组织之间的数据完全隔离

## 退出登录

> 界面提示：点击右上角的用户菜单，选择「退出登录」即可安全退出当前会话。

退出登录后，你需要重新输入密码（或使用 OAuth 重新登录）才能访问平台。如果你启用了 MFA，还需要在登录时提供验证码。
