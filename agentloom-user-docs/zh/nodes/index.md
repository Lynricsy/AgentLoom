# 节点参考

本页面提供 AgentLoom 工作流画布中所有可用节点的总览，帮助你了解每种节点的用途、分类和基本使用方式。

## 什么是节点

在 AgentLoom 中，**节点**是工作流画布上的基本构建单元。每个节点代表一个独立的功能步骤——可以是 AI 推理、数据处理、外部调用、逻辑控制，或者输入输出。

你通过将不同节点拖拽到画布上，并用连线（边）将它们的端口连接起来，就构成了一个完整的工作流。数据从上游节点流向下游节点，按照你设计的路径被处理和转换。

AgentLoom 的节点按功能分为以下几个大类。

### 输入与输出

这类节点负责工作流的数据入口和结果展示。

| 节点 | 说明 |
|------|------|

## 端口和数据类型

### 什么是端口

每个节点左右两侧都有一些彩色的小图标，这些就是**端口**。端口分为两类：

- **输入端口**（位于节点左侧）：接收来自上游节点的数据。
- **输出端口**（位于节点右侧）：将处理后的数据发送给下游节点。

你需要将上游节点的输出端口连接到下游节点的输入端口来建立数据传递关系。

### 数据类型

每个端口都有一个特定的数据类型，不同类型的端口通过颜色和形状来区分。只有兼容的数据类型才能连接。

| 数据类型 | 说明 | 形状 |
|----------|------|------|
| model | LLM 模型实例 | 圆形 |
| text | 文本数据 | 圆形 |
| json | 结构化 JSON 数据 | 方形 |
| image | 图片数据 | 菱形 |
| audio | 音频数据 | 胶囊形 |
| tool | 工具描述符 | 六边形 |
| sandbox | 沙箱环境 | 三角形 |
| knowledge | 知识库引用 | 书本形 |
| skill | 技能定义 | 菱形 |
| agent | Agent 实例 | 圆形 |

### 执行流端口

除了数据端口，大部分节点还有一个特殊的**执行流端口**（exec）。执行流端口用箭头形状表示，控制节点的执行顺序。

- **exec 输入**：连接前序节点的 exec 输出，表示"前序完成后执行我"。
- **exec 输出**：连接后续节点的 exec 输入，表示"我完成后执行下一个"。

执行流是工作流的"控制线"，数据端口是"数据线"。大多数情况下你需要同时连接两者。

### 端口兼容性

当你在画布上拖拽连线时，系统会自动检查端口的数据类型是否兼容：

- **精确匹配**：两个端口的数据类型完全相同（例如 text 到 text），连线显示为绿色。
- **可转换**：数据类型不同但可以自动转换（例如 text 到 json），连线显示为黄色。
- **不兼容**：数据类型无法转换，不允许连接。

端口兼容性由 Rust WASM 类型引擎实时检查，确保你在设计阶段就能发现数据类型不匹配的问题。

## 如何添加节点

### 从节点面板拖拽

> 界面提示：画布左侧有一个节点面板，按分类展示所有可用节点。

1. 在节点面板中找到你需要的节点。
2. 按住节点拖拽到画布上的目标位置。
3. 松开鼠标，节点会被添加到画布上。

节点面板支持搜索——在面板顶部的搜索框中输入关键词可以快速定位节点。

### 连接端口

1. 将鼠标移到一个节点的输出端口上，端口会高亮。
2. 按住鼠标从端口拖出一条连线。
3. 将连线拖拽到目标节点的兼容输入端口上，松开鼠标完成连接。

连线会显示兼容性状态的颜色提示。如果两个端口不兼容，连线会显示红色并且无法建立连接。

## 如何配置节点

### 打开配置面板

点击画布上的某个节点，右侧会弹出该节点的配置面板。不同类型的节点有不同的配置项。

### 通用操作

所有节点都支持以下通用操作：

| 操作 | 说明 |
|------|------|
| 选中 | 点击节点选中它，打开配置面板 |
| 移动 | 拖拽节点在画布上移动位置 |
| 删除 | 选中后按 Delete 键或通过右键菜单删除 |
| 复制 | 通过右键菜单复制节点 |
| 框选 | 在画布空白区域拖拽框选多个节点 |
