# 文本输出

## 功能说明

文本输出节点用于展示工作流的最终文本结果。它是一个终端节点——接收上游传来的文本数据并将其作为工作流的输出呈现给用户。在工作流执行完成后，你可以在执行结果页面看到文本输出节点收到的内容。

文本输出节点支持内联输出预览功能，在工作流执行过程中你就能在画布卡片上实时看到该节点已接收到的内容片段，无需等待整个工作流完成。

## 使用场景

- **展示 AI 回复**：将 LLM Agent 或 Agent 节点生成的自然语言文本回复作为工作流的最终输出展示给用户。这是最常见的使用场景。
- **展示处理结果**：将数据处理、格式转换后的文本结果呈现给用户。例如翻译后的文本、总结后的摘要等。
- **多输出分支**：工作流可以有多个文本输出节点，分别展示不同处理分支的结果。例如条件分支后的不同路径各有一个文本输出。
- **报告生成**：将 Agent 生成的 Markdown 格式报告通过文本输出节点展示，利用 Markdown 渲染能力呈现格式化的报告内容。

## 端口说明

### 输入端口

| 端口名称 | 数据类型 | 必需 | 说明 |
|----------|----------|------|------|
| exec | exec | 否 | 执行流入口，前序节点完成后触发输出节点接收数据 |
| 文本 | text | 否 | 接收要作为工作流最终结果展示的文本内容 |

> 界面提示：文本输入端口在画布上显示为圆形图标，使用 Text 类型的配色。

### 输出端口

文本输出节点没有输出端口，它是工作流的终端节点。数据到达此节点后不再往下游传递。

## 配置项

文本输出节点没有额外的配置项。它是一个纯展示节点，只负责接收上游传递来的文本数据并展示给用户。

你不需要在这个节点上做任何配置——只需要将它放在画布上，并将上游节点的文本输出端口连接到它的"文本"输入端口即可。

## 使用示例

### 示例一：简单的问答工作流

最基础的工作流模式——用户提问，AI 回答：

1. **手动触发器** — 用户输入问题。
2. **LLM 模型** — 配置使用的 AI 模型。
3. **LLM Agent** — 设置系统提示词，接收用户问题并生成回答。
4. **文本输出** — 展示 Agent 的回答内容。

将 LLM Agent 的"回复"端口（text 类型）连接到文本输出的"文本"端口，Agent 生成的回复就会作为工作流的最终输出。

### 示例二：翻译工作流

1. **手动触发器** — 用户输入待翻译的文本。
2. **LLM Agent** — 系统提示词设为"你是一名专业翻译，将用户输入翻译为英文。只返回翻译结果。"
3. **文本输出** — 展示翻译后的英文文本。

### 示例三：多分支输出

在条件分支工作流中，不同分支的结果通过不同的文本输出节点展示：

1. **触发器** — 接收用户输入。
2. **LLM Agent** — 分析输入内容的类型并给出分类标签。
3. **条件分支** — 根据分类标签分流。
4. **文本输出 A**（IF 分支：技术问题）— 展示技术问答结果。
5. **文本输出 B**（ELSE 分支：其他问题）— 展示通用回答结果。

每个文本输出节点独立展示其所在分支的结果。在执行结果页面中，你可以看到哪个分支被实际触发以及该分支的输出内容。

### 示例四：报告生成与展示

1. **定时触发器** — 每周一上午 9 点自动触发。
2. **HTTP 请求节点** — 从数据 API 获取过去一周的数据。
3. **LLM Agent** — 根据数据生成 Markdown 格式的周报。
4. **文本输出** — 展示格式化的周报。

由于文本输出支持 Markdown 渲染，报告中的标题、列表、表格、代码块等元素都能正确展示。

## 与 JSON 输出的对比

| 对比维度 | 文本输出 | JSON 输出 |
|----------|----------|-----------|
| 接收数据类型 | text | json |
| 展示格式 | 纯文本或 Markdown 渲染 | 格式化缩进的 JSON 视图 |
| 适用内容 | 自然语言、报告、代码片段 | 结构化对象、数组、键值对 |
| 端口形状 | 圆形（Text 类型） | 方形（JSON 类型） |

如果不确定用哪个：

- 上游是 LLM Agent 的"回复"端口 — 使用 **文本输出**。
- 上游是 LLM Agent 的"结构化"端口 — 使用 **JSON 输出**。
- 上游是 HTTP 请求的"响应体"端口 — 使用 **JSON 输出**。

## 注意事项

1. **内联预览**：在工作流执行期间，文本输出节点的画布卡片上会实时显示已接收到的内容片段。内容较长时会截断显示，完整内容可在执行结果页面查看。
2. **仅接收文本**：文本输出节点只接收 text 类型的数据。如果你需要展示 JSON 结构化数据，请使用 JSON 输出节点。如果上游输出的是 json 类型，端口不兼容，需要通过输入预处理器做类型转换。
3. **Markdown 支持**：输出内容支持 Markdown 格式渲染，包括标题、列表、表格、代码块（带语法高亮）、粗体、斜体等。如果你的 Agent 输出 Markdown 格式的内容，文本输出节点会自动渲染。
4. **多个文本输出**：一个工作流中可以有多个文本输出节点。每个节点独立接收和展示数据。在执行结果页面中，所有文本输出节点的内容都会被展示。
5. **空输出处理**：如果上游节点没有产出文本数据（例如 Agent 返回了空回复），文本输出节点会显示为空。这不会导致工作流执行失败。
