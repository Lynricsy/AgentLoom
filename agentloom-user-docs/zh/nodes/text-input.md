# 文本输入

## 功能说明

文本输入节点是工作流的入口节点之一。在 AgentLoom 中，文本输入通常由触发器节点的"触发数据"端口提供。触发器节点（手动触发器、定时触发器、Webhook 触发器和 API 事件触发器）在被触发时会携带输入数据，这些数据通过触发器的输出端口传递给工作流中的下游节点。

对于手动触发器，用户在运行工作流时可以通过表单填写输入内容；对于 Webhook 和 API 事件触发器，输入数据来自外部 HTTP 请求的载荷。

## 使用场景

- **用户输入处理**：手动触发工作流时，用户填写的表单内容作为工作流的起始数据传递到后续的 AI 推理或数据处理节点。
- **外部数据接入**：Webhook 或 API 事件触发时，外部系统传入的数据作为工作流的输入源。
- **固定文本注入**：在工作流中需要一段固定的模板文本作为某个节点的输入时。

## 端口说明

触发器节点的输出端口提供工作流输入数据。

### 手动触发器输出端口

| 端口名称 | 数据类型 | 说明 |
|----------|----------|------|
| exec | exec | 执行流出口，触发后启动工作流 |
| 触发数据 | json | 手动触发时传入的表单参数数据 |

### 工作流输入参数配置

工作流支持通过 `input_schema` 定义结构化的输入参数。你可以配置：

- **表单模式（form）**：用户通过结构化表单填写输入。适合参数明确、类型固定的场景。
- **对话模式（conversation）**：用户通过自然语言输入。适合开放式输入的场景。
- **混合模式（hybrid）**：同时支持表单和对话输入。

## 配置项

### 输入参数定义

在工作流设置中（而非单个节点），你可以定义工作流的输入参数 Schema：

| 配置 | 说明 |
|------|------|
| 参数名称 | 每个输入参数的名称标识 |
| 参数类型 | 支持文本、数字、布尔值、JSON 等 |
| 是否必填 | 控制运行时是否强制要求填写 |
| 默认值 | 未填写时使用的默认值 |
| 描述 | 向用户说明这个参数的含义 |

### 采集模式

| 模式 | 说明 |
|------|------|
| form | 结构化表单，每个参数独立填写 |
| conversation | 对话式输入，自由文本 |
| hybrid | 表单 + 对话混合 |

## 使用示例

### 示例一：表单式输入

创建一个文本翻译工作流：

1. 放置一个 **手动触发器** 节点。
2. 在工作流设置中定义两个输入参数：
   - `sourceText`（类型：文本，必填，描述："请输入要翻译的文本"）
   - `targetLanguage`（类型：文本，必填，默认值："英文"，描述："目标语言"）
3. 将触发器的"触发数据"端口连接到 Agent 节点的输入。
4. 运行工作流时，用户会看到一个包含两个输入框的表单。

### 示例二：对话式输入

创建一个通用 AI 助手工作流：

1. 放置一个 **手动触发器** 节点。
2. 将工作流输入参数采集模式设为 `conversation`。
3. 运行时用户可以直接用自然语言描述需求，不需要填写固定格式的表单。

## 注意事项

1. **触��器是入口**：工作流的输入数据总是通过触发器节点进入。确保将触发器的输出端口正确连接到需要接收数据的下游节点。
2. **数据格式**：触发器输出的是 JSON 格式的数据。如果下游节点期望纯文本输入，可能需要在中间使用输入预处理器节点做格式转换。
3. **必填校验**：如果定义了必填参数，用户在运行工作流时必须填写这些参数，否则无法启动。
