# 技能节点

## 功能说明

技能（Skill）节点用于将预定义的行为指令注入到 Agent 的系统提示中，增强 Agent 在特定领域的能力。你可以把技能理解为一套"操作手册"——当 Agent 被赋予某个技能后，它会按照技能中定义的流程、标准和最佳实践来执行任务。

每个技能通过一份 SKILL.md 文件定义其内容，包含 YAML 格式的元数据和 Markdown 格式的指令正文。

## 使用场景

- **代码审查**：使用"代码审查"技能，让 Agent 按照特定的审查标准和流程来检查代码。
- **文档编写**：使用"文档编写"技能，让 Agent 遵循文档模板和写作规范来生成文档。
- **测试生成**：使用"测试生成"技能，让 Agent 按照测试策略和覆盖要求来编写测试用例。

## 端口说明

### 输入端口

| 端口名称 | 数据类型 | 必需 | 说明 |
|----------|----------|------|------|
| exec | exec | 否 | 执行流入口，前序节点完成后解析 Skill 内容 |

### 输出端口

| 端口名称 | 数据类型 | 说明 |
|----------|----------|------|
| exec | exec | 执行流出口 |
| Skill | skill | 预定义的能力模板，连接到 Agent 后可按需激活使用 |

## 配置项

### 技能选择

在配置面板中选择要使用的技能。

| 配置 | 必需 | 说明 |
|------|------|------|
| Skill ID | 是 | 关联的技能 ID |
| 技能名称 | 否 | 技能显示名称 |
| 技能描述 | 否 | 技能功能描述 |

> 界面提示：配置面板会显示技能的名称和描述信息，帮助你确认选择了正确的技能。

### 内置技能

AgentLoom 预置了 5 个常用技能，可以直接使用：

| 技能 | 说明 |
|------|------|
| Code Review | 代码审查 — 指导 Agent 按照最佳实践检查代码质量、安全性和可维护性 |
| Documentation | 文档编写 — 指导 Agent 按照文档模板和写作规范生成技术文档 |
| Test Generation | 测试生成 — 指导 Agent 按照测试策略编写全面的测试用例 |
| Refactoring | 代码重构 — 指导 Agent 按照重构原则优化代码结构 |
| Debugging | 调试排错 — 指导 Agent 按照系统化的排查流程定位和解决问题 |

### 自定义技能

除了内置技能，你还可以创建自定义技能：

> 界面提示：在 "设置 > Skills" 页面中，你可以创建新的技能，通过 Monaco 代码编辑器编写 SKILL.md 内容。

自定义技能的 SKILL.md 文件包含：

- **YAML Frontmatter**：技能的元数据（名称、描述、分类等）。
- **Markdown 正文**：具体的行为指令和操作流程。

## 使用示例

### 示例一：代码审查工作流

1. 放置一个 **手动触发器** — 用户提交代码。
2. 放置一个 **技能** 节点，选择"Code Review"技能。
3. 放置一个 **Agent** 节点（引用一个配置了编程相关工具的 Agent）。
4. 将技能的"Skill"端口连接到 Agent 的"Skills"端口。
5. 将触发器的文本输出连接到 Agent 的输入。
6. Agent 在审查代码时会自动遵循代码审查技能中定义的流程和标准。

### 示例二：多技能叠加

为一个 Agent 同时赋予多种技能：

1. 放置两个 **技能** 节点，分别选择"Code Review"和"Test Generation"。
2. 将两个技能的输出端口都连接到同一个 Agent 节点的"Skills"端口（该端口支持多连接）。
3. Agent 在处理任务时，会综合运用代码审查和测试生成两种技能。

## 注意事项

1. **技能注入机制**：技能内容通过 SkillResolverService 生成 XML 格式的文本，注入到 Agent 的系统提示中。这意味着技能会占用系统提示的 Token 空间。
2. **内置技能不可删除**：5 个内置技能由系统维护，标记为 `isBuiltin = true`，不能被删除。
3. **技能管理**：技能的创建和管理在"设置 > Skills"页面中进行，而不是在工作流画布中。画布中的技能节点只是引用已有的技能。
4. **技能启停**：在技能管理页面中，你可以启用或停用特定的技能。停用的技能不会被 Agent 使用。
5. **多技能时的 Token 消耗**：同时启用多个技能会增加系统提示的长度，从而增加 Token 消耗。建议只启用当前任务真正需要的技能。
