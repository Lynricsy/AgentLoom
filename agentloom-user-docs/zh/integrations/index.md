# 集成连接

AgentLoom 提供了丰富的集成能力，让你的工作流能够连接外部工具和服务。通过集成，Agent 可以调用外部 API、使用 MCP 工具、运行插件，甚至与其他平台无缝协作。

## 集成概述

AgentLoom 支持以下几种集成方式：

### API 密钥

AgentLoom 提供了开放的 REST API，你可以通过 API 密钥从外部系统调用 AgentLoom 的各种功能。适合需要将 AgentLoom 嵌入到已有系统或工作流中的场景。

- 创建和管理 API Token
- 通过 API 触发工作流执行
- 从外部应用查询执行结果

详细说明请参考 [API 密钥管理](./api-keys.md)。

### MCP 工具

MCP（Model Context Protocol）是一种让 AI Agent 连接外部工具的标准协议。通过 MCP，你可以将各种外部服务和工具接入 AgentLoom，让 Agent 在执行任务时能够调用这些工具。

- 连接 MCP 服务器
- 发现和导入工具
- 在工作流中使用 MCP 工具

详细说明请参考 [MCP 工具](./mcp-tools.md)。

### 插件

插件是 AgentLoom 生态系统的重要组成部分。通过插件，你可以扩展平台的功能，添加自定义的节点类型和处理逻辑。

- 从市场浏览和安装插件
- 管理已安装的插件
- 了解插件的安全和权限机制

详细说明请参考 [使用插件](./plugins.md)。

## 可连接的外部服务类型

通过上述集成方式，AgentLoom 可以连接以下类型的外部服务：

### AI 模型服务

连接各种 AI 模型提供商（如 OpenAI、Anthropic 等），为 Agent 提供不同能力的 AI 模型支持。模型配置在工作流的 Agent 节点中完成。

### 代码仓库

通过 Webhook 或 API 事件触发器，连接 GitHub 等代码托管平台。常见的集成场景包括：

- 代码推送时自动触发代码审查工作流
- 新的 Pull Request 时自动生成审查报告
- Issue 创建时自动分类和分配

### 数据存储

Agent 可以通过 MCP 工具连接外部数据库和存储服务，读取或写入数据。

### 通信工具

通过集成通信平台（如 Slack、飞书等），Agent 可以在工作流执行完成后自动发送通知，或者从消息中触发工作流。

### 自定义服务

通过 MCP 协议，你可以将任何支持 HTTP 的内部或外部服务接入 AgentLoom，让 Agent 调用这些服务的功能。

## 集成安全

所有集成功能都遵循 AgentLoom 的安全策略：

- **认证**：所有 API 调用都需要有效的认证信息（JWT Token 或 API Key）
- **租户隔离**：集成配置和数据严格按组织隔离
- **权限控制**：不同的集成操作需要对应的角色权限
- **限流保护**：API 调用有速率限制，防止滥用
- **审计记录**：重要的集成操作会被记录到审计日志
