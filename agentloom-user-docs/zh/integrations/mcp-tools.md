# MCP 工具

MCP（Model Context Protocol，模型上下文协议）是一种让 AI Agent 连接外部工具和服务的标准协议。通过 MCP，你可以将各种外部能力接入 AgentLoom，让 Agent 在执行任务时调用这些外部工具。

## MCP 是什么

简单来说，MCP 是一种「让 AI 使用工具」的标准方式。就像人类使用工具来完成工作一样，AI Agent 也需要工具来执行具体的操作 -- 比如搜索网页、读写文件、查询数据库、调用 API 等。

MCP 定义了 Agent 和工具之间的通信规则：

- Agent 知道有哪些工具可用（工具发现）
- Agent 知道每个工具需要什么输入、会返回什么输出（工具描述）
- Agent 在需要时可以调用工具（工具执行）

通过 MCP，你不需要为每个外部服务都编写定制化的集成代码。只要外部服务提供了 MCP 接口，AgentLoom 就能自动发现和使用它的功能。

## 连接 MCP 服务器

MCP 工具由 MCP 服务器提供。你需要先将 MCP 服务器连接到 AgentLoom，然后才能使用其中的工具。

### 管理权限

MCP 服务器的连接和管理需要所有者（Owner）或管理员（Admin）角色。

### 连接步骤

> 界面提示：在 AgentLoom Studio 中，依次进入「设置」页面，找到 MCP 工具管理区域。

#### 1. 测试连接

在添加 MCP 服务器之前，建议先测试连接是否正常。

> 界面提示：在 MCP 管理页面中，点击「测试连接」按钮。

输入 MCP 服务器的连接信息后，系统会尝试建立连接并返回测试结果。如果连接失败，请检查服务器地址、端口和认证信息是否正确。

#### 2. 发现工具

连接成功后，你可以让 AgentLoom 自动发现 MCP 服务器上可用的工具列表。

> 界面提示：点击「发现工具」按钮，系统会列出 MCP 服务器提供的所有工具及其描述。

发现的工具列表会显示：

- 工具名称
- 工具描述
- 输入参数说明
- 输出格式说明

#### 3. 导入工具

从发现的工具列表中选择需要使用的工具，将它们导入到 AgentLoom 中。

> 界面提示：在工具列表中选择需要的工具，点击「导入」按钮即可。

导入后的工具会出现在 AgentLoom 的工具定义列表中，可以在工作流画布中使用。

### 管理已连接的服务器

#### 查看服务器列表

> 界面提示：在 MCP 管理页面的「已配置服务器」区域，可以看到所有已连接的 MCP 服务器列表。

服务器列表支持分页浏览，显示每个服务器的名称和连接状态。

#### 查看服务器详情

点击某个服务器，可以查看其详细配置信息和关联的工具列表。

#### 更新服务器配置

如果 MCP 服务器的地址或认证信息发生变化，你可以更新已保存的配置。

#### 重新发现工具

如果 MCP 服务器上的工具有更新（新增或移除了工具），你可以重新发现工具并更新本地的工具列表。

#### 重新导入工具

当 MCP 服务器上的工具定义发生变化（如参数格式更新）时，可以重新导入工具以同步最新的工具定义。

#### 测试已保存的配置

随时测试已保存的 MCP 服务器配置是否仍然可以正常连接。

#### 删除服务器配置

如果不再需要某个 MCP 服务器，可以删除其配置。删除后，通过该服务器导入的工具定义也会被移除。

## 管理工具定义

### 查看工具列表

> 界面提示：在 MCP 管理页面中，可以查看所有已导入的工具定义列表。

工具列表支持按来源筛选：

- **MCP**：通过 MCP 服务器导入的工具
- **内置（Builtin）**：AgentLoom 平台内置的工具
- **自定义（Custom）**：手动创建的自定义工具

### 停用工具

如果某个已导入的工具暂时不需要使用，你可以将其停用。停用后的工具不会出现在工作流画布的工具选择中。

## 在工作流中使用 MCP 工具

将 MCP 工具导入到 AgentLoom 后，你可以在工作流画布中使用这些工具。

### 连接 Agent 节点

MCP 工具通常通过工具节点连接到 Agent 节点。当 Agent 执行时，它可以根据任务需要自主决定是否调用这些工具以及如何使用工具的返回结果。

### 工具的端口类型

MCP 工具在画布中作为 `tool` 类型的端口连接到 Agent 节点。AgentLoom 的端口兼容性检查器会自动验证连接是否有效。

### 运行时行为

当工作流执行到 Agent 节点，且该 Agent 配置了 MCP 工具时：

1. Agent 会收到可用工具的列表和描述
2. Agent 根据当前任务判断是否需要使用工具
3. 如果需要，Agent 会生成工具调用请求
4. 系统将请求发送到 MCP 服务器执行
5. 执行结果返回给 Agent
6. Agent 基于工具返回的结果继续处理任务

这个过程对于终端用户是透明的 -- Agent 会自主决定何时使用工具以及如何使用。

## 常见问题

### MCP 服务器连接失败

可能的原因：
1. 服务器地址或端口不正确
2. 网络连接问题或防火墙阻拦
3. 认证信息不正确
4. MCP 服务器未启动或不可用

### 发现工具时返回空列表

可能的原因：
1. MCP 服务器尚未注册任何工具
2. 连接的不是正确的 MCP 端点
3. MCP 服务器版本不兼容

### 工具执行超时

MCP 工具的执行时间取决于外部服务的响应速度。如果工具频繁超时，请检查 MCP 服务器和其依赖的外部服务是否正常运行。
