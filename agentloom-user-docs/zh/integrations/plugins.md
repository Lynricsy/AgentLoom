# 使用插件

插件是 AgentLoom 生态系统中用于扩展平台功能的独立模块。通过插件，你可以为工作流添加自定义的处理逻辑和节点类型，无需修改平台本身的代码。

## 插件是什么

在 AgentLoom 中，插件是一个打包好的功能模块，可以在工作流中作为节点使用。每个插件包含：

- **功能逻辑**：插件要执行的具体操作
- **节点定义**：插件在工作流画布中的节点类型、输入输出端口
- **清单信息（Manifest）**：插件的名称、描述、版本等元数据
- **数字签名**：确保插件来源可信且未被篡改

插件在安全隔离的沙箱环境中运行（基于 WASM 技术），确保插件的执行不会影响平台和其他工作流的稳定性。

## 从市场安装插件

最简单的方式是从 AgentLoom 市场安装其他开发者发布的插件。

### 浏览插件

> 界面提示：进入 AgentLoom 市场页面，在类型筛选中选择「插件」，即可只浏览插件类型的内容。

市场中的插件会显示以下信息：

- 插件名称和描述
- 开发者信息
- 安装量和评分
- 定价模式（免费 / 按执行付费）

### 安装步骤

1. 在市场中找到需要的插件
2. 查看插件详情，了解其功能和使用方式
3. 点击「安装」按钮
4. 确认安装

安装完成后，插件会出现在你的组织的插件列表中，其提供的节点类型可以在工作流画布中使用。

### 安装权限

以下角色可以安装插件：

- 所有者（Owner）
- 管理员（Admin）
- 创建者（Creator）
- 操作者（Operator）

## 管理已安装插件

### 查看插件列表

> 界面提示：在 AgentLoom Studio 的设置或资源页面中，可以找到已安装插件的列表。

插件列表显示以下信息：

- 插件名称
- 版本号
- 状态（启用 / 禁用）
- 安装时间

### 启用和禁用

你可以切换插件的启用状态。禁用插件后，其提供的节点类型在画布中不可用，但已使用该插件节点的工作流定义不会被删除。

### 更新插件状态

插件的状态管理支持以下操作：

- **启用**：让插件正常工作
- **禁用**：临时停用插件
- **删除**：从组织中移除插件

## 在工作流中使用插件

安装并启用插件后，你可以在工作流画布中使用插件提供的节点类型。

### 添加插件节点

> 界面提示：在工作流画布的节点面板中，已安装的插件节点会出现在可用节点列表中。将其拖拽到画布上即可添加。

### 配置插件节点

插件节点的配置取决于插件本身的定义。点击画布上的插件节点，在右侧配置面板中按照插件要求填写输入参数。

### 连接其他节点

插件节点可以像其他节点一样通过端口与工作流中的其他节点连接。端口的类型和数量由插件的节点定义决定。

## 插件的安全机制

AgentLoom 对插件的安全性有严格的保障：

### WASM 沙箱隔离

每个插件在独立的 WebAssembly（WASM）沙箱中运行。这意味着：

- 插件无法直接访问平台的文件系统和网络
- 插件无法影响其他插件或工作流的运行
- 即使插件代码存在缺陷，也不会影响平台的稳定性

### 资源限制

插件的执行受到以下限制：

- **执行超时**：单次执行最长 30 秒
- **内存限制**：每个插件实例有独立的内存上限
- 超出限制的插件执行会被自动终止

### 数字签名验证

每个插件都包含开发者的数字签名（RSA-PSS）。AgentLoom 在注册插件时会验证签名，确保：

- 插件确实来自声称的开发者
- 插件内容在发布后未被篡改

### 开发者密钥管理

插件的签名验证依赖于开发者密钥系统：

- 开发者需要注册 RSA 公钥才能发布插件
- 组织可以管理已注册的开发者密钥
- 可以撤销不受信任的开发者密钥

## 插件的使用量和费用

### 使用量记录

每次插件执行都会被记录，包括：

- 执行时长
- 输入和输出的 Token 数量
- 计费金额（如果适用）

### 费用模式

市场中的插件支持两种定价模式：

- **免费**：安装和使用均不收费
- **按执行付费**：每次执行产生费用，费用根据使用量计算

### 收益分成

对于付费插件，平台采用以下收益分成模型：

- 开发者获得约 59.5% 的收入
- 平台获得约 30% 的收入
- 其余部分为上架佣金

## 常见问题

### 安装的插件在画布中找不到节点

可能的原因：
1. 插件处于禁用状态
2. 需要刷新画布页面以加载新安装的插件
3. 插件可能没有定义画布节点（纯后端处理插件）

### 插件执行失败

可能的原因：
1. 插件执行超时（超过 30 秒限制）
2. 输入参数格式不正确
3. 插件依赖的外部服务不可用
4. 插件内部逻辑错误

检查工作流执行日志可以看到详细的错误信息。

### 如何确认插件是否安全

AgentLoom 通过以下机制保障插件安全：
1. 数字签名验证确保来源可信
2. WASM 沙箱隔离防止恶意行为
3. 资源限制防止过度消耗
4. 市场审查确保基本质量

建议优先安装评分较高、安装量较大的插件。
