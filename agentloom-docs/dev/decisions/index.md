## 模板

新建 `NNNN-<kebab-标题>.md`，编号取现有最大号加一，复制以下结构：

```markdown
---
docType: explanation
---

# NNNN 标题

- 状态：提议
- 日期：YYYY-MM-DD

## 背景

（决策时的事实与约束，带源码位置；只写当时为真的事）

## 决策

（选了什么；被否决的方案各自为什么不选）

## 后果

（变容易的事、变困难的事、需要遵守的新约束）

## 确认方式

（怎样验证决策已被执行：测试、检查命令、可观察的系统行为）
```

状态取值：提议、已接受、已实施、已废弃（被 NNNN 取代）。已接受的 ADR 不改正文，只在「状态」行追加变化。
