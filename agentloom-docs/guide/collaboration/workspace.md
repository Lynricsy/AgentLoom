# 管理组织成员

组织是成员与资源的共同边界：组织内的工作流、Agent、知识库等资源对组织成员可见，对其他组织不可见。本页说明如何查看组织信息、邀请成员、修改角色与移除成员。各角色能做什么见 [角色与权限](/guide/collaboration/roles)。

组织在注册后的初始化向导「创建组织」一步中建立，创建者成为 owner，见 [快速开始](/guide/getting-started/quickstart)。组织名称创建后不能在 Studio 中修改；Studio 也没有在多个组织之间切换的入口。

前提：查看成员名册与以下所有操作都需要 owner 或 admin 角色。其他角色在成员名册位置看到「无权查看成员名册」。

## 查看组织信息

1. 点击侧边栏底部的「设置」，在「通用」分组中点击「组织」（路径 `/settings/organization`）。

   页面标题为「组织」。信息卡片显示组织名称、状态（「正常」或「已停用」）、「标识」「成员数」「创建时间」「组织 ID」；下方「成员名册」列出每个成员的「邮箱」「显示名」「角色」「加入时间」。

## 邀请成员

::: warning 邀请不会发送邮件
当前版本服务端只生成邀请记录，不发送邮件，Studio 也不显示邀请链接；对话框中的「邀请已发送」提示并不表示对方收到了任何消息。邀请链接为 `<Studio 地址>/invitations/<token>`，`token` 只出现在接口 `POST /api/v1/organizations/<组织 ID>/invitations` 的响应 `data.token` 中，需要由调用接口的管理员把链接转交给对方。
:::

1. 在「组织」页右上角点击「邀请成员」。
2. 在「邀请成员」对话框中填写「邮箱」，在「角色」中选择角色（默认「访客」），下拉框下方显示所选角色的说明。
3. 点击「发送邀请」。

   页面提示「邀请已发送」。邀请有效期 7 天。失败时对话框显示服务端返回的原因，例如「该邮箱 "…" 已有待处理的邀请」「该用户已经是此组织的成员」「管理员不能邀请用户为所有者角色」。

## 接受邀请

被邀请人执行以下步骤：

1. 在浏览器中打开邀请链接。未登录时先跳转到登录页，登录（或注册）后自动回到邀请页。

   页面显示「正在接受邀请」，成功后提示「已加入组织」「欢迎加入「组织名」。」并跳转到工作台。链接过期或已被使用时显示「邀请无法接受」，并提供「返回工作台」。

接受邀请只在账号还没有当前组织时把新组织设为当前组织。已经属于另一个组织的账号接受邀请后，仍停留在原组织中。

## 修改成员角色

1. 在「成员名册」中，从目标成员「角色」列的下拉框选择新角色。

   页面提示「角色已更新」，服务端立即按新角色校验该成员的请求；该成员的 Studio 界面在重新登录后才按新角色显示入口。把最后一名 owner 改为其他角色时提示失败（409 `sole-owner-constraint`）。

## 移除成员

1. 在「成员名册」中点击目标成员所在行的移除按钮。
2. 在「移除成员」确认框中点击「移除」。

   页面提示「成员已移除」，该成员立即失去组织内全部资源的访问权限。该成员创建的资源保留在组织中。不能移除最后一名 owner；admin 不能移除 owner。
