# 开发者控制台

开发者控制台用于两件事：登记插件签名用的开发者公钥，以及查看插件在市场上的收益与推进打款。插件的开发、打包与签名见 [插件开发教程](/api/plugins/tutorial)，分成比例与结算规则见 [市场与收益](/api/plugins/marketplace)。

| 标签 | 路径 | 可见角色 |
| --- | --- | --- |
| 开发者密钥 | `/developer-console/keys` | owner、admin、creator |
| 收益 | `/developer-console/earnings` | owner、admin |

侧边栏「探索」分组中的「开发者」入口只对这三种角色显示：owner 与 admin 点击后进入「收益」，creator 进入「开发者密钥」。operator 与 viewer 看不到入口，直接打开路径时显示「无权访问「…」」。

## 登记开发者公钥

平台注册 `.alp` 插件包时，按包内签名对应的公钥指纹在本组织已登记的公钥中查找；找不到有效公钥时拒绝注册。

前提：你已用 `agentloom-plugin keys generate` 生成密钥对，手里有 SPKI 格式的 PEM 公钥文件（如 `keys/public.pem`）。生成方法见 [插件开发教程](/api/plugins/tutorial)。

1. 打开侧边栏「开发者」，切换到「开发者密钥」标签，点击右上角「注册公钥」。

   弹出「注册开发者公钥」对话框。

2. （可选）填写「标签（可选）」，例如「CI 签名密钥」，用于区分多台构建机或多个成员的密钥。
3. 在「公钥（PEM）」中粘贴公钥文件的全部内容，包括 `-----BEGIN PUBLIC KEY-----` 与 `-----END PUBLIC KEY-----` 两行。不要粘贴私钥。
4. 点击「注册公钥」。

   对话框变为「公钥注册成功」并显示「密钥指纹」，可点击「复制指纹」。该指纹应与 `agentloom-plugin keys generate` 输出的指纹一致。同一公钥在组织内只能登记一次。

列表按「标签」「指纹」「状态」「创建时间」显示组织内**所有成员**登记的公钥，可在「按状态筛选」中选择「全部状态」「有效」「已撤销」。

## 撤销开发者公钥

私钥泄露或构建机下线时撤销对应公钥。撤销不可恢复。

1. 在「开发者密钥」列表中，点击目标公钥所在行的「撤销」。
2. 在「撤销开发者密钥？」确认框中点击「确认撤销」。

   页面提示「密钥已撤销」「使用该密钥签名的插件包将不再通过验签。」，状态变为「已撤销」。creator 也可以撤销组织内其他成员登记的公钥。

## 查看收益

1. 打开侧边栏「开发者」，切换到「收益」标签。

   页面依次显示：

   - 汇总卡片：「总收入」「本月收入」「开发者分成」「待打款」「已打款」「总使用次数」「活跃插件数」，金额以 USD 显示。
   - 「月度收入趋势」图表与「插件使用排名」表（「插件名称」「使用次数」「收入」「占比」）。
   - 「结算历史」表：「期间」「插件名」「使用量」「总收入」「开发者份额」「状态」。

结算记录由平台每月自动生成，规则见 [市场与收益](/api/plugins/marketplace)。

## 推进打款状态

打款在平台外完成，这里只记录进度。结算记录的状态为「待处理」「处理中」「已完成」「失败」。

1. 在「结算历史」的「打款操作」列点击下一步操作：

   | 当前状态 | 可用操作 |
   | --- | --- |
   | 待处理 | 标记处理中 |
   | 处理中 | 标记完成、标记失败 |
   | 失败 | 重试处理（回到「处理中」） |
   | 已完成 | 无（显示「终态」） |

   点击「标记处理中」「标记失败」「重试处理」时立即生效，页面提示「打款状态已更新」。

2. 点击「标记完成」时，弹出「标记打款完成」对话框，可在「打款凭证号 (可选)」中填写银行流水号或转账单号，点击「确认完成」。

   状态变为「已完成」，之后不能再变更。
