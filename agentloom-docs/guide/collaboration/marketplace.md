# 市场

市场让组织之间共享工作流与插件：你可以把其他组织上架的条目安装到本组织，也可以把自己的工作流或插件上架。本页按「浏览与安装」「评价」「上架」「管理我的发布」组织。插件开发者的分成与结算见 [开发者控制台](/guide/collaboration/developer-console)。

## 浏览市场

1. 在侧边栏「探索」分组点击「市场」（路径 `/marketplace`）。

   页面列出已上架的工作流与插件，每页 12 条。「发现」（`/discover`）页面展示同一份内容。

2. 用页面顶部的控件缩小范围：
   - 搜索框「搜索市场工作流或插件」；
   - 类型：「全部内容」「工作流」「插件」；
   - 分类：「全部」「分析」「内容」「开发」「自动化」「报告」；
   - 定价：「全部定价」「免费」「按次计费」；
   - 排序：「最受欢迎」「评分最高」「最新发布」。

   没有匹配项时显示「未找到工作流或插件」。

3. 点击一个条目打开「市场条目详情」：工作流显示「工作流预览」，插件显示「插件信息」（「插件 ID」「开发者」「许可协议」），下方是评价列表。

## 安装条目

前提：你的角色是 owner、admin、creator 或 operator。

1. 在「市场条目详情」中点击「安装到工作区」。
2. 在「安装 Marketplace 工作流」或「安装 Marketplace 插件」对话框中，按需修改名称（默认为条目标题）与「描述 (可选)」，点击「确认安装」。

   对话框显示「安装成功」：
   - **工作流**：本组织新增一个工作流副本，与市场中的原条目互不影响，可以继续编辑和运行；它和新建的工作流一样需要发布后才能被触发器启动。
   - **插件**：插件副本进入「资源 → 插件」，状态为启用，其节点出现在画布节点面板的 Plugin 分组；点击「前往插件管理」查看。

插件副本的升级与卸载见 [使用插件](/guide/integrations/plugins)。

## 发表评价

1. 在「市场条目详情」的「写下你的评价」中选择 1 到 5 星，「评价内容（可选）」最多 2000 字，点击「提交评价」。

   提示「评价已提交」，评价公开显示在条目详情中，条目的平均分随之更新。每个账号对同一条目只能评价一次，再次提交时提示「无法重复评价」。评价插件条目要求本组织已安装该插件。

## 上架工作流

前提：

- 你的角色是 owner、admin 或 creator。
- 工作流已发布且未归档；所有 Agent 节点都绑定了已发布的 Agent；已发布版本在过去 30 天内至少成功执行过一次。提交时服务端逐项审查，不满足的项会在「审核未通过」中列出。

1. 打开工作流画布，点击顶部工具栏「发布到市场」。
2. 在「发布到市场」对话框中填写：
   - 「标题」：5 到 120 个字符；
   - 「简介」：30 到 500 个字符；
   - 标签：1 到 8 个，每个最多 32 个字符，输入后按 Enter 或逗号确认；
   - 「封面图片 URL (可选)」。
3. 点击「提交到市场」。

   审查立即完成。通过时提示「提交成功」「工作流已通过审核并上架市场」；不通过时显示「审核未通过，请修复以下问题后重试」与逐项原因（例如「过去 30 天内没有成功的执行记录」「N 个 Agent 节点配置不完整」）。同一工作流版本已提交过时提示「已存在」。

## 上架插件

前提：你的角色是 owner、admin 或 creator；插件已在「资源 → 插件」中注册且状态为启用。

1. 在侧边栏「资源 → 插件」的插件列表中，点击目标插件行的发布按钮。
2. 在「发布到市场」对话框中填写「标题」「简介」、标签、「分类 (可选)」，在「计费模式」中选择「免费」或「按次计费」；按次计费时填写「每次执行单价 (USD)」（非负，最多 8 位小数）。
3. 点击「提交到市场」。

   审查通过时提示「审核通过」「插件已上架到市场」。该插件已有发布记录时提示到「我的市场发布」中编辑它。

## 管理我的发布

1. 在「市场」页右上角点击「我的发布」（路径 `/marketplace/my-listings`）。

   页面「我的市场发布」列出本组织提交过的条目，可按「全部」「已上架」「审核中」「审核未通过」「已下架」筛选。

2. 对单个条目执行操作：

   | 状态 | 操作 | 结果 |
   | --- | --- | --- |
   | 已上架 | 「下架」→ 确认框「确认下架」 | 提示「下架成功」，条目不再出现在市场中 |
   | 已下架 | 「重新上架」 | 重新审查，通过时提示「重新上架成功」 |
   | 审核未通过 | 「查看审核结果」、「重新提交」 | 查看逐项原因，修复后重新审查 |
   | 任意（仅插件） | 「编辑」→「保存并重新审查」 | 修改后重新审查；不通过时已上架的插件被下架 |
