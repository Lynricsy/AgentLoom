# 知识库

知识库保存你上传的文档。文档上传后自动解析、切分为知识节点并建立向量索引；Agent 通过连接的知识库节点检索这些内容来回答问题。知识库在侧边栏「资源」组的「知识库」入口（`/resources/knowledge-bases`）中管理。

| 你要做的事 | 页面 |
| --- | --- |
| 创建知识库、上传与删除文档 | [创建知识库](/guide/knowledge-base/creating) |
| 调整分块、检索、重排与查询策略，测试检索效果 | [检索配置](/guide/knowledge-base/retrieval) |
| 让 Agent 或工作流使用知识库 | [在工作流中使用知识库](/guide/knowledge-base/in-workflows) |
