# 检索配置

本页说明如何调整一个知识库的分块、检索、重排与查询策略，并验证检索结果。每个知识库的策略独立设置。前提：已打开知识库详情页。

## 修改策略

在详情页的「检索策略」表单中调整以下项，点击「保存策略」，提示「知识库策略已更新」：

| 设置 | 选项与默认值 |
| --- | --- |
| Embedding 模型 | 默认「使用默认 Embedding Key + 模型名」，也可选择已有模型配置 |
| 分块策略 | 「Sentence Window」（默认，Window Size 默认 3）、「句子分块」（Chunk Size 默认 512，最小 64；Chunk Overlap 默认 64）、「Markdown 分块」 |
| 检索 Top K | 默认 8，最小 1 |
| 相似度阈值 | 0 到 1；留空表示不限制（默认） |
| 重排策略 | 「关闭重排」（默认）或「Cohere Rerank」（可设 Cohere 模型与重排 Top N） |
| Query Orchestration | 「直接查询」（默认）或「HyDE」（可选 HyDE 模型，默认使用默认聊天模型；HyDE Prompt Template 支持 `{{query}}` 占位符，留空使用系统默认提示词） |

## 让新策略对已有文档生效

修改分块策略或 Embedding 模型后，点击详情页顶部的「重建索引/重切分」。提示「已提交 N 个文档的重建任务」，文档重新进入处理流程，状态回到「处理中」，完成后为「已就绪」。

## 测试检索

在「测试检索」区域输入查询问题，点击「执行测试检索」。结果使用当前知识库的完整策略，结果区域显示命中的知识节点。查询为空时提示「请输入测试检索查询」。
