# 创建知识库

本页说明如何创建知识库、上传文档并确认文档已可检索。前提：已登录并加入组织。

## 新建知识库

1. 在侧边栏「资源」组点击「知识库」，进入「知识库管理」页面。
2. 点击「创建知识库」（列表为空时也可点击「创建第一个知识库」），在「创建知识库」对话框中填写「名称」与可选的「描述」，点击「创建」。

新知识库出现在列表中，卡片显示文档数、可见性（新建默认为「私有」）与更新时间。点击卡片进入详情页 `/resources/knowledge-bases/:knowledgeBaseId`。

## 上传文档

1. 在详情页的「文档与构建状态」区域点击「上传文档」，选择文件。支持 PDF、TXT、Markdown 与 DOCX（扩展名 `.pdf`、`.txt`、`.md`、`.docx`），单个文件最大 50 MB。
2. 上传后文档进入解析、切分与索引流程，处理进度依次显示「准备文件」「解析文档」「生成节点」「提交索引」「处理完成」。

文档状态变为「已就绪」后即可被检索；处理失败时状态为「失败」并显示失败原因。可用「文档状态筛选」按全部文档、待处理、处理中、已就绪、失败筛选。

知识库未配置可用的 Embedding 模型时，上传区域会提示「当前知识库未配置可用的 Embedding 模型，上传后的检索质量无法保证」，先按 [检索配置](/guide/knowledge-base/retrieval) 选择 Embedding 模型再上传。

## 删除文档或知识库

- 删除文档：在文档列表中点击该文档的删除按钮，在浏览器确认框中确认。
- 删除知识库：在列表页知识库卡片上点击删除，在「删除知识库」对话框中点击「确认删除」。该操作会同时删除其下文档、知识节点与向量索引，且不可恢复。
