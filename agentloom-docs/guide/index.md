# 用户指南

本分区面向在 AgentLoom Studio 中搭建和运行工作流、Agent 的用户。按你要做的事选择入口。

| 你要做的事 | 从这里开始 |
| --- | --- |
| 第一次使用，想跑通一个完整例子 | [快速开始](/guide/getting-started/quickstart)：创建并发布一个 Agent，再用工作流调用它并查看输出 |
| 先弄清工作流、Agent、节点、端口这些概念 | [核心概念](/guide/getting-started/core-concepts) |
| 找某个菜单、设置项在哪里 | [界面导览](/guide/getting-started/interface-overview)：侧边栏与设置页的全部入口 |
| 在画布上搭建、运行、调试工作流 | [工作流](/guide/workflows/) |
| 查某个节点的端口与配置 | [节点参考](/guide/nodes/) |
| 创建 Agent 并与它对话 | [Agent](/guide/agents/) |
| 让外部系统通过 API 调用已发布的 Agent | [Agent API 访问](/guide/agents/api-access) |
| 上传文档，让 Agent 或工作流检索私有资料 | [知识库](/guide/knowledge-base/) |
| 为 Agent 启用或编写技能 | [技能](/guide/skills/) |
| 让工作流按定时、Webhook 或 API 事件自动运行 | [触发器](/guide/triggers/) |
| 用自然语言描述生成一个应用 | [生成应用](/guide/generated-apps/) |
| 与团队成员共享资源、分配角色、使用市场 | [团队协作](/guide/collaboration/) |
| 接入 MCP 服务、插件或 API Token | [集成](/guide/integrations/) |
| 管理个人账户、安全与通知 | [账户](/guide/account/) |
| 在手机上查看和操作 | [移动端](/guide/mobile/) |
| 参考完整的业务场景示例 | [用例](/guide/use-cases/) |
| 遇到报错或运行结果不符合预期 | [故障排查](/guide/troubleshooting/) |

通过 REST、Webhook 或插件 SDK 与 AgentLoom 集成的开发者，请阅读 [API 与集成](/api/)。
