# 安全设置

安全设置帮助你保护 AgentLoom 账户的安全。本文介绍密码修改、多因素认证（MFA）、会话管理和端到端加密等安全功能。

## 进入安全设置页面

> 界面提示：在 AgentLoom Studio 中，依次点击「设置」，然后选择「安全」选项卡，即可进入安全设置页面。页面路径为 `/settings/security`。

安全设置页面分为三个主要区域：修改密码、多因素认证和活跃会话。

## 修改密码

定期修改密码是保护账户安全的重要措施。

### 密码要求

AgentLoom 的密码需要满足以下要求：

- 至少 8 个字符
- 包含至少一个大写字母
- 包含至少一个小写字母
- 包含至少一个数字

### 修改步骤

> 界面提示：在安全设置页面的「修改密码」区域，可以找到密码修改表单。

1. 在「当前密码」输入框中输入你现在使用的密码
2. 在「新密码」输入框中输入你想设置的新密码
3. 在「确认新密码」输入框中再次输入新密码
4. 点击「修改密码」按钮

如果当前密码输入正确且新密码符合要求，修改会立即生效。修改成功后，你不需要重新登录 -- 当前会话会继续保持有效。

### 忘记当前密码

如果你忘记了当前密码，无法在安全设置中修改。你需要退出登录，然后在登录页面使用「忘记密码」功能通过注册邮箱重置密码。

## 多因素认证（MFA）

多因素认证（Multi-Factor Authentication）为你的账户增加一层额外的安全保护。启用 MFA 后，除了输入密码，登录时还需要提供一个实时生成的验证码。

### MFA 的工作方式

AgentLoom 使用 TOTP（基于时间的一次性密码）作为 MFA 方式：

1. 你在手机上安装一个验证器应用（如 Google Authenticator、Microsoft Authenticator、Authy 等）
2. 在 AgentLoom 中注册 MFA 时，用验证器应用扫描二维码
3. 验证器应用会每 30 秒生成一个新的 6 位数验证码
4. 登录时，输入密码后还需要输入当前的验证码

### 启用 MFA

> 界面提示：在安全设置页面的「多因素认证」区域，如果 MFA 未启用，会显示一个「启用 MFA」按钮。

1. 点击「启用 MFA」按钮
2. 系统会弹出注册对话框，显示一个二维码
3. 打开手机上的验证器应用，扫描该二维码
4. 验证器应用会显示一个 6 位数的验证码
5. 在对话框中输入该验证码以完成验证
6. 验证成功后，MFA 即启用

**重要提示**：
- 请确保验证器应用已成功添加 AgentLoom 的条目后再关闭注册对话框
- 建议同时记下备份恢复码（如果提供），以防手机丢失

### 启用后的登录流程

MFA 启用后，每次登录的流程变为：

1. 输入邮箱和密码
2. 系统提示输入 MFA 验证码
3. 打开验证器应用，输入当前显示的 6 位数验证码
4. 验证通过后完成登录

### 禁用 MFA

如果你需要禁用 MFA（例如更换手机前），可以在安全设置中操作。

> 界面提示：当 MFA 已启用时，安全设置页面会显示「MFA 已启用」状态和「禁用 MFA」按钮。

点击「禁用 MFA」按钮后，系统会移除已注册的验证因子。禁用后，登录时不再需要输入验证码。

**注意**：禁用 MFA 会降低账户安全性。如果只是需要更换验证器设备，建议先禁用再重新启用，完成设备迁移。

## 会话管理

会话管理让你查看和控制所有已登录的设备和浏览器。

### 查看活跃会话

> 界面提示：在安全设置页面的「活跃会话」区域，可以看到所有当前有效的登录会话列表。

每个会话显示以下信息：

- **设备/浏览器**：登录使用的浏览器或设备类型
- **当前会话标记**：如果是你当前正在使用的会话，会显示「当前会话」标识
- **IP 地址**：登录时的 IP 地址
- **活跃时间**：最近一次使用该会话的时间

### 撤销其他会话

如果你发现一个不认识的会话，或者在公共设备上忘记退出，可以远程撤销该会话。

> 界面提示：在每个非当前会话旁边，有一个撤销按钮（垃圾桶图标），点击即可撤销。

撤销后，该设备上的登录状态会立即失效，用户需要重新登录才能访问 AgentLoom。

**注意**：你不能撤销当前正在使用的会话。要退出当前会话，请使用正常的「退出登录」功能。

### 发现可疑会话

如果你看到以下情况，建议立即采取行动：

- 来自不认识的 IP 地址的会话
- 来自你不使用的浏览器或设备的会话
- 在你没有登录过的时间出现的会话

应对步骤：

1. 立即撤销所有可疑会话
2. 修改账户密码
3. 如果尚未启用 MFA，立即启用
4. 检查账户中是否有异常操作

## OAuth 绑定

如果你使用邮箱密码注册的账户，可以绑定 Google 或 GitHub 账号，之后就可以使用这些第三方账号快速登录。

### 绑定 Google 账号

> 界面提示：在账户设置中找到 OAuth 绑定区域，点击 Google 连接按钮。

系统会跳转到 Google 的授权页面。确认授权后，你的 Google 账号就会与 AgentLoom 账户绑定。

### 绑定 GitHub 账号

> 界面提示：在账户设置中找到 OAuth 绑定区域，点击 GitHub 连接按钮。

系统会跳转到 GitHub 的授权页面。确认授权后，你的 GitHub 账号就会与 AgentLoom 账户绑定。

### 绑定后的登录

绑定成功后，你可以在登录页面选择使用 Google 或 GitHub 账号登录，无需输入邮箱和密码。如果你同时启用了 MFA，OAuth 登录后仍然需要输入 MFA 验证码。

## 端到端加密（E2EE）

AgentLoom 对敏感数据实施了端到端加密保护，确保你的数据在传输和存储过程中的安全性。

### E2EE 保护的内容

以下类型的数据受到端到端加密保护：

- AI 模型的输出结果
- Agent 的决策记录
- 工具执行的输出数据

### E2EE 的工作方式（通俗解释）

端到端加密的核心思想是：只有你（和你的团队）才能解密数据，平台本身也无法查看数据明文。

具体来说：

1. 你的组织有一对加密密钥 -- 一个公钥和一个私钥
2. 公钥存储在平台服务端，用于加密数据
3. 私钥只存储在你的浏览器本地，永远不会上传到服务器
4. 当需要查看加密数据时，浏览器使用本地的私钥进行解密

这意味着即使是 AgentLoom 的运维人员，也无法查看你的加密数据内容。

### E2EE 的注意事项

- 私钥存储在浏览器的本地存储中，如果清除浏览器数据可能会丢失私钥
- 建议在多个设备上登录以确保私钥的可用性
- 如果所有设备上的私钥都丢失，加密数据将无法恢复
