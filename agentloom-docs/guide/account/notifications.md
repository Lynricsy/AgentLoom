# 通知

AgentLoom 在执行完成、失败、等待人工介入或资源治理事件发生时向相关成员发送通知。本页说明在哪里查看通知，以及如何按类型和渠道关闭不需要的提醒。

## 查看最近的通知

1. 点击侧边栏底部的通知铃铛。

   铃铛上的数字是未读数（超过 99 显示 `99+`）。下拉框标题为「通知中心」「最近 20 条消息」。

2. 点击一条通知。

   该通知标记为已读；通知关联了某次执行时，跳转到该执行的时间线。

Studio 打开期间收到新通知时，页面弹出标题为「新通知」的提示。

## 在通知中心批量处理

1. 在铃铛下拉框底部点击「查看全部通知」，或在侧边栏「运维」分组点击「通知」（路径 `/notifications`）。

   页面标题为「通知中心」，表格列出「通知」「类型」「时间」「操作」，按时间倒序。

2. 切换「全部」与「未读（N）」标签筛选；在单条通知的「操作」列点击「标记已读」，或点击右上角「全部标记已读」。

   全部标记后提示「已将全部通知标记为已读」，「未读」标签显示「没有未读通知」，铃铛上的数字消失。

## 关闭某类提醒

1. 点击侧边栏底部的「设置」，在「通用」分组中点击「通知」（路径 `/settings/notifications`）。

   页面标题为「通知偏好」。表格每行是一种通知类型，每列是一个渠道，每格一个开关。

2. 切换开关。

   改动立即保存，保存期间显示「保存中」；保存失败时提示「保存通知偏好失败」「开关已回滚，请稍后重试」，开关恢复原状。

从未改动过的开关一律视为开启。

### 通知类型

| 类型 | 页面上的说明 |
| --- | --- |
| 执行完成 | 工作流或 Agent 执行成功结束 |
| 执行失败 | 执行过程中出错并中止 |
| 需要人工介入 | 执行暂停，等待人工确认或补充输入 |
| 执行被拦截 | 资源治理策略阻止了一次执行 |
| 配额变更 | 组织的资源配额被调整 |
| 管控策略变更 | 资源治理的管控项被修改 |
| 执行被终止 | 资源治理策略强制终止了运行中的执行 |
| 系统通知 | 平台公告、维护与账户相关消息 |

### 渠道

| 渠道 | 关闭后的效果 |
| --- | --- |
| 站内 | 不再弹出「新通知」提示；通知仍写入通知中心，铃铛未读数照常更新 |
| 邮件 | 当前版本服务端不发送邮件通知，该开关只保存偏好，开或关都不会收到邮件 |
| 推送 | 不再向你登录过的 AgentLoom 移动端设备推送。Studio 网页本身不接收推送；服务端未配置 Firebase 时所有推送都不发送 |
