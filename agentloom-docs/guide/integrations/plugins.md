# 使用插件

插件是签名过的 `.alp` 包，内含在 WebAssembly 沙箱中运行的代码与一个或多个画布节点定义。本页说明如何让插件出现在本组织的画布中（从市场安装或上传注册）、如何启停、升级与卸载，以及如何查看用量。开发插件见 [插件开发](/api/plugins/)。

## 从市场安装插件

1. 在 [市场](/guide/collaboration/marketplace) 中把类型切到「插件」，打开目标插件，点击「安装到工作区」→「确认安装」。

   对话框显示「安装成功」，点击「前往插件管理」。插件副本出现在「资源 → 插件」列表中，「来源」为「市场安装」，状态为「已启用」。

安装需要 owner、admin、creator 或 operator 角色。按次计费的插件每次执行都记录计费金额，见下文「查看用量」。

## 上传并注册插件包

前提：

- 你的角色是 owner、admin 或 creator。
- 插件包的签名公钥已在本组织的 [开发者控制台](/guide/collaboration/developer-console) 中登记且有效。
- 插件包不超过 50 MB。

1. 在侧边栏「资源」分组点击「插件」（路径 `/resources/plugins`），点击「注册插件」。
2. 在「注册插件」对话框中把 `.alp` 文件拖入，或点击「选择文件」。按需保留「注册后立即启用」。
3. 点击「上传并注册」。

   进度依次显示「正在上传…」「正在校验签名…」，完成后提示「插件已注册」，列表新增一行，「来源」为「本地上传」。签名公钥未登记或已撤销时注册失败。

## 在画布中使用插件节点

1. 打开工作流画布，在左侧节点面板的 Plugin 分组中找到插件提供的节点，拖到画布上。
2. 点击节点，在配置面板中按插件定义填写配置，并按端口类型连线。

   节点的通用行为见 [Plugin 节点](/guide/nodes/plugin)。插件被停用后，节点从面板中消失，引用它的工作流无法执行。

## 启用、停用与删除

在「插件」列表中操作（需要 owner 或 admin 角色）：

| 操作 | 结果 |
| --- | --- |
| 停用 | 提示「插件已停用」，节点不再出现在画布节点面板中 |
| 启用 | 提示「插件已启用」 |
| 删除 | 在「删除插件」确认框中确认后提示「插件已删除」。不可撤销，使用了该插件节点的工作流将无法继续执行 |

## 升级与卸载市场安装的插件

1. 在「插件」列表中点击一个「市场安装」的插件，打开「插件详情」。

   详情显示状态、版本、作者、许可协议、申请的权限与导出的节点，以及安装时间、最近升级与「安装时计费口径」。

2. 市场上有新版本时显示「升级到 vX.Y.Z」，点击后提示「插件已升级」。升级需要 owner 或 admin；其他角色看到「有新版本 …，需要 owner/admin 执行升级。」
3. 不再使用时点击「卸载（停用副本）」，在「卸载插件副本」确认框中点击「停用副本」。

   提示「插件副本已停用」。卸载只把副本置为停用，插件记录与产物都保留，随时可在列表中重新启用；停用期间用到这些插件节点的工作流无法执行。

## 查看用量

1. 在「插件」列表中点击目标插件行的用量按钮。

   打开「插件用量」页，显示所选时间段内的「总执行次数」「总计费金额」「平均耗时」，以及逐条调用流水（「时间 (UTC)」「执行」「耗时」「计费金额」「来源 listing」）。免费插件的金额显示「免费」。
