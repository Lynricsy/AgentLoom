# 集成

集成分两个方向：让 Agent 与工作流调用外部能力（MCP 服务器、插件、HTTP 接口），以及让外部系统调用 AgentLoom（API Token、Webhook、API 事件、Agent API）。

| 你要做的事 | 页面 |
| --- | --- |
| 把 MCP 服务器的工具交给 Agent 调用 | [MCP 工具](/guide/integrations/mcp-tools) |
| 安装或上传插件，在画布中使用插件节点 | [使用插件](/guide/integrations/plugins) |
| 在工作流中直接调用一个 HTTP 接口 | [HTTP Request 节点](/guide/nodes/http-tool) |
| 让脚本或服务以你的身份调用平台 API | [API Token](/guide/integrations/api-keys) |
| 让第三方系统通过回调 URL 启动工作流 | [Webhook 触发](/guide/triggers/webhook) |
| 让你的服务发送事件，同时启动多个工作流 | [API 事件触发](/guide/triggers/api-event) |
| 让第三方系统与某个 Agent 对话 | [通过 API 调用 Agent](/guide/agents/api-access) |
| 查 HTTP API 的凭证、请求与错误格式 | [API 约定](/api/) |
