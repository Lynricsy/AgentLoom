# MCP 工具

本页说明如何把一个 MCP（Model Context Protocol）服务器接入组织，让 Agent 在运行时调用它提供的工具，例如文件系统、搜索或内部系统的查询接口。接入后在画布上用 [MCP Tool 节点](/guide/nodes/mcp-tool) 把选定的工具交给 Agent。

前提：

- 你的角色是 owner 或 admin。MCP 服务的查看与管理接口只对这两种角色开放；其他角色在「资源 → MCP 服务」中看到「服务器列表加载失败」。
- 准备好服务器的连接方式：
  - **stdio**：启动命令与参数。命令在 AgentLoom 服务端所在的主机（或容器）中启动，该环境必须装有对应的运行时（如 `npx`、`uvx`）。
  - **SSE** 或 **HTTP**：服务地址，以及需要的请求头（例如鉴权头）。服务端必须能访问该地址。

## 导入 MCP 服务器

1. 在侧边栏「资源」分组点击「MCP 服务」（路径 `/resources/mcp-servers`），点击右上角「导入新的」。

   弹出「导入 MCP 工具」对话框，共四步：配置连接、测试连接、发现工具、导入并复核。

2. **配置连接**：填写「服务器名称」、「服务器描述（可选）」，选择「传输方式」（stdio、SSE、HTTP）：
   - stdio：填写「命令」（如 `npx`）、「命令参数」（如 `-y @modelcontextprotocol/server-filesystem /data`），「环境变量（可选）」每行一个 `KEY=value`。
   - SSE / HTTP：填写「服务地址」（如 `https://mcp.example.com`），「请求头（可选）」每行一个 `Header=value`。

   点击「继续测试连接」。

3. **测试连接**：点击「测试连接」。

   成功时显示「服务器响应正常」以及服务器名称、版本与协议版本；失败时提示「测试连接失败」，点击「返回配置连接」修改。成功后点击「继续发现工具」。

4. **发现工具**：点击「发现工具」。

   列出服务器提供的工具名称、描述，可展开「查看 inputSchema 摘要」。显示「当前已发现 N 个工具」后点击「继续选择导入」。

5. **导入并复核**：在「选择要导入的工具」中取消不需要的工具（默认全选），在「冲突处理策略」中选择「覆盖已存在工具」或「跳过已存在工具」，点击「开始导入」。

   同一步显示「导入回执」，列出总计处理、已导入、已覆盖等数量。点击「完成」后，服务器出现在「MCP Servers」列表中，显示「传输」「状态」「工具数」「最后测试」。

## 在工作流中使用

1. 在工作流画布中添加 [MCP Tool 节点](/guide/nodes/mcp-tool)，在配置面板中选择刚导入的服务器并勾选工具。
2. 把节点的「工具」端口连接到 [Agent 节点](/guide/nodes/agent) 的「扩展工具」端口。

   运行时 Agent 收到这些工具的描述，自行决定是否调用；工具调用记录在执行详情中查看。

## 维护已导入的服务器

在「MCP Servers」列表中，每行有「测试」按钮与更多操作菜单：

| 操作 | 作用 |
| --- | --- |
| 测试 | 用已保存的配置重新测试连接，提示「连接测试成功」或「连接测试失败」 |
| 重新发现 | 从服务器拉取最新工具列表，提示「已重新发现工具」 |
| 重新导入 | 复用已保存配置重走测试、发现、导入三步，用于同步工具定义的变更 |
| 编辑 | 修改名称、描述、传输方式与连接参数。已保存的环境变量与请求头的值不回显，修改时需要重新填写全部条目 |
| 删除 | 删除服务器配置 |

点击行进入服务器详情页，可以搜索工具，并对单个工具点击停用。停用后提示「工具已停用，画布中的 Imported Tools 将同步隐藏该项。」

列表可按状态（「活跃」「未激活」「错误」）与传输方式筛选。
