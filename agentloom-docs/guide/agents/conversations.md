# 与 Agent 对话

本文介绍如何与 Agent 进行对话，包括界面布局、消息交互、工具调用展示和文件操作等功能。

## 进入对话页面

你可以通过以下方式进入 Agent 对话页面：

1. 在 Agent 列表页面，点击某个 Agent 的名称或卡片，进入 Agent 详情页后选择"对话"。
2. 直接从导航栏进入已有的对话列表，选择一个对话继续。

> 界面提示：对话页面的 URL 格式为 `/agents/:agentId/conversations/:conversationId`。

## 界面布局

Agent 对话页面采用灵活的分栏布局，主要由以下区域组成。

### 左侧：消息区

消息区占据页面的主要空间（默认约 60%），包含：

- **消息列表**：显示你与 Agent 之间的完整对话历史。用户消息和 Agent 回复以不同样式区分。
- **输入框**：位于消息列表下方，用于输入新的消息。支持多行输入，按 Enter 发送，Shift+Enter 换行。
- **操作按钮**：发送按钮、停止按钮（Agent 正在回复时可用）、文件附件按钮等。

### 右侧：沙箱与文件面板

右侧面板（默认约 40%）显示 Agent 的沙箱环境信息和文件操作内容。你可以通过拖拽分隔线来调整左右面板的宽度比例。

右侧面板包含：

- **沙箱终端**：展示 Agent 在沙箱中执行的终端命令及输出。
- **文件树**：展示沙箱工作区中的目录结构。
- **文件预览**：选中文件后展示文件内容。

> 界面提示：如果 Agent 未配置沙箱（运行时模式为 no_sandbox），右侧面板不会显示沙箱相关内容。

### 顶部：导航栏

导航栏显示当前对话的 Agent 名称和面包屑路径，提供返回按钮可以回到 Agent 详情页。

## 发送消息

### 文本消息

在输入框中输入你的消息，然后按 Enter 键或点击发送按钮即可发送。Agent 收到消息后会开始处理并实时流式输出回复。

你可以在消息中使用自然语言描述任务需求，例如：

- "请帮我创建一个 React 组件，实现一个可搜索的下拉列表。"
- "分析这段代码的性能问题，并给出优化建议。"
- "在项目中添加单元测试，覆盖用户认证模块。"

### 停止生成

当 Agent 正在生成回复时，发送按钮会变为停止按钮（显示为方形图标）。点击它可以中断 Agent 当前的回复生成。

### 图片附件

你可以通过附件按钮上传图片。Agent 会分析图片内容并在回复中引用。

> 界面提示：附件按钮位于输入框左侧，显示为回形针图标。图片上传按钮显示为带加号的图片图标。

## 消息类型与展示

### 用户消息

你发送的消息以用户气泡样式显示在消息列表右侧。

### Agent 回复

Agent 的回复以助手气泡样式显示在消息列表左侧。回复内容支持 Markdown 格式，包括：

- 标题、列表、表格
- 代码块（带语法高亮）
- 链接
- 粗体、斜体等文本格式

### 思考过程

部分模型支持"思考"功能。当 Agent 使用思考能力时，回复前会展示一个可展开的思考过程区域，显示 Agent 内部的推理步骤。

### 流式输出

Agent 的回复以流式方式实时显示——你可以在 Agent 还在生成内容时就看到已经产生的部分回复。这样你不需要等待整个回复完成才能开始阅读。

## 工具调用

Agent 在对话过程中可能会调用各种工具。每次工具调用都会在消息流中以可视化的方式展示。

### 工具调用展示

当 Agent 调用工具时，消息流中会出现一个工具调用卡片，显示：

- **工具名称**：被调用的工具名。
- **调用参数**：传入工具的参数（以 JSON 格式展示）。
- **调用状态**：当前调用的执行状态。
- **调用结果**：工具返回的结果（执行完成后显示）。

### 工具调用状态

| 状态 | 说明 |
|------|------|
| pending | 工具调用已发起，等待执行 |
| awaiting_permission | 工具调用需要你的批准才能执行 |
| denied | 你拒绝了工具调用的权限请求 |
| in_progress | 工具正在执行中 |
| completed | 工具执行成功 |
| failed | 工具执行失败 |

### 权限请求

在某些自主决策模式下，Agent 在调用工具前会请求你的许可。权限请求卡片会显示：

- 工具名称和操作描述
- 影响范围（如涉及的文件路径、资源等）
- 风险等级（低 / 中 / 高）
- 批准和拒绝按钮

你可以选择批准或拒绝该操作。如果拒绝，Agent 会收到拒绝反馈，并尝试用其他方式完成任务。

## 沙箱操作

当 Agent 配有沙箱环境时，对话页面的右侧面板会显示沙箱相关内容。

### 准备阶段

首次发送消息时，Agent 需要经历以下准备阶段：

| 阶段 | 说明 |
|------|------|
| queued | 请求已进入队列，等待处理 |
| preparing | 正在准备运行环境 |
| sandbox_creating | 正在创建沙箱容器 |
| agent_initializing | 正在初始化 Agent 运行时 |
| running | 准备完成，Agent 开始工作 |

> 界面提示：准备阶段会在消息区顶部显示一个进度卡片，展示当前所处的阶段和进度。

如果之前的对话已经有沙箱会话存在且仍然有效，系统会复用已有的沙箱，此时准备阶段会更快。

### 终端输出

Agent 在沙箱中执行的终端命令和输出会实时显示在右侧的终端面板中。你可以看到：

- 执行的命令内容
- 命令的标准输出和标准错误输出
- 命令执行的时间戳

### 文件树

右侧面板的文件树展示了沙箱工作区中的文件和目录结构。文件树会随着 Agent 的文件操作实时更新。

- 点击目录可以展开或收起。
- 点击文件可以在预览区域查看文件内容。
- 文件变更（创建、修改、删除）会高亮标识。

### 文件变更

当 Agent 创建、修改或删除文件时，对应的文件变更信息会在消息流和文件树中同步展示。文件变更支持以下类型：

| 变更类型 | 说明 |
|----------|------|
| created | 新建文件 |
| modified | 修改文件内容 |
| deleted | 删除文件 |

对于修改操作，系统可能会展示变更差异（diff），帮助你快速理解 Agent 改了什么内容。

## 子 Agent 协作

如果当前 Agent 注册了子 Agent，在对话中你可能会看到子 Agent 被调用的过程。

### 子 Agent 流式视图

当主 Agent 将任务委派给子 Agent 时，消息流中会出现一个可展开的子 Agent 流式视图。该视图展示：

- 子 Agent 的名称（别名）
- 子 Agent 接收到的任务内容
- 子 Agent 的实时回复流
- 子 Agent 的工具调用和文件操作
- 子 Agent 的完成状态（完成 / 失败 / 超时 / 取消）

### 嵌套委派

子 Agent 可以进一步委派任务给它自己的子 Agent（如果配置了的话），形成嵌套的委派链。嵌套深度会在视图中以层级方式展示。

## 对话管理

### 查看历史对话

> 界面提示：对话列表位于页面的侧边栏（Conversation Sidebar），显示当前 Agent 的所有历史对话。

每个对话条目显示对话的创建时间和最近一条消息的摘要。点击某条对话即可切换到该对话的消息视图。

### 创建新对话

点击对话列表顶部的"新对话"按钮，可以创建一个新的对话。新对话会从空白消息列表开始，但 Agent 的配置（系统提示词、工具、知识库等）保持不变。

### 对话状态

| 状态 | 说明 |
|------|------|
| idle | 空闲，等待你的输入 |
| connecting | 正在建立与服务器的实时连接 |
| connected | 连接已建立，可以正常交互 |
| executing | Agent 正在处理你的消息 |
| error | 发生错误，需要检查连接或重试 |

## 错误处理

### 连接错误

如果与服务器的实时连接中断，页面会显示连接错误提示。通常你可以通过刷新页面重新建立连接。

### 执行错误

如果 Agent 在执行过程中遇到错误（如沙箱异常、模型调用失败等），错误信息会显示在消息区域中。错误消息通常包含：

- 错误发生的阶段
- 错误描述
- 可能的原因和建议操作

### Agent 空轮次

有时 Agent 可能返回一个空的回复（没有任何文本或工具调用）。这种情况通常意味着 Agent 不确定如何处理你的请求。尝试用更具体的语言重新描述你的需求。

## 使用技巧

1. **提供上下文**：在开始新任务时，尽量在第一条消息中提供足够的背景信息，帮助 Agent 理解任务全貌。
2. **分步指令**：对于复杂任务，将其分解为多个小步骤，逐步指导 Agent 完成。
3. **利用文件树**：通过观察文件树的变化来跟踪 Agent 的工作进度。
4. **及时反馈**：如果 Agent 的回复不符合预期，及时给出反馈和修正意见，帮助对话朝正确方向发展。
5. **保存重要产出**：Agent 在沙箱中生成的文件在沙箱关闭后可能会归档为工作区快照。如果有重要文件需要长期保留，可以配置持久化工作区。
