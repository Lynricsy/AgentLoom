# 与 Agent 对话

本页说明如何在 Studio 中与一个 Agent 对话。前提：Agent 已发布（对话使用 Agent 的已发布配置）。

## 开始新对话

1. 在侧边栏「构建」组点击「Agent」，点击目标 Agent 的卡片。
2. 页面进入「Agent 新对话」（`/agents/:agentId/conversations/new`），标题旁显示 Agent 的运行形态（有沙箱 / 无沙箱）。
3. 在输入框中输入消息，按 Enter 或点击「发送」；Shift+Enter 换行。

页面显示「正在创建并发送」，随后跳转到该对话。有沙箱 Agent 首次运行时，准备卡片依次显示「排队中」「准备环境」「沙箱启动中」「Agent 初始化」「开始运行」，完成后显示「环境就绪 · 用时 …」。Agent 回复以流式显示，模型输出的思考内容折叠在「思考过程」中。

## 发送文件与图片

点击输入框旁的「上传文件」或「上传图片」，也可以直接拖入文件或截图。单条消息的附件总大小不能超过 10 MB，超出时提示「单条消息附件总大小不能超过 10 MB」。有沙箱 Agent 的文件附件会显示「工作区路径」。

## 在对话中操作

- Agent 回复过程中输入框显示「Agent 正在思考中...」，点击「停止」可中止本轮。
- 左侧对话列表点击「新建」开始另一段对话；可按来源筛选：全部、Studio、API。API 来源的对话由第三方通过 Agent API Key 发起，见 [通过 API 调用 Agent](/guide/agents/api-access)。
- 删除对话：点击对话旁的「删除」，确认「确认删除此对话？」。删除后消息记录无法恢复。
- Agent 发布新版本后，对话中会出现「Agent 已升级到最新已发布版本」卡片，点击「刷新当前对话」可立即切换到新配置，不会新建对话。

## 查看沙箱

有沙箱 Agent 的对话页右侧显示沙箱面板：工具调用状态（排队中、执行中、待授权、完成、失败、已拒绝）、终端会话输出与工作区文件树。对话开始前，这里显示持久化工作区的目录预览。
