# 使用模板

本页说明如何从官方模板创建工作流并直接运行。前提：账号里至少有一个已启用的对话模型（「资源 → LLM 模型」，路径 `/resources/llm-models`）。

## 从模板创建

1. 在侧边栏「探索」组点击「模板」。页面可用「搜索模板...」搜索，并按分类筛选：全部、分析、内容、开发、自动化、报告。每张卡片显示封面、分类、难度（入门、中级、高级）与节点数。
2. 点击一张模板卡片，打开「从模板创建工作流」对话框，其中预览模板的节点与连线。
3. 「工作流名称」默认为「模板名的副本」，可修改；「描述」可选。
4. 「Agent 使用的模型」默认「自动」：使用账号的默认对话模型，没有默认模型时使用最早添加的可用对话模型。也可以指定一个模型。账号里没有可用对话模型时，对话框提示先去添加模型，「创建工作流」不可点击。
5. 点击「创建工作流」。右下角提示「工作流已创建」，页面跳转到新工作流的画布。

创建时，模板里的每个 [Agent](/guide/nodes/agent) 节点都会在你的账号中生成一个同名的已发布 Agent（无沙箱运行态，模型为上一步选择的模型），并自动绑定到节点上；这些 Agent 出现在「构建 → Agent」列表里，描述为「由模板「模板名」创建」。每个 Agent 的角色设定写在画布上连到其「系统提示词」端口的文本节点里，可以直接修改。

## 运行

模板都以 [Manual Trigger](/guide/nodes/trigger) 开始，表单字段经 [输入预处理器](/guide/nodes/input-preprocessor) 整理成任务说明后交给第一个 Agent。

1. 在画布工具栏点击「运行」，按「输入参数」表单填写字段，见 [输入参数](/guide/workflows/input-parameters)。
2. 等执行状态变为「已完成」，在输出节点查看结果。

| 模板 | 需要填写 | 结果 |
| --- | --- | --- |
| 每日竞品分析 | 分析主题、可选的重点竞品、分析深度 | Markdown 竞品分析报告 |
| 客户反馈智能分类 | 一条客户反馈、可选的渠道与关注主题 | JSON：情感、置信度、主题、紧急程度、摘要、跟进建议 |
| 技术博客创作工作流 | 博客主题、读者层级、目标字数、章节 | Markdown 博客终稿 |
| 代码审查助手 | 代码、语言、审查重点、问题输出阈值 | 合并去重后的 Markdown 审查报告 |
| 数据报表自动生成 | 粘贴的 CSV 或表格文本、报表周期、关键指标 | Markdown 周期报表与图表建议 |

模板只使用模型自身的知识，不会联网抓取数据；需要实时信息时，在画布上加 HTTP 工具或 MCP 工具节点。需要每天自动运行时，加一个定时触发器，见 [触发器与自动化](/guide/triggers/)。
