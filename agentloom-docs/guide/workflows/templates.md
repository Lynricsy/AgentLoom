# 使用模板

本页说明如何从官方模板创建工作流，以及创建后需要补齐哪些配置才能运行。前提：已有至少一个已发布的 Agent（模板中的 Agent 节点需要绑定它，创建方法见 [创建 Agent](/guide/agents/creating)）。

## 从模板创建

1. 在侧边栏「探索」组点击「模板」。页面可用「搜索模板...」搜索，并按分类筛选：全部、分析、内容、开发、自动化、报告。每张卡片显示分类、难度（入门、中级、高级）与节点数。
2. 点击一张模板卡片，打开「从模板创建工作流」对话框，其中预览模板的节点与连线数。
3. 「工作流名称」默认为「模板名的副本」，可修改；「描述」可选。点击「创建工作流」。

右下角提示「工作流已创建」，页面跳转到新工作流的画布。

## 让模板工作流能运行

官方模板只提供结构，不包含你组织中的资源。创建后：

1. 点击模板中的每个 [Agent](/guide/nodes/agent) 节点，在「选择 Agent」中选择一个已发布的 Agent。未绑定时运行会失败，错误信息为 `agent 节点必须绑定已发布的 Agent Definition；画布上的内联 Agent 配置已不再支持`。
2. 模板中有 [LLM 模型](/guide/nodes/llm-model) 节点时，在其配置面板中选择或创建模型配置。
3. 模板带有输入参数时，点击工具栏「输入参数」查看字段，运行时按提示填写，见 [输入参数](/guide/workflows/input-parameters)。
4. 点击「运行」，确认执行状态为「已完成」。

模板卡片的描述中会写明使用前需要补齐的内容（例如「使用前需为每个 Agent 节点选择一个已发布的 Agent Definition。」）。
