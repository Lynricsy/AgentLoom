# 分享与导出

本页说明如何把工作流分享给他人、导出为文件，以及从分享链接或文件得到一份工作流。组织内成员之间的协作见 [团队协作](/guide/collaboration/)；上架市场见 [市场](/guide/collaboration/marketplace)。

## 创建分享链接

1. 在画布顶部工具栏点击「分享」，打开「分享管理」对话框。
2. 在「创建新分享」中选择「分享类型」：「仅查看」或「可复制」；选择「有效期」：永不过期、1天、7天或30天。
3. 点击「创建工作流分享链接」。

右下角提示「分享链接已创建」，并尝试把链接复制到剪贴板（成功时提示「链接已自动复制到剪贴板」）。链接形如 `https://agentloom.ling.plus/s/<token>`。

「现有分享链接」列表显示每条链接的类型、状态（生效中、已过期、已撤销）、创建与过期时间。点击「复制链接」再次复制；点击「撤销分享」并「确认」后，链接立即失效，提示「分享链接已撤销」。

Agent 的分享入口是 Agent 画布工具栏的「分享」，对话框相同，按钮为「创建Agent分享链接」。

## 打开分享链接

打开链接后显示「公开分享」页面，包含作者、创建时间、有效期、节点与连线数和只读画布。

- 「可复制」的工作流分享显示「复制到我的工作流」，登录后点击即复制到你当前组织的工作流列表，提示「已导入到你的工作流列表」。
- 「仅查看」的分享只能预览。
- 链接已撤销或过期时显示「分享链接不存在」或「分享链接已过期」。

导入 Agent 分享时，页面显示资源处理结果：「已复制」「已清空」「待重绑」「跳过临时资源」。「待重绑」的资源（例如对方组织的模型配置）需要在你的 Agent 画布上重新选择。

## 导出与导入文件

- **导出**：在画布工具栏点击「导出」，或在工作流列表的卡片上点击导出按钮，下载 `.agentloom-workflow.json` 文件，提示「工作流导出成功」。
- **导入**：在画布工具栏点击「导入」，打开「导入工作流」对话框，选择或拖入 `.json` / `.agentloom-workflow.json` 文件。文件校验通过后显示其节点、连线与版本信息，填写「工作流名称」（默认「原名称 的副本」）与可选描述，点击「导入」，创建一个新的工作流。

导入不会覆盖当前工作流。文件内容不是有效 JSON 时提示「文件内容不是有效的 JSON 格式」。
