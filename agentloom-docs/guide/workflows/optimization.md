# 配置优化提案

本页说明如何用运行证据优化工作流中团队节点与智能路由节点的配置：生成提案、评测、发布、回滚。前提：工作流已发布；当前账号是组织的 owner 或 admin（「监控」页只对这两个角色开放）。

提案在「监控」页的「优化提案」Tab 中。每条提案只修改一个节点的一项配置，发布前必须评测，且只有评测结论为「优于基线」的提案可以发布。

## 提案类型与触发条件

系统每周一 02:00（UTC）自动分析所有已发布的工作流，也可以手动分析。证据取最近 28 天、与当前发布配置相同预算下已结束的运行；评测产生的执行不计入。

| 类型 | 修改的配置 | 触发条件 | 建议值 |
| --- | --- | --- | --- |
| Token 上限 | 团队节点 `maxTotalTokens` | 至少 3 次团队运行，其中 ≥ 50% 因 Token 用尽失败 | 当前值 × 1.5，向上取整到千 |
| 消息数上限 | 团队节点 `maxMessages` | 至少 3 次团队运行，其中 ≥ 50% 因消息数达到上限失败（Token 未用尽） | 当前值 × 1.5，最多 1000 |
| 截止时间 | 团队节点 `deadlineMinutes` | 至少 3 次团队运行，其中 ≥ 50% 超过截止时间 | 当前值 × 1.5，最多 1440 分钟 |
| 路由回退模型 | 智能路由节点（LLM 路由策略）的回退模型 | 未配置回退模型；至少 10 次路由决策，其中 ≥ 20% 发生回退 | 非回退决策中最常被选中的模型 |

同一节点的同一类提案同时只保留一条在处理中的。提案被忽略后，只要发布版本没变、也没有新的符合条件的失败运行（自动分析与手动分析都一样），就不会再提出同样的提案；发布新版本或出现新的命中运行后才会重新提案。

## 手动分析工作流

1. 打开「监控」→「优化提案」，点击「分析工作流」。
2. 在「已发布的工作流」中选择工作流，点击「开始分析」。

右下角提示「新建 N 条优化提案」；证据不足、同类提案已在处理中，或同类提案已被忽略且之后没有新的命中运行时提示「没有新的优化提案」。工作流未发布、或发布版本中没有团队与智能路由节点时，对话框中显示错误说明。

## 评测

1. 在列表中点击提案的「详情」，打开提案详情。详情中列出理由、证据（样本数与命中比例）和补丁（配置路径：当前值 → 建议值）。
2. 点击「评测」，在「用例数（1–10）」中填写回放的执行数（默认 3），点击「开始评测」。

系统取该工作流最近 N 次已结束的真实执行的输入，分别在当前发布版本（基线）和应用了补丁的候选版本上各运行一次。状态变为「评测中」，详情每 5 秒刷新一次。评测执行出现在执行列表中，计入组织的执行配额。

评测完成后，详情中显示基线与候选的对比：

| 列 | 含义 |
| --- | --- |
| 通过率 | 执行状态为完成的比例 |
| 平均成本 | 有成本数据的执行的平均费用 |
| 平均时长 | 从开始到结束的平均耗时 |
| 团队失败原因 | 各失败原因出现的次数 |

结论按以下规则给出：候选通过率更高为「优于基线」，更低为「劣于基线」；通过率相同时，平均成本下降至少 5% 为「优于基线」、上升至少 5% 为「劣于基线」，否则为「无差异」。

评测超过时限（至少 30 分钟，团队截止时间较长时为最长截止时间的 2 倍）时，未结束的评测执行被取消，提案回到「待评测」。结论不是「优于基线」时可以点击「重新评测」或「忽略」。

## 发布

1. 在结论为「优于基线」的提案详情中点击「发布」。
2. 可选填写「版本标签」与「发布说明」，点击「发布」。

被评测的候选版本成为工作流的发布版本，可在 [版本管理](/guide/workflows/versions) 的「历史记录」中看到；草稿中该节点同步为建议值。草稿中已不存在该节点时，详情中提示「草稿中不存在该节点，未同步」。

已在运行的执行不受影响，继续使用启动时的版本与配置；发布后新启动的执行使用新版本。

## 回滚

1. 在「已发布」的提案详情中点击「回滚」，确认「回滚到基线版本？」。

提案生成时的基线版本重新成为发布版本；草稿中该节点仍是建议值时回写为原值，已被手工修改时不回写并提示「草稿已被手工修改，未回写」。若发布版本已被其他操作切换，回滚返回错误，提案保持「已发布」。

## 状态

| 状态 | 含义 |
| --- | --- |
| 待评测 | 新建或评测超时后，等待评测 |
| 评测中 | 基线与候选执行正在运行 |
| 已评测 | 评测完成，结论见「结论」列 |
| 已发布 | 候选版本已成为发布版本 |
| 已回滚 | 已恢复基线版本 |
| 已忽略 | 不再处理；没有新的命中运行时不会再次提出 |
| 已失效 | 评测或发布时发现工作流的发布版本已不是提案的基线版本；需要重新分析 |
