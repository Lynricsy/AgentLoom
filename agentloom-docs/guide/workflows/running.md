# 运行与监控

本页说明如何手动运行工作流、在运行中跟踪节点状态，以及事后查看执行记录。前提：工作流画布上已有可运行的节点，且工作流未归档。

## 手动运行一次

1. 在画布顶部工具栏点击「运行」，弹出「启动工作流」对话框。
2. 工作流定义了输入参数时，按对话框提示填写（表单、对话或两者结合，取决于输入参数的收集方式，见 [输入参数](/guide/workflows/input-parameters)）；没有输入参数时，对话框提示「当前工作流没有需要填写的字段，确认后将直接启动执行。」
3. 点击对话框中的「运行」。

工具栏按钮变为「执行中」，底部状态栏显示执行状态。启动失败时右下角提示「启动失败」及原因。

执行结束前不能再次从画布运行。工具栏下方会显示正在进行的执行的状态、编号（如「执行 #01a15508 (2/4)，结束前无法再次运行」）和「取消执行」按钮。点击编号进入该执行的执行页。点击「取消执行」并确认后，未完成的步骤和等待干预的步骤会被取消，已完成步骤的结果保留，画布上这些节点显示「已取消」，「运行」按钮恢复可用。

在画布中运行的是当前画布草稿，包括发布后尚未再次发布的修改。这类执行称为「草稿运行」：它运行的定义保存在执行记录里，但不属于任何发布版本，按发布版本筛选执行时不会出现。触发器和移动端启动的执行运行当前发布版本，REST API 启动默认也运行当前发布版本，见 [版本管理](/guide/workflows/versions)。

让工作流按定时、Webhook 或 API 事件自动运行需要先发布工作流，再创建触发器，见 [触发器与自动化](/guide/triggers/)。通过 REST API 启动执行见 [REST API](/api/rest)。

## 跟踪运行中的执行

- **底部状态栏**显示整个执行的状态：等待中、执行中、已暂停、已完成、失败、已取消。
- **画布上的节点**按各自状态改变外观。
- **节点配置面板的「输出」标签**：点击节点后切换到「输出」，「实时执行」区域显示该节点的状态（等待中、排队中、执行中、已完成、失败、已跳过、已取消、等待干预）、步骤 ID、流式状态（接收中 / 已停止）、发生重试时的重试进度，以及 Agent 的流式输出。节点失败时这里显示错误信息。

节点状态为「等待干预」时，执行会暂停，直到有人在「介入」标签中处理，见 [调试工作流](/guide/workflows/debugging)。离开画布后也可以在执行页 `/executions/:id` 处理：选中等待干预的节点，节点详情上方显示「需要人工干预」面板，提供「批准」「修改」「拒绝」。刷新或重新进入画布时，若该工作流最近有未结束（等待中、执行中、等待干预）的执行，画布会恢复它的节点状态并继续接收实时更新，等待干预的节点仍可在「介入」标签中处理。

## 查看执行记录

1. 在画布页点击「查看执行记录」，打开「执行记录」面板，列出该工作流最近的执行。
2. 草稿运行的记录带「草稿运行」标记。点击一条记录，进入执行调试页 `/executions/:executionId`；草稿运行在调试页标题旁同样显示「草稿运行」，左侧只读画布展示的是运行当时的草稿。

执行调试页标题为「执行调试」，显示本次执行的耗时，提供「调试面板」「溯源图」「遥测」「终端」标签（「终端」标签上的数字是本次执行中的终端会话数）。「调试面板」分三栏：左侧是执行时的只读画布，中间是按时间排列的节点执行时间线，右侧是选中节点的详情。选中 Agent 节点时可以点击「打开 Agent 运行视图」，查看这次调用的完整消息。点击「返回工作流」回到画布。

「遥测」标签的执行汇总卡片列出步骤数、工具调用、Tokens 与耗时。Agent 节点所用的模型在编辑模型表单里填写了「输入价格 ($/1M tokens)」「输出价格 ($/1M tokens)」时，汇总卡片多出一项「总成本」（美元，按各 Agent 节点的 token 用量与模型单价换算）；没有任何节点的模型定价时不显示这一项。

工作流含 [Agent 团队](/guide/nodes/team) 节点时，执行调试页多出「团队」标签，每个团队节点一个面板：

- 顶部是团队运行状态；同一节点因恢复重跑而有多次团队运行时，右上角可切换查看历史运行，默认显示最新一次。
- 预算区显示已用 Tokens、已发消息数各自占上限的进度（达到 90% 时进度条转为警示色），以及运行中距截止时间的倒计时。
- 「成员」表列出角色（负责人带「负责人」标记）、所用 Agent、状态、回合数与已用 Tokens。
- 「消息」时间线按发送时间列出「发送方 → 接收方」、消息类型（发现、请求、回复、产物、系统）、投递状态（待投递、已投递、已读取、已抑制、已过期）、正文与引用。运行中新到的消息先显示前 200 字预览，团队结束后载入完整正文。配置了 Jev 影子决策时，广播的「发现」消息旁显示「Jev 影子：p=…」，仅供参考，不影响投递。
- 团队完成后显示负责人提交的结果摘要、已知局限与产物；失败或取消时显示原因（如「Token 或消息预算耗尽」「超过截止时间」）。

状态、成员与投递状态随执行实时推进，无需刷新页面。
