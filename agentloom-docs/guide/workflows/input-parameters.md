# 输入参数

本页说明如何让工作流在每次运行时接收不同的输入，并把输入交给节点使用。前提：你的角色可以编辑该工作流（只读角色打开面板时会看到「当前角色仅可查看输入参数配置，无法编辑或保存。」）。

## 定义输入字段

1. 在画布顶部工具栏点击「输入参数」，打开输入参数面板（按钮文字变为「隐藏输入参数」）。
2. 选择「收集模式」：
   - 「表单模式」：直接渲染结构化表单，适合一次性填写。
   - 「对话模式」：在运行对话框中按字段顺序逐项提问收集字段值，可设置对话计划的「系统提示词」与「最大轮次」。
   - 「混合模式」：先表单补充，再通过对话追问剩余字段。
3. 点击「添加字段」，为每个字段填写：
   - 「字段 ID」：在触发数据中作为键名。
   - 「标签」「描述」：运行对话框中显示给填写人。
   - 「字段类型」：文本、数字、单选、多选。单选与多选需要填写「选项（逗号分隔）」。
   - 「必填」「默认值」「收集提示」（对话模式下用于追问该字段）。
   - 校验：文本可设「最小长度」「最大长度」，数字可设「最小值」「最大值」。
   - 「显示条件字段」与「显示条件取值」：只有另一个字段等于指定值时才显示本字段；默认「始终显示」。
4. 在「表单预览」中检查默认值与条件显示，然后点击「保存输入参数」。

右下角提示「输入参数已保存」。配置有问题时提示「无法保存输入参数」及第一条错误。

## 运行时填写

点击「运行」后，「启动工作流」对话框按收集模式展示字段：表单模式直接显示表单；混合模式先显示「步骤 1：表单补充」，再进入「步骤 2：对话补充」；对话模式逐项提问，达到最大轮次后需要在「确认运行参数」中补齐剩余字段。不满足校验时，字段下方显示如「<标签>不能为空」的提示。

## 在节点中使用输入

运行时填写的值作为本次执行的输入参数，由触发器节点的「触发数据」端口（`json`）输出，键名为各字段的字段 ID。常见接法：

- 把 [Manual Trigger](/guide/nodes/trigger) 的「触发数据」连到 [Agent](/guide/nodes/agent) 的「上下文」端口，Agent 推理时可以参考全部输入。
- 需要把某个字段作为 Agent 的输入文本时，先用 [输入预处理器](/guide/nodes/input-preprocessor) 取出字段（例如模板模式 <code v-pre>{{json-in.topic}}</code>），再把它的「文本」输出连到 Agent 的「文本」端口。
