# 移动端功能

按底部五个标签列出移动端的页面、入口与可执行操作。界面字样取自 `agentloom_mobile/lib/features/` 下各页面源码；移动端与 Web Studio 的分工见[移动端概览](/guide/mobile/)。

大屏设备上，底部标签栏换成左侧导航栏，标签与顺序不变（`agentloom_mobile/lib/app/shell_scaffold.dart`）。

## 总览

页面标题为「仪表盘」。

| 区块 | 内容 | 操作 |
| --- | --- | --- |
| 快速访问 | 已发布的工作流；没有时显示「暂无已发布的工作流」 | 点击工作流进入详情；「查看全部」跳到「工作流」标签 |
| 最近执行 | 最近的工作流执行记录 | 点击一条记录打开「执行监控」 |

## 工作流

| 页面 | 入口 | 内容与操作 |
| --- | --- | --- |
| 工作流列表 | 「工作流」标签 | 搜索框「搜索工作流...」；状态筛选「全部」「已发布」「草稿」「已归档」；来源筛选「全部来源」「自己创建」「分享导入」 |
| 工作流详情 | 点击列表项 | 版本（已发布显示 `v<N>`，否则「未发布」）、来源、创建与更新时间、「最近执行」；来源为分享导入时可「转为自己创建」 |
| 运行参数 | 详情页右下角「运行」（仅已发布的工作流显示） | 页面标题「运行 <工作流名称>」；按表单填写参数后点「启动运行」 |
| 执行监控 | 启动运行后自动进入，或从「最近执行」进入 | 节点状态与事件实时更新；连接方式在 WebSocket 与轮询之间自动切换；结束时显示「执行已结束」 |
| 输出详情 | 执行监控中点击输出节点 | 「Markdown 富渲染」「结构化 JSON 渲染」「原文输出」三种视图 |
| Agent 运行视图 | 执行监控中点击 Agent 节点 | 按到达顺序展示文本、工具、终端与文件事件；「打开运行上下文」查看终端与工作区 |

参数收集模式为对话式或混合式（表单 + 对话）的工作流，运行参数页会提示到 Web 端启动（`agentloom_mobile/lib/features/workflows/widgets/conversation_mode_prompt.dart`）。

## Agent

标签名为「Agent」，列表与详情页的标题为「智能体」。

| 页面 | 入口 | 内容与操作 |
| --- | --- | --- |
| 智能体列表 | 「Agent」标签 | 搜索框「搜索智能体...」；状态与来源筛选同工作流列表；可直接从列表项开始新对话 |
| 智能体详情 | 点击列表项 | 运行形态、Skill、原生工具、「最近对话」；「新对话」；删除单个对话（「删除对话」，不可撤销） |
| 新对话 | 列表项或详情页「新对话」 | 标题「Agent 新对话 · 有沙箱」或「Agent 新对话 · 无沙箱」；输入框「输入消息…」，可「上传图片」「上传文件」 |
| 对话 | 新对话发送首条消息后，或点击已有对话 | 消息、思考过程与工具调用按顺序展示；「运行上下文」面板含终端、工作区文件与变更记录 |

对话中的行为：

- Agent 请求工具授权时，消息流中出现「允许一次」与「拒绝一次」。
- 以无沙箱形态运行的 Agent 没有终端、工作区和文件变更面板；Skill、知识库、记忆、HTTP MCP 与自进化结果仍在消息流中展示。
- Agent 发布了新版本时，对话中提示升级；刷新后当前对话改用最新已发布配置，不新建会话。
- 实时连接断开时提示「实时连接已断开，历史消息仍可查看」。

运行形态的区别见[创建 Agent](/guide/agents/creating)。

## 资源

「资源」标签是一个入口列表，每项进入一个资源页：

| 入口 | 页面上的操作 |
| --- | --- |
| 记忆 | 浏览记忆实例 → 实例详情（节点数、边数、节点列表）→「记忆节点」（版本历史）；「审计日志」列出节点创建、版本更新、评审结果与路径删除，审计详情可「回滚」 |
| 技能 | 搜索「搜索技能...」；按「活跃」「已归档」与「内置」「自定义」筛选；「技能详情」中可「编辑」名称与描述、「归档」「删除」；内置技能不可编辑 |
| 工作区 | 搜索「搜索工作区名称」；「新建工作区」；「删除工作区」；默认隐藏执行归档快照，打开「显示执行归档」后列出 |
| Sandbox | 搜索「搜索沙箱名称或 ID」；「新建持久沙箱」；「启动」「停止」「删除」；运行中的沙箱显示实时资源统计与「最近日志」 |
| 知识库 | 「新建知识库」；查看文档列表与状态；「重建」；「删除」 |
| MCP 服务 | 搜索「搜索 MCP 服务名称」；「导入工具」后在弹出面板中「测试连接」并「导入所选工具」；服务详情中可再次「测试连接」 |
| LLM 模型 | 页面标题「LLM 提供商」；搜索「搜索提供商名称或标识」；「添加提供商」；内置提供商由系统自动同步 |

技能的 SKILL.md 内容与文件上传只能在 Web Studio 管理。内置技能清单见[内置技能](/guide/skills/built-in)。

## 设置

| 分组 | 条目 | 说明 |
| --- | --- | --- |
| — | 连接与服务器 | 修改「Studio 基础地址」；「恢复默认地址」 |
| 个人偏好 | AI 偏好设置 | 「标题生成模型」，可选「使用组织默认」或指定模型 |
| 安全 | 修改密码 | 新密码至少 8 个字符，需同时含大写字母、小写字母和数字 |
| 安全 | 双因素认证 | 启用或禁用 TOTP 两步验证 |
| 安全 | 活跃会话 | 列出已登录设备；非当前设备的会话可「注销此会话」 |
| 账户 | 邮箱、退出登录、退出所有设备 | 页面底部显示当前邮箱与已关联账号；「退出所有设备」注销所有活跃会话 |
