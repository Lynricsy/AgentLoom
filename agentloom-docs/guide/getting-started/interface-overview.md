# 界面导览

AgentLoom Studio 是你使用 AgentLoom 的主要工作界面。本页将详细介绍 Studio 各个区域的功能和布局，帮助你快速熟悉整个界面。

---

## 整体布局

AgentLoom Studio 采用左侧边栏加主内容区的经典布局。根据你所在的页面不同，主内容区的布局也会有所变化：

- **列表页面**（如工作流列表、Agent 列表）：主内容区为卡片或列表视图
- **画布编辑器**（编辑工作流时）：主内容区为全屏画布，配有专用的节点面板、属性面板和工具栏
- **设置页面**：主内容区为左侧导航 + 右侧设置表单的子布局

---

## 侧边栏导航

侧边栏始终固定在界面最左侧，提供全局导航功能。无论你在 Studio 的哪个页面，都可以通过侧边栏快速切换到其他功能区。

### 主导航区域

侧边栏的主导航包含以下入口：

| 导航项 | 对应路径 | 说明 |
|--------|---------|------|
| 工作流 | `/workflows` | 工作流列表页，管理所有工作流 |
| Agent | `/agents` | Agent 列表页，管理独立 Agent |
| 模板 | `/templates` | 浏览和使用预置工作流模板 |
| 市场 | `/marketplace` | 浏览社区分享的工作流和插件 |
| 发现 | `/discover` | 发现推荐内容 |

### 资源管理区域

侧边栏还包含一组资源管理入口，用于管理工作流和 Agent 所依赖的各种资源：

| 资源类型 | 对应路径 | 说明 |
|---------|---------|------|
| MCP 服务 | `/resources/mcp-servers` | 管理 MCP 工具服务 |
| LLM 模型 | `/resources/llm-models` | 管理 AI 模型配置 |
| 技能 | `/resources/skills` | 管理 Agent 技能 |
| 知识库 | `/resources/knowledge-bases` | 管理向量知识库 |
| 记忆实例 | `/resources/memory-instances` | 管理 Agent 记忆 |
| 工作区 | `/resources/workspaces` | 管理持久化工作区 |
| 沙箱 | `/resources/sandboxes` | 管理沙箱环境 |

### 底部区域

侧边栏底部通常提供以下功能入口：

- **设置**：进入系统设置页面（安全、加密、审计日志、资源配额等）
- **用户信息**：显示当前登录用户的头像和名称

## 工作流列表页

工作流列表页是你登录后最常访问的页面之一，用于浏览和管理所有工作流。

> 界面提示：工作流列表页的路径为 `/workflows`。

### 页面顶部

- **标题**：显示"工作流"
- **新建工作流按钮**：点击后弹出创建工作流对话框

### 筛选与搜索

页面提供以下筛选功能：

- **搜索框**：按工作流名称搜索
- **状态筛选**：可选择"全部状态"、"草稿"、"已发布"、"已归档"
- **来源筛选**：按工作流来源筛选（例如手动创建、从模板创建、从市场安装等）
- **视图切换**：支持网格视图和列表视图两种展示方式

### 工作流卡片

每个工作流以卡片形式展示，卡片上包含：

- **图标和名称**：工作流的自定义图标和名称
- **状态徽章**：显示当前状态（草稿/已发布/已归档）
- **描述**：工作流的简要描述
- **来源标记**：如果是从模板或市场安装的，会显示来源标记
- **更新时间**：最后修改时间
- **操作菜单**：提供编辑、导出、归档等操作

点击工作流卡片会进入该工作流的画布编辑器页面。

## 画布编辑器

画布编辑器是 AgentLoom 的核心工作区域，你在这里设计和编辑工作流。

> 界面提示：画布编辑器的路径格式为 `/workflows/工作流ID`。

画布编辑器的完整界面由以下几个区域组成：

### 版本工具栏（顶部）

版本工具栏位于画布区域的顶部，提供工作流管理的核心操作。从左到右依次是：

| 元素 | 说明 |
|------|------|
| 状态徽章 | 显示工作流当前状态："草稿"（蓝色）、"已发布"（绿色）或"已归档"（灰色） |
| 保存快照 | 保存当前画布状态为一个带标签的版本快照 |
| 历史记录 | 打开版本历史面板，查看和管理所有版本 |
| 介入策略 | 配置人工干预规则，决定何时需要人工审批 |
| 输入参数 | 定义工作流的输入参数（表单字段、收集模式等） |
| 触发器 | 配置自动触发方式（定时、Webhook、API 事件） |
| 发布 | 将当前状态发布为正式版本（仅草稿状态可见） |
| 发布到市场 | 将已发布的工作流上架到社区市场（仅已发布状态可见） |
| 导出 | 将工作流导出为 `.agentloom-workflow.json` 文件 |
| 导入 | 从文件导入工作流 |
| 分享 | 生成只读分享链接（仅已发布状态可见） |
| 运行 | 启动工作流执行（归档状态下不可用） |
| 归档 | 将工作流归档停用 |

### 节点面板（左侧）

节点面板位于画布左侧，展示所有可添加到画布的节点类型。

- 节点按分类分组显示：Agent 智能体、工具、触发器、知识与记忆、输出、流程控制、插件
- 每个节点类型显示其图标、名称和简短描述
- 只展示可直接拖拽到画布的节点（某些特殊节点如循环内部节点会自动创建，不在面板中显示）
- 你可以通过拖拽的方式将节点从面板放置到画布上

### 画布区域（中央）

画布区域是编辑器的主体部分，占据了界面的大部分空间。这是你放置节点和连线的工作区。

**画布交互操作：**

| 操作 | 方法 |
|------|------|
| 平移画布 | 按住空格键拖拽，或使用鼠标中键拖拽 |
| 缩放画布 | 使用鼠标滚轮，或使用触控板捏合手势 |
| 选中节点 | 单击节点 |
| 移动节点 | 拖拽节点到新位置 |
| 删除节点 | 选中节点后按 Delete 键 |
| 连接端口 | 从输出端口按住拖拽到输入端口 |
| 删除连线 | 点击选中连线后按 Delete 键 |
| 框选多个节点 | 在画布空白处按住拖拽画出选区 |
| 搜索节点 | 使用画布搜索功能查找特定节点 |

**画布上的节点卡片：**

每个节点在画布上显示为一个卡片，卡片上包含：
- 节点图标和名称
- 节点类型标识
- 输入端口（左侧，不同形状和颜色代表不同数据类型）
- 输出端口（右侧）
- 执行状态覆盖层（运行时显示节点的执行状态）

**小地图：**

画布右下角有一个小地图（MiniMap），以缩略图形式展示整个画布的全貌。你可以通过点击小地图快速定位到画布的特定区域。

### 属性面板（右侧）

当你选中画布上的某个节点时，右侧会显示该节点的属性配置面板。

> 界面提示：属性面板宽度约 320 像素，与画布区域通过分割线隔开。

属性面板的结构：

**面板头部**
- 节点名称（可编辑）
- 节点类型说明
- 关闭按钮（点击取消选中节点）

**配置区域**
- 根据节点类型不同，显示对应的配置表单
- 例如 HTTP Request 节点有 URL、Method、Headers 等字段，Agent 节点提供已发布 Agent 的选择器
- 某些节点有专用的配置面板（如智能路由的策略选择、知识库的 ID 绑定等）
- 没有额外配置的节点会显示"该节点无需额外配置"的提示

**实时执行区域**（面板下方）
- 执行状态徽章（等待中/执行中/已完成/失败等）
- 步骤 ID、流式状态、开始时间、完成时间等执行元数据
- 重试进度（如果发生了重试）
- 执行错误信息（如果节点失败）
- 工具调用列表（展示 Agent 发起的工具调用及审批操作）
- 输出流（实时显示节点的文本输出内容）

### 状态栏（底部）

画布底部有一条窄状态栏，显示当前工作流的汇总信息。

> 界面提示：状态栏高约 28 像素，横跨画布底部。

状态栏从左到右依次显示：

| 信息 | 说明 |
|------|------|
| 节点数 | 当前画布上的节点总数 |
| 连接数 | 当前画布上的连线总数 |
| 缩放比例 | 画布的当前缩放百分比 |
| 保存状态 | "未保存"（黄色圆点）、"保存中..."（加载动画）或"已保存 . X 分钟前"（绿色勾号） |
| 执行状态 | 运行时显示执行状态和进度，���"执行中 (2/5)" |

## Agent 列表页

Agent 列表页用于管理你创建的独立 Agent。

> 界面提示：Agent 列表页的路径为 `/agents`。

页面布局与工作流列表类似，展示所有 Agent 的卡片列表，并提供搜索和新建功能。

点击 Agent 卡片会进入 Agent 详情页，在那里你可以配置 Agent 参数、查看对话历史、管理版本。

### Agent 对话页面

选择某个 Agent 后，你可以进入对话页面与 Agent 进行交互。

> 界面提示：Agent 对话页面的路径格式为 `/agents/AgentID/conversations/对话ID`。

对话页面采用三列布局：
- **左栏**：对话列表，显示该 Agent 的所有历史对话
- **中栏**：对话消息区域，显示当前对话的消息记录
- **右栏**：对话详情和 Agent 配置信息

## 执行调试页面

每次工作流执行都会在执行调试页面留下详细记录。

> 界面提示：执行调试页面的路径格式为 `/executions/执行ID`。

### 三栏布局

执行调试页面采用可调节的三栏布局：

**左栏 -- 只读画布**
- 显示工作流的画布快照，不可编辑
- 节点上叠加显示执行状态和结果
- 可以缩放和平移查看全貌

**中栏 -- 执行时间线**
- 按时间顺序展示每个节点的执行过程
- 包含节点名称、执行状态、持续时间、输入输出摘要
- 失败的节点会以醒目的样式展示错误信息
- 支持证据标记（用于审计追踪）

**右栏 -- 节点详情**
- 选中时间线中的某个节点后，显示该节点的详细执行信息
- 包含完整的输入数据、输出数据、工具调用记录
- 对于 Agent 节点，还可以查看 Agent 的对话消息记录和工作区文件

### 顶部信息栏

页面顶部显示本次执行的整体信息：
- 返回工作流的链接
- 执行状态徽章
- 开始时间和持续时长
- 切换标签页：调试视图、溯源图、终端

## 设置页面

设置页面提供系统和组织级别的配置管理。

> 界面提示：设置入口在侧边栏底部，各设置页面路径为 `/settings/...`。

设置页面采用左侧导航 + 右侧内容的子布局。主要设置项包括：

| 设置项 | 路径 | 说明 |
|--------|------|------|
| 偏好设置 | `/settings/preferences` | 用户个人偏好 |
| 安全设置 | `/settings/security` | 密码修改、MFA 多因素认证、会话管理 |
| 加密设置 | `/settings/encryption` | 端到端加密密钥管理 |
| 审计日志 | `/settings/audit-logs` | 查看组织内的操作审计记录 |
| 资源配额 | `/settings/resource-quotas` | 管理租户的资源使用限额 |
| 监控仪表板 | `/settings/monitoring` | 查看组织运行状况的实时监控 |
| 私有部署 | `/settings/private-deployment` | 配置私有化部署相关设置 |

## 常用键盘快捷键

以下是在画布编辑器中常用的键盘操作：

| 快捷键 | 功能 |
|--------|------|
| Delete / Backspace | 删除选中的节点或连线 |
| 空格 + 拖拽 | 平移画布 |
| 鼠标滚轮 | 缩放画布 |
| 点击空白区域 | 取消选中 |
