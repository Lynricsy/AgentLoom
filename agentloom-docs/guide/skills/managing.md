# 管理技能

本页说明如何查找、新建、编辑、归档和删除技能。前提：新建、编辑、归档技能需要组织角色 owner、admin 或 creator；删除需要 owner 或 admin。

## 查找技能

在侧边栏「资源」组点击「技能」，进入「技能管理」页面。用「搜索技能名称或描述...」搜索；状态筛选为全部状态、活跃、已归档；类型筛选为全部类型、内置技能、自定义技能。卡片显示名称、「内置」标记、状态、描述、文件数与更新时间。

在卡片的更多操作菜单中点击「查看详情」，可查看技能内容、前言元数据、文件数、大小、版本与创建、更新时间。

## 新建技能

1. 点击右上角「新建技能」，打开「新建技能」对话框。
2. 二选一：
   - 手动填写「名称」（必填）、「描述」，在「内容编辑」标签的「SKILL.md 内容」中编写正文，在「附件」标签中添加文件。
   - 在「导入技能文件」区域拖入 `SKILL.md` 或包含 `SKILL.md` 的 `.zip`。导入后显示「已解析: 名称」，名称与描述取自 frontmatter，zip 中的其他文件作为附件。
3. 点击「创建」。

新技能出现在列表中，状态为「活跃」。附件限制：单个文件不超过 5 MB，总量不超过 50 MB，最多 50 个文件；超出时对话框显示具体的超限提示。

## 编辑、归档与删除

在卡片的更多操作菜单中：

- 「编辑」：打开「编辑技能」对话框，修改名称、描述、SKILL.md 内容与附件，点击「保存」。内置技能没有该选项。
- 「归档」：技能状态变为「已归档」。
- 「删除」：在「确认删除」对话框中确认；此操作不可撤销。内置技能不能删除。

## 让 Agent 使用技能

在 Agent 画布中，从「高级」分组拖入 Skill 节点，在配置面板中搜索并选择技能（内置技能带「内置」标记），把它连到 Agent Main 的「Skills」端口，保存并发布 Agent。也可以在工作流中把 Skill 节点连到 Agent 节点的「Skills」端口，只对该次调用生效。见 [Skill 节点](/guide/nodes/skill)。
