# 技能系统

技能（Skill）是 AgentLoom 中用于增强 AI Agent 能力的知识模块。通过技能，你可以为 Agent 注入专业领域的工作方法和最佳实践，让它在执行特定任务时表现得更加专业和可靠。

## 什么是技能

在 AgentLoom 中，技能是一段结构化的指导文档，定义了 Agent 在特定任务场景下应该如何工作。它不同于简单的提示词，而是一份完整的专业指南，包含了任务目标、工作流程、注意事项和质量标准。

当 Agent 启用了某项技能后，该技能的内容会被自动注入到 Agent 的系统提示中，让 Agent 在对话和工作流执行时自然地遵循这些专业指导。

## 技能如何增强 Agent

没有技能的 Agent 只依赖 AI 模型自身的知识。虽然现代 AI 模型已经具备广泛的知识，但在面对专业任务时，它们可能缺乏你的团队所期望的具体工作方法和质量标准。

技能解决了这个问题。通过技能，你可以：

- **标准化工作方法**：让不同 Agent 在处理同类任务时遵循统一的流程和标准
- **注入专业知识**：将团队积累的最佳实践和经验传授给 Agent
- **提升输出质量**：通过明确的质量标准和检查清单提高 Agent 的工作成果
- **减少试错成本**：Agent 从一开始就知道如何正确地完成任务，而不需要反复调整提示词

## 技能与工具的区别

在 AgentLoom 中，技能和工具是两个不同的概念：

| 对比项 | 技能（Skill） | 工具（Tool） |
|--------|--------------|-------------|
| 本质 | 知识和方法指导 | 可执行的功能接口 |
| 作用方式 | 注入到 Agent 的系统提示中 | Agent 在需要时主动调用 |
| 类比 | 类似于一本专业手册 | 类似于一件工具 |
| 使用场景 | 指导 Agent 如何思考和工作 | 让 Agent 执行具体操作 |
| 举例 | 代码审查规范、文档编写指南 | 搜索网页、读写文件、执行代码 |

简单来说，技能告诉 Agent 「应该怎么做」，工具让 Agent 「能够去做」。两者配合使用，可以让 Agent 既有正确的方法论，又有执行能力。

## 技能的工作原理

当 Agent 开始一次对话或在工作流中执行任务时，AgentLoom 会自动完成以下步骤：

1. 查询当前租户下已启用的技能列表
2. 根据 Agent 或工作流的配置，选择相关的技能
3. 将技能内容组装为结构化的 XML 片段
4. 将这些片段注入到 Agent 的系统提示中

这个过程对用户是透明的 -- 你不需要手动将技能内容复制粘贴到提示词里，系统会自动处理。

## 技能的来源

AgentLoom 中的技能有两种来源：

### 内置技能

平台预置了 5 个经过验证的常用技能，覆盖了软件开发中最常见的场景。这些内置技能开箱即用，无需额外配置。详情请参考[内置技能](./built-in.md)。

### 自定义技能

你可以创建属于自己组织的自定义技能。自定义技能使用 SKILL.md 格式编写，支持 YAML 前置元数据和 Markdown 正文。你可以为技能附加相关文件，让 Agent 在执行时可以参考这些补充资料。

## 技能的格式

技能文档采用 SKILL.md 格式，由两部分组成：

### YAML 前置元数据

定义技能的基本属性，包括名称、描述、许可协议、兼容性要求等。

### Markdown 正文

技能的核心内容，使用 Markdown 格式编写。通常包括：

- 任务目标和适用场景
- 工作流程和步骤
- 注意事项和约束条件
- 质量标准和检查清单
- 示例和模板
