# 故障排查

遇到问题了？不用担心，本章节帮助你快速定位和解决在使用 AgentLoom 过程中可能遇到的各类问题。

## 如何使用本章节

### 快速查找

如果你遇到了具体的错误消息，请直接查看 [错误参考](./errors) 页面，里面按错误类型列出了常见错误消息、原因和解决方案。

如果你的问题是关于某个功能"怎么用"或"为什么不行"，请查看 [常见问题（FAQ）](./faq) 页面。

### 常见问题分类

| 问题类别 | 典型症状 | 查看页面 |
|----------|----------|----------|
| 账户与登录 | 无法登录、权限不足、MFA 问题 | [FAQ](./faq) |
| 工作流编辑 | 节点无法连线、配置无法保存 | [FAQ](./faq) |
| 工作流执行 | 执行失败、超时、无输出 | [FAQ](./faq) + [错误参考](./errors) |

| 知识库 | 文档处理失败、检索无结果 | [FAQ](./faq) |
| API 与集成 | API 调用报错、限流、Webhook 不触发 | [FAQ](./faq) + [错误参考](./errors) |

## 排查思路

当你遇到问题时，建议按照以下步骤排查：

### 1. 确认问题范围

- 这个问题是否只影响你一个人？让同事尝试相同操作
- 问题是偶发的还是持续的？
- 是否与最近的操作变更有关？

### 2. 检查基本条件

- 你的网络连接是否正常？
- 你是否已正确登录？尝试刷新页面
- 你的角色权限是否足够执行当前操作？
- 你的组织是否已配置必要的资源（模型提供商、知识库等）？

### 3. 查看执行记录

对于工作流执行相关的问题：

- 在工作流页面查看执行历史记录
- 点击具体的执行记录查看各节点的状态
- 检查失败节点的错误信息
- 查看监控仪表板了解整体运行状况（设置 > 运行监控）

### 4. 检查资源配额

如果操作被拒绝或返回 429/409 错误：

- 进入 设置 > 资源配额 查看当前组织的配额使用情况
- 确认是否超过了并发执行数、日执行量或 API 调用限制

### 5. 收集信息

如果以上步骤无法解决问题，请收集以下信息以便获取进一步帮助：

- 问题的具体描述和复现步骤
- 错误消息的完整内容
- 发生问题的时间
- 浏览器类型和版本
- 相关的工作流或 Agent 名称

## 获取帮助

如果你在文档中没有找到问题的解决方案：

- **社区论坛**：在社区中搜索或发起讨论
- **技术支持**：通过平台内的反馈渠道提交工单
- **更新日志**：查看[更新日志](../whats-new/)，确认你遇到的问题是否已在新版本中修复

## 提交问题报告的建议

当你向技术支持提交问题时，一份高质量的问题报告能帮助团队更快地定位和解决问题。建议包含以下信息：

1. **问题摘要**：用一句话描述遇到的问题
2. **复现步骤**：列出导致问题出现的操作步骤
3. **期望行为**：描述你认为正确的行为应该是什么
4. **实际行为**：描述实际发生了什么（包括错误消息）
5. **环境信息**：浏览器类型/版本、操作系统、移动端还是 Web 端
6. **时间戳**：问题发生的大致时间，便于排查日志
7. **截图或录屏**：如果方便的话，提供问题界面的截图
