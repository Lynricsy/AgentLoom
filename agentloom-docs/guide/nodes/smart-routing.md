# 智能路由

在多个候选模型之间按路由策略选出一个，并把选中的模型通过「选定模型」端口交给下游。候选模型来自连接到「模型 1」「模型 2」等端口的 [LLM 模型](/guide/nodes/llm-model) 节点。

## 使用要点

- 配置面板「智能路由配置」中的「路由策略」列表从服务端加载；registry 中声明的策略值见上方配置项表。所选策略需要额外参数时，面板会出现「策略参数」区域。
- 执行时节点先收集各候选端口连接的模型配置，再过滤掉健康监控判定为不可用的模型，然后交给所选策略决策；面板的「Provider 状态」区域显示各候选模型当前的健康状态（正常 / 降级 / 断路）。
- 策略没有选出任何模型时节点失败（错误信息含 `未能选择模型`）。每次决策都会被记录，供历史类策略参考。
- 「选定模型」端口输出的是选中的模型配置，与 LLM 模型节点的「模型」端口同类型，可连接到 Agent 画布中 Agent Main 的「模型」端口。
