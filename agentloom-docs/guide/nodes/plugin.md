# 插件节点

由已安装插件提供的自定义节点。每个插件可以声明自己的节点类型、端口与配置；画布上的插件节点在运行时交给插件运行时执行。

## 使用要点

- 插件节点不在固定的节点列表中：组织启用插件后，节点面板会出现「Plugins」分组，列出插件声明的节点，从这里拖入画布。上方生成表只列出通用插件节点的定义，具体端口与配置以插件为准。
- 配置面板显示插件与「节点类型」。节点缺少插件或插件节点类型时，面板提示「此节点需要从已安装的插件中选择，否则无法执行。」或「此节点缺少插件节点类型，请从已安装的插件中重新拖入节点。」；运行时也会失败。
- 执行时服务端先确认插件处于启用状态，再把节点放入插件执行队列，由插件运行时异步执行；因此节点状态会先为 `queued`，由插件运行时取走后再继续。
- 安装与启用插件见 [使用插件](/guide/integrations/plugins)；开发插件见 [插件开发](/api/plugins/)。
