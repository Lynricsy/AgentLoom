# 节点参考

每个节点页的结构相同：开头一段说明节点用途；「端口与配置」是从 Studio 节点定义生成的表格，列出输入端口、输出端口（端口 ID、名称、数据类型、是否必填、能否多连接）和配置项（配置键、名称、类型、默认值）；「使用要点」说明节点运行时的实际行为和常见错误；「相关」给出相关节点和指南。端口之间能否连线取决于数据类型，兼容规则见 [什么是 AgentLoom](/guide/getting-started/) 中的端口类型表。下表「节点面板可见」为「否」的节点不能从节点面板直接拖出，对应节点页说明了它们如何出现在画布上。
