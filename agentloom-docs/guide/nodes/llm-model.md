# LLM 模型

为 Agent 或智能路由提供一份模型配置（Provider、模型与推理参数）。节点本身不调用模型，只把选定的模型配置通过「模型」端口交给下游。

## 使用要点

- 配置面板标题为「LLM 模型配置」，可「选择已有配置」或「创建新配置」；新建时需要填写配置名称、选择 Provider 与模型，可选 Temperature（0–2）、Max Tokens、Top P（0–1）、Frequency Penalty / Presence Penalty（-2–2）与超时时间（5000–600000 ms）。保存后的配置在侧边栏「资源 → LLM 模型」中统一管理。
- 在 Agent 画布上，配置面板底部还有「思考强度」，决定该 Agent 主模型的推理强度。可选项不是固定列表，而是按所选模型配置的实际能力给出（服务端依据 LiteLLM 模型目录或 pi-ai 内置模型目录判定）：第一项总是「默认」，其后只列出该模型支持的强度，取值范围为关闭 / 最低 / 低 / 中 / 高 / 极高 / 最高；目录记录了模型自身的默认强度时，下方会提示「模型默认：…」。
  - 选「默认」会清除节点上的设置：模型支持关闭思考时不开启思考，否则（包括两个模型目录都没有该模型时）不发送强度参数、由模型按自身默认强度推理。
  - 未选择模型时下拉不可用，提示「先选择模型」；获取模型能力期间下拉暂不可用；获取失败时下拉不可用，可点「重试」。模型不做推理时显示「该模型不支持思考」，两个模型目录都没有这个模型时显示「未能获取该模型的思考能力（模型目录里没有这个模型）」，这两种情况下没有可选强度，只有节点上残留旧强度时才能打开下拉把它清回「默认」。
  - 节点上已保存的强度不在当前模型的支持范围内时（切换模型会保留原来的强度，因此常见于切换模型后），下拉显示该强度并标注「（当前模型不支持）」，例如「高（当前模型不支持）」，同时提示运行时会改用最接近的受支持强度，不会让运行失败；可以改选其他强度或选「默认」清除。
  - 该设置保存在节点上而非模型配置里，只在 LLM 模型节点直接连到 Agent Main 的「模型」端口时生效，经 [智能路由](/guide/nodes/smart-routing) 选出的模型不带思考强度。工作流画布上的 LLM 模型节点没有这一项。
- 执行时节点读取所绑定的模型配置 ID，并把它作为「模型」端口的输出；未绑定配置时节点失败，错误信息为 `LLM 模型节点缺少 llmModelConfigId`。
- 「模型」端口可同时连接多个下游，常见目标是 Agent 画布中 Agent Main 节点的「模型」端口，或 [智能路由](/guide/nodes/smart-routing) 的「模型 1 / 模型 2」端口。工作流画布上的 [Agent](/guide/nodes/agent) 节点没有模型输入端口，它使用所绑定 Agent 自己的模型配置。
