# Condition

按顺序判断若干条件分支，把输入数据交给第一个命中的分支；都不命中时走 ELSE 分支。

## 使用要点

- 配置面板「条件分支」中可「添加 ELSE IF 分支」并上移、下移、删除分支；「输入端口」区域可「添加输入」，新增的输入端口依次命名为「输入 2」「输入 3」……，每个端口可接收任意类型的上游值。
- 每个分支可在「可视化模式」与「表达式模式」之间切换。可视化模式：「添加条件」后为每条条件选择输入端口、「字段路径（可选）」、运算符与「值」，多条条件用 AND / OR 组合；运算符有 等于、不等于、包含、不包含、大于、大于等于、小于、小于等于、以...开头、以...结尾、为空、不为空、正则匹配。表达式模式：一段 JavaScript 表达式，可使用 `input`（以端口 ID 为键的输入对象）、`flatInput`（展平后的输入）与 `ports`（按端口顺序编号，`ports[1]` 是第一个输入端口）；表达式超时 1 秒。
- 分支按从上到下的顺序判断，命中第一个后不再判断后面的分支。没有任何规则的分支视为不命中。
- 命中分支的输出端口携带完整输入数据，其他分支输出为空；只连在未命中分支上的下游节点会被标记为已跳过（skipped），被跳过节点的下游如果所有前驱都被跳过，也会被跳过。
