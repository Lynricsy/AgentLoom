# 可复用块

## 功能说明

可复用块节点允许你将一组节点封装为一个单独的"块"，然后在当前工作流或其他工作流中复用它。类似于编程中的函数封装——你可以把一段常用的逻辑打包成一个模块，需要时直接调用。

可复用块有自己的版本管理机制，确保你可以安全地迭代和更新块的内容。

## 使用场景

- **标准化流程段**：将团队中常用的数据处理流程（如"文本清洗+翻译+格式化"）封装为一个可复用块，在多个工作流中统一使用。
- **最佳实践沉淀**：将经过验证的工作流片段封装后分享给团队，避免每个人都从零搭建。
- **复杂工作流简化**：将大型工作流中的子流程封装为块，让画布更整洁、更易于理解。

## 端口说明

可复用块的端口是动态的，由块内部定义的输入和输出决定。

### 输入端口

块的输入端口对应块内部子图的入口。当你封装一组节点为块时，那些暴露给外部连接的输入端口会成为块节点的输入端口。

### 输出端口

块的输出端口对应块内部子图的出口。块内部执行完成后，产出数据通过这些端口传递给下游节点。

## 配置项

### 块选择

在放置可复用块节点时，你需要从块库中选择一个已有的块。

> 界面提示：可以通过左侧面板或创建对话框浏览和搜索可用的块。

### 块内容查看

选中一个可复用块后，你可以展开它来查看内部的节点结构。

| 操作 | 说明 |
|------|------|
| 展开 | 查看块内部的节点和连线 |
| 折叠 | 将块收起为单个节点 |

### 版本管理

可复用块支持版本管理。当你更新块的内容时：

- 可以发布新版本。
- 使用该块的工作流可以选择是否升级到新版本。
- 历史版本保留，可随时回溯。

## 使用示例

### 示例一：封装文本处理流程

假设你经常需要"清洗文本 -> 翻译 -> 格式化"这样的处理链：

1. 在画布上搭建好这三步的节点和连线。
2. 框选这些节点，通过右键菜单选择"封装为可复用块"。
3. 为块命名（如"文本清洗翻译格式化"）并定义输入/输出端口。
4. 以后在任何工作流中都可以直接使用这个块，不需要重新搭建。

### 示例二：在其他工作流中使用块

1. 在新工作流的画布上，从块库中找到目标块。
2. 将块拖拽到画布上。
3. 将上游数据连接到块的输入端口，将块的输出端口连接到下游节点。
4. 执行时，块内部的节点会按设计好的逻辑运行。

## 注意事项

1. **动态端口**：可复用块的输入和输出端口由块内部定义决定。不同的块有不同的端口。
2. **块库管理**：你可以在专门的块库管理页面创建、编辑和管理所有可复用块。
3. **版本一致性**：当块发布新版本后，已使用旧版本的工作流不会自动升级。你需要手动更新每个工作流中的块版本。
4. **嵌套限制**：可复用块内部可以包含各种节点，但应避免过度嵌套（块套块），以保持可维护性。
5. **独立于画布**：可复用块在节点面板中不会默认显示，需要通过专门的创建流程来使用。
