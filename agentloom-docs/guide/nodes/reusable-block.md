# Reusable Block

把一组节点作为一个整体放到画布上复用。块可以从画布上已选的节点封装得到，也可以从块文件导入；配置面板显示「块名称」「描述」「内部节点数」「内部连线数」与输入、输出端口，可「查看内部图」。

## 端口与配置

<!--@include: ../../_generated/nodes/reusable-block.md-->

块的输入、输出端口不是固定的：每个块端口映射到块内某个节点的某个端口（封装时由连线自动派生，见下文）。

## 使用要点

- **封装**：在画布上框选或按住 Ctrl / ⌘ 多选至少两个同一层级的节点（同为顶层，或同在一个 Loop / Iteration 容器内；选中容器会连同其内部节点一起封装），右键选择「封装为可复用块」。对话框按「从块外连进选区」与「从选区连出块外」的连线派生输入、输出端口，可改端口名称；填写「块名称」与分类后点「确认创建」。块先保存到「My Blocks」，保存成功后选区在画布上被一个块节点替换，原有外部连线改接到块的对应端口。保存失败时画布不变。
- **复用**：Reusable Block 不出现在节点面板的分类列表中。在节点面板切换到「My Blocks」标签，把块拖到画布上；也可以点「导入」选择块文件（`.agentloom-block.json` 或 `.json`）。画布上的块节点内嵌一份块定义的拷贝，之后在 My Blocks 中修改块不会影响已经拖到画布上的块。
- **执行**：运行工作流时，服务端在生成执行快照前把块展开为块内节点。块内节点的执行步骤 ID 为 `<块节点 ID>::<块内节点 ID>`（块中再嵌块时逐层加前缀），连到块端口的外部连线改接到端口映射的块内节点端口，块内节点按普通节点调度。画布上的块节点显示块内步骤的汇总状态：任一步骤失败即为失败，其次依次是等待人工干预、运行中；全部完成（或跳过）为完成。执行详情里列出每个块内步骤。
- 块端口没有映射到块内节点，或外部连线连到块上不存在的端口时，运行请求返回 422，错误类型 `https://agentloom.dev/errors/reusable-block-expansion-failed`。
